#### Інсталятор Windows (GUI + CLI + Backend)

* **Тип файлу**: .exe (інсталятор Windows)**Етапи інсталяції:**

1. Завантажте вищезазначений файл .exe
2. Двічі клацніть на інсталятор, щоб розпочати інсталяцію
3. Дотримуйтесь підказок майстра інсталяції
4. Виберіть каталог для встановлення (за замовчуванням: `C:\Program Files\[USER]\Chloros\`)
5. Завершіть встановлення та запустіть Chloros або Chloros CLI
6. Увійдіть у свій [MAPIR Cloud Chloros+ обліковий запис](https://cloud.mapir.camera/pricing) (або продовжуйте користуватися безкоштовною версією)

{% hint style="success" %}
Інсталятор автоматично додає `chloros-cli` до системного PATH для доступу через командний рядок.
{% endhint %}

#### Linux amd64 (пакет .deb — CLI + Backend)

* **Тип файлу**: .deb (пакет Debian/Ubuntu)
* **Архітектура**: x86\_64 (amd64)

```bash
sudo dpkg -i chloros-amd64.deb
chloros-cli --version  # Verify installation
```

#### Linux arm64 — NVIDIA Jetson (пакет .deb — CLI + Backend)

* **Тип файлу**: .deb (JetPack 6)
* **Архітектура**: aarch64 (arm64)

```bash
sudo dpkg -i chloros-arm64-jp6.deb
chloros-cli --version  # Verify installation
```

Детальні інструкції з налаштування див. у розділі [Встановлення Linux](linux/linux-installation.md), а рекомендації щодо роботи з Jetson — у [Посібнику з NVIDIA Jetson](linux/nvidia-jetson-guide.md).

#### Python SDK (Усі платформи)

```bash
pip install chloros-sdk
```

Дивіться [API : Python SDK](api-python-sdk.md) для документації.

{% hint style="info" %}
**Користувачі Linux**: Пакет `.deb` встановлює CLI та бекенд. Python SDK встановлюється окремо за допомогою pip. Для Linux немає графічного інтерфейсу — вся взаємодія відбувається через CLI або SDK.
{% endhint %}

## Допомога з інсталяцією

### Усунення несправностей

**Інсталяція завершується з помилкою:**

* Переконайтеся, що у вас є права адміністратора
* Тимчасово вимкніть антивірусне програмне забезпечення
* Перевірте, чи відповідає ваша система мінімальним системним вимогам

**Програма не запускається (Windows):**

* Перевірте, чи встановлено Windows 10/11 (64-біт)
* Оновіть драйвери графічної карти
* Перевірте Windows «Переглядач подій» на наявність деталей про помилку
* Зверніться до служби підтримки з журналами помилок

**CLI не запускається (Linux):**

* Перевірте, чи правильно встановлено пакет `.deb`: `dpkg -l | grep chloros`
* Перевірте права доступу: `sudo chmod +x /usr/bin/chloros-cli`
* Запустіть діагностику: `chloros-cli selftest`
* Перевірте наявність відсутніх бібліотек: `ldd /usr/lib/chloros/chloros-backend | grep "not found"`

**Проблеми з активацією ліцензії:**

* Переконайтеся, що підключення до Інтернету активне
* Перевірте облікові дані за адресою [https://cloud.mapir.camera](https://cloud.mapir.camera)
* Перевірте, чи брандмауер не блокує Chloros
* Детальні інструкції дивіться за посиланням [Chloros+ Вхід](chloros+-login.md)
