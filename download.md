#### Інсталятор для Windows (GUI + CLI + Backend)

* **Тип файлу**: .exe (інсталятор для Windows)

1. Завантажте зазначений вище файл .exe
2. Двічі клацніть на інсталяторі, щоб розпочати інсталяцію
3. Дотримуйтесь вказівок майстра інсталяції
4. Оберіть каталог для інсталяції (за замовчуванням: `C:\Program Files\Chloros\`)
5. На сторінці **Вибір додаткових завдань**залиште позначені обидві опції**Системні налаштування** (рекомендовано — див. нижче)
6. Завершіть інсталяцію та запустіть Chloros або Chloros CLI
7. Увійдіть у свій [обліковий запис MAPIR Cloud Chloros+](https://cloud.mapir.camera/pricing) (або продовжуйте користуватися безкоштовною версією)

**Параметри системних налаштувань** (обидва відмічені за замовчуванням):

| Параметр, як зазначено в інсталяторі | Що він робить | Відмова від автоматичної інсталяції |
| --- | --- | --- |
| **Увімкнути довгі шляхи в Windows** (дозволяє розміщувати папки проектів глибше, ніж 260 символів; рекомендується) | Встановлює для всієї системи Windows значення параметра `LongPathsEnabled` на 1. У Windows цей параметр вимкнено за замовчуванням, і тоді жоден шлях до файлу не може перевищувати 260 символів; продукти Chloros розміщуються приблизно на 130 символів нижче за папку проєкту, тому при вимкнених довгих шляхах глибша папка проєкту не допускається. Набуває чинності для програм, запущених після інсталяції. Залишається увімкненим після видалення програми, оскільки інші програми можуть покладатися на це налаштування. | `/MERGETASKS="!longpaths"` |
| **Виключити бекенд Chloros зі сканування Microsoft Defender** (значно швидше захоплення зображення з камери; рекомендується) | Додає виключення процесу Microsoft Defender для `chloros-backend.exe` у папці інсталяції, завдяки чому захист у реальному часі не сканує кожен файл, який записує бекенд, незалежно від місця запису. При високій частоті зйомки сканування займає приблизно 30 % від частоти зйомки (77,7 проти 52,7 знімків на секунду під час безперервної зйомки з 9 камер). Жодна інша програма не виключається, а виключення видаляється під час видалення програми. Якщо Defender відсутній або заблокований політикою, цей крок тихо завершується з помилкою, а інсталяція продовжується. | `/MERGETASKS="!defenderexclusion"` |

Після встановлення відкрийте новий термінал, щоб скористатися `chloros-cli`. Інсталятор також додає два правила брандмауера Windows для бекенду в кожному профілі мережі: **Chloros Backend (UDP-In)**— для потоків з камер, PTP, mDNS та потоку даних DAQ-E, а також**Chloros Backend (TCP-In)**, обмежене локальною підмережею, для оновлення прошивки DAQ-E, під час якого датчик підключається до цього комп’ютера для збору зображення. Обидва правила видаляються під час видалення програми.
{% endhint %}

#### Linux amd64 (пакет .deb — CLI + бекенд)

* **Тип файлу**: .deb (пакет Debian/Ubuntu)
* **Архітектура**: x86\_64 (amd64)

```bash
sudo apt install ./chloros_1.3.0_amd64.deb
chloros-cli --version     # Verify installation: "Chloros CLI 1.3.0"
```

#### Linux arm64 — NVIDIA Jetson (пакет .deb — CLI + бекенд)

* **Тип файлу**: .deb (JetPack 6)
* **Архітектура**: aarch64 (arm64)

```bash
sudo apt install ./chloros_1.3.0_arm64_jp6.deb
chloros-cli --version     # Verify installation: "Chloros CLI 1.3.0"
```

Використовуйте ім’я файлу, яке ви фактично завантажили, і залиште `./`, щоб `apt` встановив саме цей файл, а не шукав пакет за назвою. Встановіть за допомогою `apt install`, а не за допомогою `dpkg -i`: apt також встановлює вимоги Python SDK, які пакет рекомендує, а не вимагає, а `dpkg -i` пропускає їх. Починаючи з версії 1.3.0, бекенд та CLI встановлюються у розпакованому вигляді під `/usr/lib/chloros/`, тому вони запускаються без попереднього розпакування.

Пакет Jetson використовує CUDA-збірку PyTorch від JetPack 6, тому обробка, включаючи вбудований дебейер Texture Aware, виконується на графічному процесорі Jetson. Він використовує бібліотеки CUDA та cuDNN, які встановлює JetPack 6 (`sudo apt install nvidia-jetpack` на образі, де їх немає).

Детальні інструкції з налаштування див. у розділі [Встановлення на Linux](linux/linux-installation.md), а рекомендації щодо Jetson — у [Посібнику з NVIDIA Jetson](linux/nvidia-jetson-guide.md).

#### Python SDK (усі платформи)

Кожен інсталятор містить відповідний пакет wheel `chloros_sdk`, тому версія SDK завжди відповідає встановленому графічному інтерфейсу, CLI або бекенду. У Windows інсталятор автоматично встановлює його у системний Python. У Linux `.deb` встановлює SDK для самого системного `python3` (у `/usr/lib/python3/dist-packages`), тож `import chloros_sdk` працює одразу після встановлення, без pip та без підключення до мережі. Лише у віртуальне середовище (virtualenv), яке не бачить системних пакетів, потрібно встановити вбудований файл wheel:

```bash
pip install /usr/lib/chloros/sdk/chloros_sdk-*.whl
```

Для хостів, що використовують лише pip (без встановленого пакета Chloros; у цьому випадку SDK керує бекендом на іншій машині), SDK також доступний на PyPI:

```bash
pip install chloros-sdk
```

Документацію дивіться у розділі [API: Python SDK](api-python-sdk.md) та [Довідка по SDK](reference/sdk-reference.md).

{% hint style="info" %}
**Користувачі Linux**: Пакет `.deb` встановлює CLI, бекенд та Python SDK. Для Linux немає графічного інтерфейсу — вся взаємодія відбувається через CLI або SDK.
{% endhint %}

## Допомога з інсталяцією

### Усунення несправностей

**Інсталяція завершується з помилкою:**

* Переконайтеся, що у вас є права адміністратора
* Тимчасово вимкніть антивірусне програмне забезпечення
* Перевірте, чи відповідає ваша система мінімальним системним вимогам

**Програма не запускається (Windows Windows):**

* Переконайтеся, що встановлено Windows 10/11 (64-бітна версія)
* Оновіть драйвери відеокарти
* Перевірте журнал подій Windows для детальної інформації про помилку
* Зверніться до служби підтримки, надавши журнали помилок

**CLI не запускається (Linux):**

* Перевірте, чи правильно встановлено пакет `.deb`: `dpkg -l | grep chloros`
* Перевірте права доступу: `sudo chmod +x /usr/bin/chloros-cli`
* Запустіть діагностику: `chloros-cli selftest`
* Перевірте, чи не бракує бібліотек: `ldd /usr/lib/chloros/backend/chloros-backend | grep "not found"` (починаючи з версії 1.3.0, `/usr/lib/chloros/chloros-backend` — це невеликий скрипт-запускач; сама програма знаходиться у файлі `/usr/lib/chloros/backend/`)

**Проблеми з активацією ліцензії:**

* Переконайтеся, що підключення до Інтернету активне
* Перевірте облікові дані за посиланням [https://cloud.mapir.camera](https://cloud.mapir.camera)
* Переконайтеся, що брандмауер не блокує Chloros

* Детальні інструкції дивіться у розділі [Chloros+ Login](chloros+-login.md)

## Оновлення програмного забезпечення

Chloros перевіряє наявність оновлень, повідомляє про вихід нової версії та надає посилання на цю сторінку завантаження — оновлення виконується шляхом запуску нового підписаного інсталятора. У Linux та Jetson `chloros-cli update` перевіряє наявність новішої версії та пропонує завантажити й встановити відповідну `.deb` (ця команда доступна лише в Linux).
