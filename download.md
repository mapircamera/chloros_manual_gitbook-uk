#### Інсталятор Windows (графічний інтерфейс + CLI + серверна частина)

* **Тип файлу**: .exe (інсталятор Windows)**Покрокові інструкції з встановлення:**

1. Завантажте вищезазначений файл .exe
2. Двічі клацніть на інсталяторі, щоб розпочати встановлення
3. Дотримуйтесь підказок майстра встановлення
4. Оберіть каталог для встановлення (за замовчуванням: `C:\Program Files\MAPIR\Chloros\`)
5. Завершіть інсталяцію та запустіть Chloros або Chloros CLI
6. Увійдіть у свій [обліковий запис MAPIR Cloud Chloros+](https://cloud.mapir.camera/pricing) (або продовжуйте користуватися безкоштовною версією)

{% hint style="success" %}
Інсталятор автоматично додає `chloros-cli` до системної змінної PATH для доступу через командний рядок.
{% endhint %}

#### Linux amd64 (пакет .deb — CLI + бекенд)

* **Тип файлу**: .deb (пакет Debian/Ubuntu)
* **Архітектура**: x86\_64 (amd64)

```bash
sudo dpkg -i chloros-amd64.deb
chloros-cli --version  # Verify installation
```

#### Linux arm64 — NVIDIA Jetson (пакет .deb — CLI + бекенд)

* **Тип файлу**: .deb (JetPack 6)
* **Архітектура**: aarch64 (arm64)

```bash
sudo dpkg -i chloros-arm64-jp6.deb
chloros-cli --version  # Verify installation
```

Детальні інструкції з налаштування див. у розділі [Встановлення Linux](linux/linux-installation.md), а рекомендації щодо роботи з Jetson — у [Посібнику з NVIDIA Jetson](linux/nvidia-jetson-guide.md).

#### Python SDK (усі платформи)

Кожен інсталятор містить відповідний модуль `chloros_sdk`, тому версія SDK завжди відповідає встановленому графічному інтерфейсу (GUI)/CLI/бекенду. На Windows інсталятор автоматично встановлює його у вашу систему Python; у версії Linux інсталятор `.deb` розміщує колесо у `/usr/lib/chloros/sdk/` і виводить команду інсталяції:

```bash
pip install --user /usr/lib/chloros/sdk/chloros_sdk-*.whl
```

Для хостів, що підтримують лише pip (без встановленого пакета Chloros), SDK також доступний на PyPI:

```bash
pip install chloros-sdk
```

Див. [API : Python SDK](api-python-sdk.md) та [Довідник SDK](reference/sdk-reference.md) для ознайомлення з документацією.

{% hint style="info" %}
**Користувачі Linux**: Пакет `.deb` встановлює CLI та серверну частину. Для Linux графічний інтерфейс відсутній — вся взаємодія відбувається через CLI або SDK.
{% endhint %}

## Допомога з інсталяцією

### Усунення несправностей

**Інсталяція завершується з помилкою:**

* Переконайтеся, що у вас є права адміністратора
* Тимчасово вимкніть антивірусне програмне забезпечення
* Перевірте, чи відповідає ваша система мінімальним системним вимогам

**Програма не запускається (Windows):**

* Перевірте, чи встановлено Windows 10/11 (64-біт)
* Оновіть драйвери відеокарти
* Перегляньте журнал подій Windows, щоб дізнатися подробиці про помилку
* Зверніться до служби підтримки, надавши журнали помилок

**CLI не запускається (Linux):**

* Перевірте, чи правильно встановлено пакет `.deb`: `dpkg -l | grep chloros`
* Перевірте права доступу: `sudo chmod +x /usr/bin/chloros-cli`
* Запустіть діагностику: `chloros-cli selftest`
* Перевірте, чи не бракує бібліотек: `ldd /usr/lib/chloros/chloros-backend | grep "not found"`

**Проблеми з активацією ліцензії:**

* Переконайтеся, що підключення до Інтернету активне
* Перевірте облікові дані за посиланням [https://cloud.mapir.camera](https://cloud.mapir.camera)
* Перевірте, чи брандмауер не блокує Chloros
* Детальні інструкції див. у розділі [Chloros+ Вхід](chloros+-login.md)

## Оновлення програмного забезпечення

Chloros перевіряє наявність оновлень, повідомляє про появу нової версії та надає посилання на цю сторінку завантаження — оновлення виконується шляхом запуску нового підписаного інсталятора. Ваші налаштування та проєкти зберігаються після оновлення. У Linux та Jetson `chloros-cli update` перевіряє наявність новішої версії та пропонує завантажити й встановити відповідний `.deb` (ця команда доступна лише у версії Linux).
