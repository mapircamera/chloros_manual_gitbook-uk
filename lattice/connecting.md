# Підключення камер

<figure><img src="../.gitbook/assets/image (37).png" alt=""><figcaption><p>Вкладка «Камери» до підключення будь-яких пристроїв</p></figcaption></figure>Chloros автоматично виявляє камери LATTICE на каналі зв&#x27;язку — з вкладки «Камери» графічного інтерфейсу, з `chloros-cli lattice`, або з Python SDK. Рядок моделі камери визначає всі подальші дії: Chloros визначає профіль датчика, схему діапазонів та заводське калібрування на основі параметрів камери `DeviceUserID` + `DeviceSerialNumber`, тому **налаштування для кожної камери не потрібні**.

Перед підключенням переконайтеся, що мережа хоста налаштована — локальна адресація каналу, джамбо-фрейми та, для масивів, налаштування буфера прийому мережевої карти. Це налаштування на рівні апаратного забезпечення, яке описано в посібнику LATTICE: [**Налаштування мережі**](https://mapir.gitbook.io/lattice-camera/setup/network-setup).

## Підключення через графічний інтерфейс

Відкрийте вкладку **Камери**на бічній панелі Chloros (вкладки, пов’язані з апаратним забезпеченням, з’являються після завершення запуску серверної частини), або скористайтеся головним меню →**Підключити камеру**. Обидва варіанти відкривають діалогове вікно**Підключити камеру(и)**.

### Діалогове вікно «Підключити камери»

Діалогове вікно сканує мережу одразу після відкриття («Сканування мережі...») і відображає список усіх знайдених камер. У кожному рядку вказано **модель**камери (наприклад, `LATT-M3M-L41-F550`),**серійний номер**та**IP-адресу**.

* **Клацніть на рядку, щоб вибрати його**(зелене підсвічування). Ви можете вибрати**кілька камер** і підключити їх одночасно — Chloros підключає їх послідовно.
* Рядки з позначкою **«Підключено»** вже підключені й не можуть бути вибрані повторно.
* Рядки з позначкою **«У масиві»** належать до масиву камер, що наразі підключений. Спочатку відключіть масив, щоб використовувати цю камеру автономно.
* **Підключити** — підключає вибрані камери; на кнопці відображається кількість, наприклад «Підключити (3)», якщо вибрано більше однієї камери.
* **Повторне сканування** — запускає пошук знову.
* **Закрити** — закриває діалогове вікно.
* Якщо сканування завершилося без результатів, у діалоговому вікні з’явиться повідомлення **«У мережі не знайдено камер»** — див. розділ [Усунення несправностей](connecting.md#troubleshooting) нижче.

<figure><img src="../.gitbook/assets/image (38).png" alt=""><figcaption><p>Діалогове вікно «Підключити камери» — тут показано, коли в мережі немає камер</p></figcaption></figure>### Перше підключення: завантаження пакета калібрування

**Під час першого**підключення певної камери до комп’ютера Chloros завантажує заводський пакет калібрування камери (\~3,8 МБ) безпосередньо з камери через GigE. Поки це відбувається, у діалоговому вікні відображається зелена панель**«Завантаження даних калібрування з камери»**із індикатором прогресу для кожного серійного номера — очікуйте приблизно**70 секунд** на кожну камеру. Пакет зберігається в кеші на хості, тому під час подальших підключень тієї самої камери завантаження повністю пропускається (і панель не відображається).

### Аналіз системи

Кнопка **«Аналіз системи»** у діалоговому вікні виконує діагностику хоста та мережі (під час роботи з’являється напис «Аналізується...») і формує діагностичний звіт:

* **Хост** — ядра процесора та обсяг оперативної пам’яті; назва та обсяг пам’яті графічного процесора (GPU) або «GPU: не виявлено».
* **Мережеві інтерфейси** — назва кожного мережевого адаптера, швидкість з’єднання, MTU (з позначкою «jumbo», якщо активна), стан (активний/неактивний) та інформація про те, чи підключений він до USB-шини.
* **Камери**— серійний номер, модель, IP-адреса та**на якій мережевій карті підключена кожна камера**.
* **Продуктивність** — поточна та ідеальна частота кадрів (fps) на камеру для даного формату пікселів; зелений рядок «Потенціал: можливе покращення в N разів» з’являється, коли ідеальне значення перевищує поточне.
* **Попередження та пронумеровані рекомендації** — або повідомлення «Система працює нормально для поточної кількості камер», коли нічого виправляти не потрібно.

Запускайте цю функцію, коли виявлення або потокове передавання даних відбувається несподівано — вона виявляє більшість проблем на стороні мережевих карт (неправильний розмір MTU, камера підключена до неправильного інтерфейсу, обмеження USB-адаптера) без виходу з діалогового вікна.

### Підключення масиву

Щоб підключити дві або більше камер як **синхронізований масив**, скористайтеся майстром підключення масиву (**Підключити масив камер**): він покроково проведе вас через вибір головного/підлеглого пристрою (попередньо заповнений за допомогою зонда підключення GPIO), вибір режиму відображення (окремі або об’єднані фрагменти) та налаштування масиву з динамічним прогнозом можливої частоти кадрів та пропускної здатності каналу перед підтвердженням. Майстер та робочі процеси роботи з масивами описані в розділі «Масиви з декількох камер» цього посібника; еквівалентом для CLI є «Процес першого підключення камери LATTICE» у [Довіднику CLI](../reference/cli-reference.md).

## Підключення з CLI та SDK

Для доступу до CLI та SDK необхідний платний тарифний план Chloros+ та авторизація; це контролюється на стороні сервера (`401 AUTH_REQUIRED`, якщо ви не ввійшли в систему, `403 PLAN_UPGRADE_REQUIRED` на безкоштовному тарифі).

```bash
# List cameras on the network (vendor, model, serial, IP, MAC)
chloros-cli lattice info

# Single-camera smoke test: capture one frame (saves every applicable export type)
chloros-cli lattice capture -o output/

# Connect a synchronized array — same smart-prep flow as the GUI
chloros-cli lattice array-connect --serials 213800234,214000533
```

```python
import chloros_sdk

# Persistent live-camera session through the backend
with chloros_sdk.connect_camera("213800234") as cam:
    ...

# Array session (smart-prep: network probe, tier auto-pick, PTP, AE seeding, trigger config)
with chloros_sdk.connect_array(["213800234", "214000533"]) as array:
    ...
```

Повні сигнатури, параметри та робочі процеси збору даних: [CLI Довідка](../reference/cli-reference.md) § `chloros-cli lattice`, [SDK Довідка](../reference/sdk-reference.md) § `connect_camera()` / `connect_array()`.

## Як відбувається калібрування під час підключення

Кожна камера LATTICE має свій заводський пакет калібрування **вбудований у камеру**, а Chloros також перевіряє хмарне сховище MAPIR під час підключення камери:

| Ситуація   | Що використовує Chloros                                                                                                                                                                                                          |
| ----------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Онлайн**|**Найновіша калібрування, опублікована для цього серійного номера** — копія з хмари має пріоритет над копією на камері. Тому камера, яка була перекалібрована або оновлена за допомогою MAPIR, оновлюється автоматично; жодних дій з боку користувача не потрібно. |
| **Офлайн**|**Пакет, що зберігається у камері**, у тому вигляді, в якому він є. Повністю офлайн-робочі процеси продовжують працювати; вони просто не враховують новіші калібрування, доки камера хоча б раз не підключиться до мережі (або не буде перепрошита до заводських налаштувань).                                                  |

Під час зйомки фактично застосовані коефіцієнти **зафіксовані в метаданих XMP кожного зображення**. Пізніше оновлення калібрування ніколи не змінює без вашого відома вже зроблені знімки — при повторній обробці старого знімка використовуються коефіцієнти, зафіксовані в його XMP, а не найновіші на сьогодні.

## Усунення несправностей

* **&quot;У мережі не знайдено камер»**— перевірте налаштування локального з’єднання в розділі [Налаштування мережі](https://mapir.gitbook.io/lattice-camera/setup/network-setup): статична IP-адреса мережевої карти хоста `169.254.x.x/16`, камери на тому самому з’єднанні, DHCP/шлюз не передбачаються. Потім скористайтеся функцією**«Аналіз системи»**у діалоговому вікні підключення, щоб перевірити, на якій мережевій карті видно (або не видно) кожну камеру. Після будь-яких змін у кабельному підключенні або мережевій карті виконайте**повторне сканування**.
* **Система, яка раніше працювала, відмовляється підключатися** (панелі масиву з кодами `FRAMES WILL DROP` / `Reduce ROI to enable`) — оновлення драйвера мережевої карти без попередження скинуло налаштування кільця прийому. Застосуйте їх знову або запустіть `chloros-cli lattice network --fix` з терміналу з підвищеними правами; див. [Налаштування мережі](https://mapir.gitbook.io/lattice-camera/setup/network-setup).
* **Камера показує «In Array»** — вона належить до сеансу підключеного масиву. Відключіть масив, щоб використовувати камеру в автономному режимі.
