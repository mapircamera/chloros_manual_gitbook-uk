# Підключення камер

<figure><img src="../.gitbook/assets/image (37).png" alt=""><figcaption><p>Вкладка «Камери» до підключення будь-яких пристроїв</p></figcaption></figure>

Chloros автоматично виявляє камери LATTICE у мережі — через вкладку «Камери» графічного інтерфейсу, через `chloros-cli lattice` або через Python SDK. Рядок моделі камери визначає всі подальші дії: Chloros визначає профіль датчика, розкладку діапазонів та заводську калібровку на основі файлів `DeviceUserID` та `DeviceSerialNumber` камери, тому **налаштувати кожну камеру окремо не потрібно**.

Перед підключенням переконайтеся, що мережа хоста налаштована — локальна адресація, джамбо-фрейми та, для масивів, налаштування буфера прийому мережевої карти. Це налаштування на рівні апаратного забезпечення, яке описано в посібнику LATTICE: [**Налаштування мережі**](https://mapir.gitbook.io/lattice-camera/setup/network-setup).

## Підключення через графічний інтерфейс

Відкрийте вкладку **Камери** на бічній панелі Chloros (вкладки, пов’язані з апаратним забезпеченням, з’являються після завершення запуску серверної частини) або скористайтеся головним меню → **Підключити до камери**. Обидва варіанти відкривають діалогове вікно**Підключити камеру(и)**.

### Діалогове вікно «Підключити камери»

Діалогове вікно сканує мережу одразу після відкриття («Сканування мережі...») і відображає список усіх знайдених камер. У кожному рядку вказано **модель**камери (наприклад, `LATT-M3M-L41-F550`),**серійний номер**та**IP-адресу**.

* **Клацніть на рядок, щоб вибрати його**(зелене підсвічування). Ви можете вибрати**кілька камер** і підключити їх одночасно — Chloros підключає їх послідовно.
* Рядки з позначкою **«Підключено»** вже підключені і не можуть бути вибрані повторно.
* Рядки з позначкою **«У масиві»** належать до масиву камер, що наразі підключений. Спочатку від’єднайте масив, щоб використовувати цю камеру автономно.
* **Підключити** — підключає вибрані камери; на кнопці відображається кількість, наприклад «Підключити (3)», якщо вибрано більше однієї камери.
* **Повторне сканування** — запускає пошук знову.
* **Закрити** — закриває діалогове вікно.
* Якщо сканування завершилося без результатів, у діалоговому вікні з’явиться повідомлення **«У мережі не знайдено камер»** — див. розділ [Усунення несправностей](connecting.md#troubleshooting) нижче.

### Перше підключення: завантаження пакета калібрування

**Під час першого** підключення певної камери до комп’ютера Chloros завантажує заводський пакет калібрування камери (\~3,8 МБ) безпосередньо з самої камери через GigE. Під час цього процесу у діалоговому вікні відображається зелена панель **«Завантаження даних калібрування з камери»**із індикатором прогресу для кожного серійного номера — очікуйте приблизно**70 секунд** на кожну камеру. Якщо камер більше шести, рядки прогресу прокручуються всередині панелі. Пакет зберігається у кеші на хості, тому під час наступних підключень тієї самої камери завантаження повністю пропускається (і панель не відображається).

### Аналіз системи

Кнопка **«Аналіз системи»** у діалоговому вікні перевіряє хост і мережу (під час роботи на ній з’являється напис «Аналізується...») та формує діагностичний звіт:

* **Хост** — ядра процесора та оперативна пам’ять; назва та обсяг пам’яті графічного процесора, або «GPU: не виявлено».
* **Мережеві інтерфейси** — назва кожного мережевого адаптера, швидкість з’єднання, MTU (з позначкою «jumbo», якщо активна), стан (up/down) та інформація про те, чи підключений він до USB-шини.
* **Камери**— серійний номер, модель, IP-адреса та**на якій мережевій карті підключена кожна камера**.
* **Продуктивність** — поточна та ідеальна частота кадрів (fps) на камеру для даного формату пікселів; зелений рядок «Потенціал: можливе покращення в N разів» з’являється, коли ідеальне значення перевищує поточне.
* **Попередження та пронумеровані рекомендації** — або повідомлення «Система працює нормально для поточної кількості камер», коли виправити нічого немає.

Запускайте цю функцію щоразу, коли виявлення або потокове передавання даних відбувається несподівано — вона виявляє більшість проблем на стороні мережевих адаптерів (неправильний MTU, камера на неправильному інтерфейсі, обмеження USB-адаптера) без виходу з діалогового вікна.

### Підключення масиву

Щоб підключити дві або більше камер як **синхронізований масив**, скористайтеся майстром підключення масиву (**«Підключити масив камер»**): він проведе вас через вибір головного/підлеглого пристрою (попередньо заповнений за допомогою тестування синхронізаційного кабелю — будь-яка камера, підключена кабелем, може бути головною, а камера RGB `-FRGB` попередньо вибирається, коли вона підключена кабелем), вибір режиму відображення (окремі або об’єднані фрагменти) та сцену налаштувань масиву з проекцією в реальному часі можливої частоти кадрів (fps) та пропускної здатності каналу перед підтвердженням. Майстер та робочі процеси масиву описані в розділі «Багатокамерні масиви» цього посібника; еквівалентом у CLI є «Робочий процес першого підключення камери LATTICE» у [Довіднику CLI](../reference/cli-reference.md).

## Підключення через CLI та SDK
Для доступу через

CLI та SDK необхідний платний тарифний план Chloros+ та авторизація; це обмеження застосовується на стороні сервера (`401 AUTH_REQUIRED` у разі відсутності авторизації, `403 PLAN_UPGRADE_REQUIRED` на безкоштовному тарифному плані).

```bash
# List cameras on the network (vendor, model, serial, IP, MAC)
chloros-cli lattice info

# Single-camera smoke test: capture one frame (saves every applicable export type)
chloros-cli lattice capture -o output/

# Connect a synchronized array — same smart-prep flow as the GUI
chloros-cli lattice array-connect --serials 213800234,214000533
```

```python
import chloros_sdk

# Persistent live-camera session through the backend
with chloros_sdk.connect_camera("213800234") as cam:
    ...

# Array session (smart-prep: network probe, tier auto-pick, PTP, AE seeding, trigger config)
with chloros_sdk.connect_array(["213800234", "214000533"]) as array:
    ...
```

Повні сигнатури, параметри та робочі процеси збору даних: [Довідка щодо CLI](../reference/cli-reference.md) § `chloros-cli lattice`, [Довідка щодо SDK](../reference/sdk-reference.md) § `connect_camera()` / `connect_array()`.

## Як відбувається калібрування під час підключення

Кожна камера LATTICE має свій заводський пакет калібрування **вбудований у камеру**, а Chloros також перевіряє хмарне сховище MAPIR під час підключення камери:

| Ситуація   | Що використовує Chloros                                                                                                                                                                                                           |
| ----------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Онлайн**|**Найновіша калібровка, опублікована для цього серійного номера** — копія з хмари має пріоритет над копією на камері. Отже, камера, яка була перекалібрована або оновлена MAPIR, оновлюється автоматично; жодних дій з боку користувача не потрібно. |
| **Офлайн**|**Пакет, що зберігається в камері**, у тому вигляді, в якому він є. Повністю офлайн-робочі процеси продовжують працювати; вони просто не враховують новіші калібрування, доки камера хоча б раз не підключиться до мережі (або не буде перепрошита до заводських налаштувань).                                                  |

Під час зйомки коефіцієнти, що фактично застосовуються, **зафіксовані в метаданих XMP кожного зображення**. Пізніше оновлення калібрування ніколи не змінює вже зняті зображення без вашого відома — під час повторної обробки старого знімка використовуються коефіцієнти, зафіксовані в його XMP, а не ті, що є найновішими на сьогодні.

## Усунення несправностей

* **"У мережі не знайдено камер»**— перевірте налаштування локального з’єднання в розділі [Налаштування мережі](https://mapir.gitbook.io/lattice-camera/setup/network-setup): статична мережева карта хоста `169.254.x.x/16`, камери на тому самому з’єднанні, DHCP/шлюз не передбачаються. Потім скористайтеся функцією**«Аналіз системи»**у діалоговому вікні підключення, щоб перевірити, на якій мережевій карті видно (або не видно) кожну камеру. Після будь-яких змін у кабельному підключенні або мережевій карті виконайте**повторне сканування**.
* **Система, яка раніше працювала, відмовляється підключатися** (панелі масиву з кодами помилок `FRAMES WILL DROP` / `Reduce ROI to enable`) — оновлення драйвера мережевої карти без попередження скинуло налаштування кільця прийому. Застосуйте їх знову або запустіть `chloros-cli lattice network --fix` з терміналу з підвищеними правами; див. [Налаштування мережі](https://mapir.gitbook.io/lattice-camera/setup/network-setup).
* **Камера відображає статус «In Array»** — вона належить до підключеного масиву. Від’єднайте масив, щоб використовувати камеру в автономному режимі.
