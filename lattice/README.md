# Камери LATTICE

LATTICE — це модульна мультиспектральна система камер від компанії MAPIR, призначена для зйомки в сільському господарстві та науці. Кожна камера LATTICE побудована на базі сенсора Sony IMX265 з глобальним затвором (**3,1 МП, пікселі 3,45 мкм**) і підключається через Ethernet як пристрій**GigE Vision**.

Chloros 1.3.0 керує камерами LATTICE в режимі реального часу — виявлення, попередній перегляд, зйомка та синхронізовані масиви з декількох камер — з трьох інтерфейсів:

| Інтерфейс    | Де                                                          | Платформи                                                |
| ---------- | -------------------------------------------------------------- | -------------------------------------------------------- |
| Графічний інтерфейс | Вкладка **Камери** на бічній панелі Chloros                         | Windows 10/11 x64                                        |
| CLI        | Сімейство команд `chloros-cli lattice`                           | Windows 10/11 x64, Linux x86\_64, Linux aarch64 (Jetson) |
| Python SDK | `chloros_sdk.connect_camera()` / `chloros_sdk.connect_array()` | Windows 10/11 x64, Linux x86\_64, Linux aarch64 (Jetson) |

> **Шукаєте обладнання?**Модулі камер, об&#x27;єктиви, фільтри та діапазони, рами та кріплення, кабелі, PoE та проводка тригера описані в [**посібнику користувача LATTICE**](https://mapir.gitbook.io/lattice-camera). У цьому розділі розглядається керування камерами за допомогою Chloros.

Знімки LATTICE — це стандартні файли формату `.tif`/`.tiff`, і Chloros завжди обробляє їх, починаючи з необроблених знімків. Повний перелік команд та інтерфейсу API наведено в [Довіднику CLI](../reference/cli-reference.md) та [Довіднику SDK](../reference/sdk-reference.md).

## Дві конфігурації датчиків

| Конфігурація | Датчик       | Фільтр                                | Що надає одна камера                                          |
| ------------- | ------------ | ------------------------------------- | ----------------------------------------------------------------- |
| **M3C**| Кольоровий (Bayer) | потрійний смуговий фільтр                |**Три відкалібровані діапазони за одну експозицію**                 |
| **M3M**| Монохромна   | Один вузькосмуговий інтерференційний фільтр |**Один калібрований діапазон**; для отримання індексів об’єднуйте кілька камер M3M |

Оскільки камера M3M є монохромною за одним фільтром, кожен діапазон отримує власну експозицію. Камера M3C охоплює всі три свої діапазони за одну експозицію сенсора.

## Рядки моделей та іменування

Кожна камера зберігає свою ідентифікацію у GenICam `DeviceUserID` у вигляді рядка моделі:

```
<sensor>-<lens>-F<filter>       e.g.  M3C-L41-FRGN,  M3M-L87-F450
```

Chloros відображає її з префіксом `LATT-` (наприклад, `LATT-M3M-L87-F450`). Цей самий рядок `LATT-…` записується у тег EXIF `Model` кожного експортованого файлу та використовується як назва вихідної папки камери в оброблених проєктах.

| Компонент | Значення                                                   | Значення                                                                                            |
| --------- | -------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| Датчик    | `M3C` / `M3M`                                            | Кольоровий (Bayer) / монохромний                                                                          |
| Об&#x27;єктив      | `L41` / `L87`                                            | Це число позначає **горизонтальний кут огляду у градусах**: L41 = вузький (41°), L87 = широкий (87°)    |
| Фільтр    | `FRGB` / `FRGN` / `FOCN` / `FNGB` (M3C) або `F<nm>` (M3M) | Див. [Фільтри та спектральні діапазони](https://mapir.gitbook.io/lattice-camera/hardware/filters-and-bands) |

Рядок моделі визначає всі подальші дії: Chloros визначає профіль датчика, розкладку діапазонів та заводську калібровку на основі `DeviceUserID` + `DeviceSerialNumber`. Налаштування для кожної камери не потрібні — див. [Підключення камер](connecting.md).

## Фільтри та спектральні діапазони

Центри діапазонів, ширина на піввищі (FWHM) та повний каталог M3M із 23 позиціями є технічними характеристиками продукту, тому вони наведені в посібнику з експлуатації обладнання: [**Фільтри та спектральні діапазони**](https://mapir.gitbook.io/lattice-camera/hardware/filters-and-bands).

Що важливо з точки зору програмного забезпечення: код фільтра в рядку моделі визначає, які продукти може створювати Chloros. Камери з RGB-фільтрами (`FRGB`) видають лише продукти з дебейєрингом та попереднім переглядом — величини випромінювання та відбиття для кожної смуги не мають значення для широкосмугового датчика, тому Chloros пропускає їх і вказує на це. Кожен інший фільтр забезпечує повний ланцюжок: випромінювання → відбиття → індекс.

## Короткий огляд радіометричної калібрування

Кожна камера LATTICE індивідуально калібрується на заводі за ланцюгом, простежуваним до NIST, і постачається з індивідуальним сертифікатом. Що саме охоплює калібрування, як воно вимірюється та яку точність можна вказати, описано в посібнику з експлуатації обладнання: [**Заводська радіометрична калібрування**](https://mapir.gitbook.io/lattice-camera/calibration/factory-radiometric-calibration).

Що стосується програмного забезпечення, важливо, щоб Chloros визначав правильну калібровку під час підключення камери та фіксував застосовані коефіцієнти в кожному експорті — див. [Підключення камер](connecting.md).
