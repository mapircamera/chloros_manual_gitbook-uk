# Камери LATTICE

LATTICE — це модульна мультиспектральна система камер від MAPIR, призначена для зйомки в сільському господарстві та науці. Кожна камера LATTICE побудована на базі датчика Sony IMX265 з глобальним затвором (**3,1 МП, розмір пікселя 3,45 мкм**) і підключається через Ethernet як пристрій**GigE Vision**.

Chloros 1.2.0 керує камерами LATTICE в режимі реального часу — виявлення, попередній перегляд, зйомка та синхронізовані масиви з декількох камер — з трьох інтерфейсів:

| Інтерфейс    | Де                                                          | Платформи                                                |
| ---------- | -------------------------------------------------------------- | -------------------------------------------------------- |
| Графічний інтерфейс | Вкладка **Камери** на бічній панелі Chloros                         | Windows 10/11 x64                                        |
| CLI        | Сімейство команд `chloros-cli lattice`                           | Windows 10/11 x64, Linux x86_64, Linux aarch64 (Jetson) |
| Python SDK | `chloros_sdk.connect_camera()` / `chloros_sdk.connect_array()` | Windows 10/11 x64, Linux x86\_64, Linux aarch64 (Jetson) |

> **Шукаєте обладнання?**Інформація про модулі камер, об&#x27;єктиви, фільтри та діапазони, рамки та кріплення, кабелі, PoE та проводку тригера наведена в [**посібнику користувача LATTICE**](https://mapir.gitbook.io/lattice-camera). У цьому розділі розглядається керування камерами з Chloros.

Знімки LATTICE — це стандартні файли формату `.tif`/`.tiff`, і Chloros завжди обробляє їх, починаючи з необроблених знімків. Див. [Довідник CLI](../reference/cli-reference.md) та [Довідник SDK](../reference/sdk-reference.md) для ознайомлення з повним переліком команд та інтерфейсом API.

## Дві конфігурації датчиків

| Конфігурація | Датчик       | Фільтр                                | Що надає одна камера                                          |
| ------------- | ------------ | ------------------------------------- | ----------------------------------------------------------------- |
| **M3C**| Кольоровий (Bayer) | потрійний смуговий фільтр                |**Три відкалібровані діапазони за одну експозицію**                 |
| **M3M**| Монохромний   | одинарний вузькосмуговий інтерференційний фільтр |**Один відкалібрований діапазон**; для отримання індексів об’єднуйте кілька камер M3M |

Оскільки камера M3M є монохромною за єдиним фільтром, кожна смуга отримує власну експозицію. Камера M3C охоплює всі три свої смуги за одну експозицію сенсора.

## Ряди моделей та іменування

Кожна камера зберігає свою ідентифікацію у GenICam `DeviceUserID` у вигляді рядка моделі:

```
<sensor>-<lens>-F<filter>       e.g.  M3C-L41-FRGN,  M3M-L87-F450
```

Chloros відображає його з префіксом `LATT-` (наприклад, `LATT-M3M-L87-F450`). Цей самий рядок `LATT-…` записується в тег EXIF `Model` під час кожного експорту та використовується як ім’я вихідної папки камери в оброблених проєктах.

| Компонент | Значення                                                   | Значення                                                                                            |
| --------- | -------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| Матриця    | `M3C` / `M3M`                                            | Кольорова матриця Байєра / монохромна                                                                          |
| Об&#x27;єктив    | `L41` / `L87`                                            | Цифра позначає **горизонтальний кут огляду в градусах**: L41 = вузький (41°), L87 = широкий (87°)    |
| Фільтр    | `FRGB` / `FRGN` / `FOCN` / `FNGB` (M3C) або `F<nm>` (M3M) | Див. [Фільтри та спектральні діапазони](https://mapir.gitbook.io/lattice-camera/hardware/filters-and-bands) |

Рядок моделі визначає все подальше: Chloros визначає профіль датчика, розклад смуг та заводську калібровку на основі `DeviceUserID` + `DeviceSerialNumber`. Налаштування для кожної камери не потрібні — див. [Підключення камер](connecting.md).

## Фільтри та діапазони

Центри діапазонів, межі FWHM та повний каталог M3M із 23 позиціями є технічними характеристиками продукту, тому вони наведені в посібнику з обладнання: [**Фільтри та спектральні діапазони**](https://mapir.gitbook.io/lattice-camera/hardware/filters-and-bands).

Що важливо з точки зору програмного забезпечення: код фільтра в рядку моделі визначає, які продукти Chloros можна створити. Камери з фільтром RGB (`FRGB`) видають лише продукти з дебейєризацією та попереднім переглядом — значення яскравості та відбиття для окремих діапазонів не мають сенсу для широкосмугового датчика, тому Chloros пропускає їх і повідомляє про це. Кожен інший фільтр забезпечує повний ланцюжок «яскравість → відбивна здатність → індекс».

## Короткий огляд радіометричної калібрування

Кожна камера LATTICE індивідуально калібрується на заводі за ланцюгом, простежуваним до NIST, і постачається з індивідуальним сертифікатом. Що саме охоплює калібрування, як воно вимірюється та яку точність можна вказати, описано в посібнику з експлуатації обладнання: [**Заводська радіометрична калібрування**](https://mapir.gitbook.io/lattice-camera/calibration/factory-radiometric-calibration).

Що стосується програмного забезпечення, важливо, що Chloros визначає правильну калібровку під час підключення камери та фіксує застосовані коефіцієнти у кожному експорті — див. [Підключення камер](connecting.md).
