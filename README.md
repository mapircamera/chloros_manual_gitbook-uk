# Початок роботи

<div data-full-width="false"><figure><img src=".gitbook/assets/chloros_logo_transparent.png" alt=""><figcaption></figcaption></figure></div>Chloros — це програмне забезпечення від [MAPIR](https://www.mapir.camera), призначена для обробки мультиспектральних зображень, управління апаратним забезпеченням MAPIR у режимі реального часу та запису даних з датчиків. Chloros 1.2.0 підтримує всю лінійку продуктів MAPIR:

* **Камери Survey3** — обробка знімків у форматі RAW+JPG з отриманням каліброваних карт відбивної здатності та індексів рослинності. Див. [Підтримувані камери](supported-cameras.md).
* **Камери LATTICE** — підключення мультиспектральних камерних модулів GigE у режимі реального часу, поодинці або у вигляді синхронізованих масивів з декількох камер: попередній перегляд, зйомка та обробка з отриманням каліброваних продуктів випромінювання та відбиття. Див. [розділ LATTICE](lattice/README.md).
* **Світлові датчики DAQ** — спектральні датчики DAQ-U (USB), DAQ-M (Bluetooth) та DAQ-E (Ethernet): відкалібровані спектри в режимі реального часу, записи `.daq` та освітлення, що падає зверху, для обробки даних відбиття. Див. [розділ «DAQ»](daq/README.md).

{% hint style="success" %}
**Нові можливості у версії Chloros 1.2.0**: управління камерами та масивами LATTICE в режимі реального часу, інтеграція світлових датчиків DAQ, режими зйомки та реєстратори, повний конвеєр радіометричної обробки LATTICE, автоматизація проектів з CLI/SDK та багато іншого. Ознайомтеся зі списком нововведень нижче та [завантажте](download.md) журнал змін.
{% endhint %}

## Що нового в Chloros 1.2.0

* **Керування камерами в режимі реального часу — нова вкладка «Камери».** Підключайте камери LATTICE по одній або у вигляді синхронізованих масивів з декількох камер (синхронізація часу PTP, зйомка з апаратним тригером) із накладенням попереднього перегляду в режимі реального часу, гістограмами для окремих діапазонів, інтелектуальною автоматичною експозицією, калькулятором індексу в режимі реального часу та оновленнями прошивки камер безпосередньо в додатку.
* **Світлові датчики — нова вкладка «Світлові датчики».** Підключайте датчики DAQ-U (USB), DAQ-M (Bluetooth) та DAQ-E (Ethernet); переглядайте відкалібровані спектри в режимі реального часу (Вт/м²/нм), записуйте файли `.daq` у свій проєкт, обирайте профілі корекції капа та оновлюйте прошивку DAQ-E через мережу.
* **Режими зйомки та реєстратори.** Одноразова / безперервна / інтервальна зйомка, а також режим «Найшвидша зйомка» (лише у форматі RAW); вибір для кожного проєкту, які камери та типи експорту створює функція «Зняти все»; масивні реєстратори для індексного відео моніторингового рівня та серій RAW-кадрів аналітичного рівня з офлайн-збіркою відео.
* **Конвеєр обробки LATTICE.** Імпортуйте папки з записами LATTICE та розбивайте кожен необроблений кадр на продукти: з дебейєрингом, попередній перегляд, яскравість у форматі float32 (Вт/м²/стр/нм) та коефіцієнт відбиття з можливістю вмикання/вимикання для кожного продукту окремо. Значення відбиття можуть походити від калібрувальної мітки в кадрі або від даних DAQ; під час експорту застосовується вирівнювання масиву; відсутні заводські калібрувальні дані завантажуються автоматично за серійним номером камери.
* **Проєкти запам’ятовують апаратне забезпечення.** Підключені камери та датчики освітленості зберігаються разом із проєктом (`cameras.json` / `sensors.json`) і підключаються знову зі збереженими налаштуваннями при повторному відкритті проєкту. Див. [Графічний інтерфейс: Проєкти](projects.md).
* **Оновлення переглядача зображень.** Зчитування пікселів/індексу курсором із правильним масштабуванням відбивної здатності для кожного файлу, гістограми шарів, повзунок бінінгу GSD, режими сітки «На тригер» / «На камеру», перегляд продуктів LATTICE та експорт індексу/LUT у пісочницю на диск.
* **CLI та SDK, значно розширені.** Нові сімейства команд `lattice`, `daq pool-*`, `project` та `time-sync`; нові параметри `process` (`--input-level` — перемикачі для окремих продуктів, `--reflectance-source` — прапори вирівнювання масивів); дескриптори smart-connect для SDK (`connect_camera` / `connect_array` / `connect_daq_sensor`), які автоматично запускають бекенд; `open_project()` автоматизація; колесо SDK входить до складу інсталяторів та опубліковано на PyPI як `chloros-sdk`.
* **Чітка семантика помилок.** Запуск `chloros-cli process`, який запитував продукти, але не записав жодного, тепер явно завершується з помилкою та повертає ненульовий код; успішні запуски повідомляють, скільки образів продуктів було записано.
* **Новий формат виводу.** Продукти зберігаються у папках `<project>/<camera>/<format>/<Product>_Images/` і зберігають ім’я вихідного файлу — саме папка, а не суфікс імені файлу, ідентифікує продукт. Див. [Формати вихідних зображень](output-image-formats.md).
* **Більше вхідних даних, планів та мов.** Підтримка вхідних даних `.dng`; повне наповнення всіх 38 мов інтерфейсу; апаратні обмеження для кожного плану з безкоштовним (без входу в систему) використанням до 4 камер та 2 датчиків освітлення.
* **Надійність.** Функція «Зупинити обробку» коректно завершує роботу, надаючи вичерпний звіт про виконання; у проєктах із кількома камерами експортуються дані з кожної камери; оновлення інсталятора більше не призводять до виходу з системи.***

Chloros доступний у 3 варіантах інтерфейсу:

## Chloros: Настільний додаток із графічним інтерфейсом

Автономне окреме вікно з усіма функціями, включаючи вкладки «Камери» та «Датчики освітлення» у режимі реального часу. _Тільки для Windows._

## [Chloros CLI: Інтерфейс командного рядка](CLI.md)

Пакетна обробка з командного рядка та команди в режимі реального часу `lattice`, `daq pool-*`, `project` та `time-sync`. Ідеально підходить для автоматизації, створення скриптів та роботи без графічного інтерфейсу. Доступно на **Windows, Linux amd64 та Linux arm64 (NVIDIA Jetson)**. _Для доступу до CLI необхідний платний тарифний план Chloros+._

## [Chloros API: Python SDK](api-python-sdk.md)

Програмний інтерфейс Python для автоматизації та налаштування робочих процесів: обробка повного конвеєра, сеанси роботи з камерами/масивами в режимі реального часу, сеанси роботи з датчиками DAQ та автоматизація збережених проєктів. Встановлюється разом із пакетом для настільних ПК/CLI, а також опубліковано як `pip install chloros-sdk`. _Для доступу до API необхідний платний тарифний план Chloros+._

## Почніть роботу за три кроки

1. **Встановити** — завантажте та запустіть інсталятор для вашої платформи. Див. [Завантажити](download.md).
2. **Увійдіть у систему (не обов’язково для графічного інтерфейсу)** — графічний інтерфейс обробляє зображення безкоштовно без облікового запису. [Chloros+ вхід у систему](chloros+-login.md) надає доступ до паралельної обробки, прискорення на GPU, більші обмеження на кількість пристроїв та доступ до CLI/SDK.
3. **Створіть свій перший проєкт** — відкрийте Chloros, створіть [Новий проєкт](projects.md), [додайте свої зображення](processing-images-gui/adding-files-to-a-project.md) та [розпочніть обробку](processing-images-gui/starting-the-processing.md). Щоб керувати реальним обладнанням, відкрийте вкладку «Камери» або «Світлові датчики» — див. [GUI: Навігація](navigation.md).***

## Chloros+

Хоча Chloros є безкоштовним для більшості завдань, вам можуть знадобитися додаткові можливості. Саме в цьому випадку вам стане в нагоді платна ліцензія на Chloros+. З ліцензією Chloros+ ви зможете отримати доступ до таких нових функцій:

* **Багатопотокова обробка**: значно прискорює обробку зображень у великих проєктах завдяки одночасній обробці зображень у конвеєрі.
* **Прискорення за допомогою графічного процесора (CUDA)**: скористайтеся перевагами сучасних графічних процесорів з більшим об’ємом пам’яті для подальшого прискорення конвеєра обробки зображень. Для досягнення найкращих результатів ми рекомендуємо 4 ГБ або більше відеопам’яті (VRAM).
* **Chloros+**[**CLI**](CLI.md)**Доступ**: запустіть Chloros+ з командного рядка для автоматизації та інтеграції у власне програмне забезпечення. Доступно на будь-якому платному тарифному плані; застосовується на стороні сервера.
* **Chloros+**[**API**](api-python-sdk.md)**Доступ:** запустіть Chloros+ з Python для програмного керування, що забезпечує безперебійну інтеграцію з вашими дослідницькими конвеєрами, робочими процесами аналізу даних та власними додатками. Доступно на будь-якому платному тарифі; застосовується на стороні сервера.
* **Більші апаратні обмеження**: підключайте одночасно більше камер та світлових датчиків. Без входу в систему графічний інтерфейс підтримує підключення до 4 камер та 2 світлових датчиків DAQ; платні тарифні плани збільшують обидва обмеження:

| Тариф | Камери | Світлові датчики DAQ |
| --- | --- | --- |
| Iron (безкоштовний, без входу) | 4 | 2 |
| Copper / Bronze | 6 | 3 |
| Silver | 10 | 6 |
| Gold | 20 | 12 |

* **Використання декількох пристроїв**: кожна ліцензія Chloros+ дозволяє зареєструвати 2 і більше пристроїв. Використовуйте свій обліковий запис MAPIR Cloud для управління зареєстрованими пристроями. Додайте підтримку для більшої кількості пристроїв, оновивши свою ліцензію Chloros+.
* **Удосконалений метод дебейєрингу з урахуванням текстури:** високоякісний дебейєринг з урахуванням контурів у поєднанні з моделлю шумозаглушення на основі штучного інтелекту та машинного навчання, що усуває майже весь шум, пов’язаний з дебейєрингом.
* **Налаштовані формули мультиспектральних індексів:** введіть власні мультиспектральні індекси в растрові калькулятори Chloros як для обробки, так і для пісочниці перегляду зображень.
* **Linux та периферійні обчислення:** запускайте Chloros на платформах Linux x86_64 та ARM64, включаючи NVIDIA Jetson, для польової та периферійної обробки. Див. [Огляд Linux](linux/linux-overview.md).
