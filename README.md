# Початок роботи

<div data-full-width="false"><figure><img src=".gitbook/assets/chloros_logo_transparent.png" alt=""><figcaption></figcaption></figure></div>Chloros — це програмне забезпечення від [MAPIR](https://www.mapir.camera) для обробки зображень та інших даних датчиків.

***{% hint style="success" %}**Що нового в Chloros 1.1.0**: Вбудована підтримка Linux (amd64 та arm64), обчислення на периферії NVIDIA Jetson, динамічна адаптація обчислень, 4-потоковий конвеєр обробки, нові команди та опції CLI. Повний список змін дивіться у розділі [Завантажити](download.md).
{% endhint %}

Chloros доступний у 3 режимах роботи:

## Chloros: Настільна програма з графічним інтерфейсом

Автономне окреме вікно з усіма функціями. _Тільки для Windows._

## [Chloros CLI: Інтерфейс командного рядка](CLI.md)

Пакетна обробка з командного рядка. Ідеально підходить для автоматизації, створення скриптів та роботи без графічного інтерфейсу. Доступно на **Windows, Linux amd64 та Linux arm64 (NVIDIA Jetson)**. _Для доступу до CLI потрібна ліцензія Chloros+._

## [Chloros API: Python SDK](api-python-sdk.md)

Програмний інтерфейс Python для автоматизації та налаштування робочих процесів. Ідеально підходить для дослідницьких конвеєрів, інтеграції з існуючими додатками Python та створення власних інструментів. Доступний на **усіх платформах** через `pip install chloros-sdk`. _Для доступу до API потрібна ліцензія Chloros+._***

## Підтримувані платформи

| Платформа | GUI | CLI | Python SDK |
| --- | --- | --- | --- |
| **Windows 10/11** | Так | Так | Так |
| **Linux amd64 (x86_64)** | Ні | Так | Так |
| **Linux arm64 (NVIDIA Jetson)** | Ні | Так | Так |

Інструкції з інсталяції Linux див. у розділі [Linux та Edge Computing](linux/linux-overview.md).

## Chloros+

Хоча Chloros є безкоштовним для більшості завдань, вам може знадобитися більше можливостей. Саме в цьому випадку вам стане в нагоді платна ліцензія на Chloros+. З ліцензією Chloros+ ви зможете отримати доступ до таких нових функцій:

* **Багатопотокова обробка**: значно пришвидшіть обробку зображень у великих проектах завдяки одночасній обробці зображень у конвеєрі.
* **Прискорення за допомогою графічного процесора (CUDA)**: скористайтеся сучасними можливостями графічних процесорів з більшим об&#x27;ємом пам&#x27;яті, щоб ще більше прискорити конвеєр обробки зображень. Для найкращих результатів ми рекомендуємо 4 ГБ або більше відеопам&#x27;яті.
* **Chloros+**[**CLI**](CLI.md)**Доступ**: запускайте Chloros+ з командного рядка для автоматизації та інтеграції у ваше власне програмне забезпечення.
* **Chloros+**[**API**](api-python-sdk.md)**Доступ:** запустіть Chloros+ з Python для програмного керування, що забезпечує безперебійну інтеграцію з вашими дослідницькими конвеєрами, робочими процесами аналізу даних та власними додатками.
* **Використання на декількох пристроях**: кожна ліцензія Chloros+ дозволяє зареєструвати 2 і більше пристроїв. Використовуйте свій обліковий запис MAPIR Cloud для управління зареєстрованими пристроями. Додайте підтримку для більшої кількості пристроїв, оновивши свою ліцензію Chloros+.
* **Розширений метод дебайєрингу з урахуванням текстури:** високоякісний дебайєринг з урахуванням країв у поєднанні з моделлю шумозаглушення на основі AI/ML, що усуває майже весь шум дебайєрингу. 
* **Налаштовані формули мультиспектральних індексів:** введіть налаштовані мультиспектральні індекси в растрові калькулятори Chloros як для обробки, так і для пісочниці перегляду зображень.
* **Linux та периферійні обчислення:** запускайте Chloros на платформах Linux x86\_64 та ARM64, включаючи NVIDIA Jetson, для польової та периферійної обробки. Див. [Огляд Linux](linux/linux-overview.md).
