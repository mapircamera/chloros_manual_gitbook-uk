Після входу у систему будуть показані дані вашого облікового запису:

<figure><img src=".gitbook/assets/user_account.JPG" alt="" width="375"><figcaption></figcaption></figure>## Вхід у CLI

Увійдіть за допомогою своїх облікових даних Chloros+, щоб увімкнути обробку CLI. У Linux (без графічного інтерфейсу) це єдиний спосіб активувати вашу ліцензію.

**Синтаксис:**

```bash
chloros-cli login <email> <password>
```

{% hint style="info" %}
**Користувачі SDK**: Python SDK також надає програмний метод `logout()` для очищення кешованих облікових даних. Детальніше див. [документацію Python SDK](api-python-sdk.md#logout).
{% endhint %}

**Приклад:**

```powershell
chloros-cli login user@example.com 'MyP@ssw0rd123'
```

{% hint style="warning" %}
**Спеціальні символи**: Використовуйте одинарні лапки навколо паролів, що містять такі символи, як `$`, `!` або пробіли.
{% endhint %}

**Вихідні дані:**

<figure><img src=".gitbook/assets/cli login_w.JPG" alt=""><figcaption></figcaption></figure>### Зберігання облікових даних

Облікові дані, що зберігаються у кеші, розміщуються у специфічному для платформи місці:

| Платформа | Шлях до кешу облікових даних |
| --- | --- |
| **Windows** | `%APPDATA%\Chloros\cache\` |
| **Linux** | `~/.cache/chloros/` |

### Термін дії плану

Термін дії плану в графічному інтерфейсі користувача показує, коли ваша ліцензія втратить чинність. Для щомісячних передплат термін дії закінчується в кінці місяця. Для річних передплат — через рік після початку передплати. Для перевірки ліцензії необхідне щомісячне підключення до Інтернету, з 30-денним пільговим періодом.

### Обмеження кількості пристроїв

Кожен план Chloros+ пропонує різну кількість зареєстрованих пристроїв. Кожен пристрій, на якому ви входите в систему за допомогою облікового запису Chloros+, буде враховуватися у вашій кількості зареєстрованих пристроїв. Ви можете перейменувати та видалити пристрій на сторінці вашого облікового запису MAPIR Cloud.
