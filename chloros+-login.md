# Вхід у Chloros+

## Вхід через графічний інтерфейс

Меню бічної панелі користувача <img src=".gitbook/assets/icon_user.JPG" alt="" data-size="line"> дозволяє увійти у свій обліковий запис Chloros+ та отримати доступ до додаткових функцій.

## Рівні тарифних планів

| Тарифний план | `plan_id` | Тип |
| --- | --- | --- |
| Iron | `0` | Безкоштовний |
| Copper | `1` | Платний (Chloros+) |
| Bronze | `2` | Платний (Chloros+) |
| Silver | `3` | Платний (Chloros+) |
| Золото | `4` | Платний (Chloros+) |

Дивіться [тарифи та ціни](https://cloud.mapir.camera/pricing), щоб дізнатися, що включає кожен платний тариф.

### Для доступу до CLI/SDK потрібен платний тариф

Для доступу до CLI та Python SDK необхідний **будь-який платний рівень Chloros+ (Copper або вище)**. Це забезпечується**на стороні сервера** — кожен запит CLI/SDK повинен містити як активну сесію, так і платний тарифний план:

| Статус HTTP | `error_code` | Значення | Виправлення |
| --- | --- | --- | --- |
| `401` | `AUTH_REQUIRED` | Не ввійшли на цьому пристрої | `chloros-cli login <email> <password>` |
| `403` | `PLAN_UPGRADE_REQUIRED` | Увійшли, але рівень тарифного плану занадто низький (безкоштовний рівень «Iron») | Перейдіть на будь-який платний тарифний план «Chloros+» |

`chloros-cli status` залишається доступним на безкоштовному рівні, тому ви завжди можете переглянути свій поточний тарифний план та причину відмови в доступі.

### Обмеження щодо підключеного обладнання для кожного тарифного плану

Кожен тарифний план обмежує кількість камер LATTICE та світлових датчиків DAQ, які можна одночасно підключити в режимі реального часу:

| Тариф | Камери LATTICE | Світлові датчики DAQ |
| --- | --- | --- |
| Iron (безкоштовний / без входу в систему) | 4 | 2 |
| Copper / Bronze | 6 | 3 |
| Silver | 10 | 6 |
| Gold | 20 | 12 |

## Вхід через CLI



Увійдіть за допомогою своїх облікових даних Chloros+, щоб увімкнути обробку через CLI. У Linux (без графічного інтерфейсу) це єдиний спосіб активувати вашу ліцензію.

**Синтаксис:**

```bash
chloros-cli login <email> <password>
```

{% hint style="info" %}
**Користувачі SDK**: Python SDK також надає програмний метод `logout()` для очищення кешованих облікових даних. Детальніше див. у [Довіднику SDK](reference/sdk-reference.md).
{% endhint %}

**Приклад:**

```powershell
chloros-cli login user@example.com 'MyP@ssw0rd123'
```

{% hint style="warning" %}
**Спеціальні символи**: Використовуйте одинарні лапки навколо паролів, що містять такі символи, як `$`, `!` або пробіли.
{% endhint %}

### Зберігання облікових даних

Кешовані облікові дані та конфігурація зберігаються у папці `.chloros` у вашому домашньому каталозі користувача на **усіх платформах**:

| Платформа | Шлях до кешу облікових даних |
| --- | --- |
| **Windows** | `%USERPROFILE%\.chloros\` |
| **Linux** | `~/.chloros/` |

Встановлення нової версії поверх існуючої зберігає ваші дані для входу в системі в Windows (інсталятор) та в Linux (папка `.deb`, включаючи `chloros-cli update`). Видалення Chloros — або видалення пакета для Linux — очищає кешовані дані входу, тому після нової інсталяції вам доведеться увійти знову.

### Закінчення терміну дії плану та пільговий період для роботи в автономному режимі

Термін дії плану, що відображається в графічному інтерфейсі, показує, коли ваша ліцензія втратить чинність. Для щомісячних передплат термін дії закінчується наприкінці місяця; для річних передплат — через рік після початку передплати.

Chloros перевіряє вашу ліцензію в режимі онлайн, але робота в автономному режимі підтримується протягом пільгового періоду:

* Результати успішної перевірки на сервері зберігаються в кеші протягом **5 хвилин**, тому під час звичайного використання кількість запитів на перевірку ліцензії є дуже малою.
* Кеш підписаної ліцензії, прив’язаної до конкретного комп’ютера, забезпечує роботу в автономному режимі протягом триваліших періодів: **30 днів для щомісячних планів**та**до дати закінчення терміну дії вашої передплати (максимум 365 днів) для річних планів**.
* Після закінчення пільгового періоду тариф переходить на безкоштовний рівень «Iron» доти, доки пристрій не зможе хоча б раз підключитися до сервера ліцензій; доступ відновлюється після наступної успішної перевірки.

### Обмеження кількості пристроїв

Кожен тарифний план «Chloros+» передбачає різну кількість зареєстрованих пристроїв. Кожен пристрій, на якому ви входите в обліковий запис «Chloros+», враховується у вашій кількості зареєстрованих пристроїв. Ви можете перейменувати та видалити пристрій на сторінці вашого облікового запису в хмарному сервісі MAPIR.

Вихід із системи на пристрої надійно звільняє його слот, а вже зареєстрований пристрій завжди може знову увійти в систему, навіть якщо обліковий запис досяг ліміту пристроїв.
