## Рівні тарифних планів

| Тарифний план | `plan_id` | Тип |
| --- | --- | --- |
| Залізо | `0` | Безкоштовний |
| Мідь | `1` | Платний (Chloros+) |
| Bronze | `2` | Платний (Chloros+) |
| Срібло | `3` | Платний (Chloros+) |
| Золотий | `4` | Платний (Chloros+) |

Дивіться [плани та ціни](https://cloud.mapir.camera/pricing), щоб дізнатися, що включає кожен платний рівень.

### Для доступу до CLI / SDK необхідний платний рівень

Для доступу до CLI, Python та SDK необхідний **будь-який платний тариф Chloros+ (Copper або вище)**. Це забезпечується**на стороні сервера** — кожен запит CLI/SDK повинен містити як активну сесію, так і платний тарифний план:

| Статус HTTP | `error_code` | Значення | Виправлення |
| --- | --- | --- | --- |
| `401` | `AUTH_REQUIRED` | Не ввійшли на цьому комп’ютері | `chloros-cli login <email> <password>` |
| `403` | `PLAN_UPGRADE_REQUIRED` | Увійшли в систему, але рівень тарифного плану занадто низький (безкоштовний рівень «Iron») | Перейдіть на будь-який платний тарифний план Chloros+ |

`chloros-cli status` залишається доступним на безкоштовному тарифі, тому ви завжди можете переглянути свій поточний тарифний план та причину відмови в доступі.

### Обмеження щодо підключеного обладнання для кожного тарифного плану

Кожен тарифний план обмежує кількість камер LATTICE та світлових датчиків DAQ, які можна підключити одночасно в режимі реального часу:

| Тариф | Камери LATTICE | Датчики освітлення DAQ |
| --- | --- | --- |
| Iron (безкоштовний / без входу в систему) | 4 | 2 |
| Copper / Bronze | 6 | 3 |
| Silver | 10 | 6 |
| Gold | 20 | 12 |

## Вхід у CLI

Увійдіть за допомогою своїх облікових даних Chloros+, щоб увімкнути обробку CLI. У Linux (без графічного інтерфейсу) це єдиний спосіб активувати вашу ліцензію.

**Синтаксис:**

```bash
chloros-cli login <email> <password>
```

{% hint style="info" %}
**Користувачі SDK**: Python SDK також надає програмний метод `logout()` для очищення кешованих облікових даних. Детальніше див. [Довідку щодо SDK](reference/sdk-reference.md).
{% endhint %}

**Приклад:**

```powershell
chloros-cli login user@example.com 'MyP@ssw0rd123'
```

{% hint style="warning" %}
**Спеціальні символи**: Використовуйте одинарні лапки для паролів, що містять символи, такі як `$`, `!` або пробіли.
{% endhint %}

### Зберігання облікових даних

Кешовані облікові дані та конфігурація зберігаються у папці `.chloros` у вашому домашньому каталозі користувача на **усіх платформах**:

| Платформа | Шлях до кешу облікових даних |
| --- | --- |
| **Windows** | `%USERPROFILE%\.chloros\` |
| **Linux** | `~/.chloros/` |

### Термін дії плану та пільговий період для роботи в автономному режимі

Термін дії плану, що відображається в графічному інтерфейсі, вказує, коли ваша ліцензія втратить чинність. Для щомісячних передплат термін дії закінчується наприкінці місяця; для річних передплат — через рік після початку передплати.

Chloros перевіряє вашу ліцензію в режимі онлайн, але робота в автономному режимі підтримується протягом пільгового періоду:

* Результати успішних перевірок на сервері зберігаються в кеші протягом **5 хвилин**, тому під час звичайного використання кількість запитів на ліцензію є дуже малою.
* Кеш підписаних ліцензій, прив’язаних до конкретного комп’ютера, забезпечує більш тривалий офлайн-режим: **30 днів для щомісячних планів**та**до дати закінчення терміну дії вашої передплати (максимум 365 днів) для річних планів**.
* Після закінчення пільгового періоду тариф переходить на безкоштовний рівень «Iron» доти, доки комп’ютер не зможе хоча б раз підключитися до сервера ліцензій; доступ відновлюється після наступної успішної перевірки.

### Обмеження щодо пристроїв

Кожен тариф Chloros+ передбачає різну кількість зареєстрованих пристроїв. Кожен пристрій, на якому ви входите в систему за допомогою облікового запису Chloros+, враховується у кількості зареєстрованих пристроїв. Ви можете перейменувати та видалити пристрій на сторінці свого облікового запису MAPIR Cloud.
