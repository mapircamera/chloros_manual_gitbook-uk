# Маркери на карті

На вкладці «Карта» ваші зображення відображаються на інтерактивній 2D-карті на основі їх GPS-координат. Це дає географічний огляд вашої сесії зйомки та допомагає візуалізувати просторове покриття. Це також корисно під час першого імпортування зображень, щоб швидко видалити ті, які не потрібно обробляти.

## Доступ до вкладки «Карта»

1. Відкрийте або створіть проект у Chloros.
2. Імпортуйте зображення, що містять метадані GPS.
3. Клацніть вкладку **«Карта»** <img src="../.gitbook/assets/image (3).png" alt="" data-size="line"> у лівій бічній панелі
4. На карті будуть відображатися маркери у GPS-координатах кожного зображення

{% hint style=&quot;info&quot; %}
**Необхідний GPS**: на карті будуть відображатися тільки зображення з вбудованими GPS-координатами в метаданих EXIF. Переконайтеся, що під час зйомки на вашій камері увімкнено GPS.
{% endhint %}

## Маркери зображень

Кожне зображення з даними GPS представлене маркером на карті:

### Відображення маркерів

* Маркери вказують точні GPS-координати, де було зроблено кожне зображення.
* При зменшенні масштабу кластеризовані маркери можуть групуватися.
* Збільште масштаб, щоб побачити окремі місця розташування зображень.

{% hint style=&quot;success&quot; %}
СУПЕРЗУМ: Коли ви досягаєте максимального рівня збільшення від постачальника карткових фрагментів, фрагмент збільшується при подальшому збільшенні, що дозволяє побачити маркери, які знаходяться близько один до одного.
{% endhint %}

### Попередній перегляд при наведенні курсору

* **Наведіть курсор миші** на будь-який маркер, щоб побачити попередній перегляд цього зображення.
* Це дозволяє швидко ідентифікувати зображення, не залишаючи вікна карти.
* Корисно для пошуку конкретних зображень у великій сесії знімків.

## Постачальники карт

{% hint style=&quot;success&quot; %}
**Автоматичний вибір**: Chloros автоматично вибирає службу карт, яка забезпечує найкращий рівень масштабування для вашого поточного місцезнаходження на карті. За бажанням ви можете вручну перемикатися між постачальниками.
{% endhint %}

Вкладка «Карта» підтримує двох постачальників карт для зображень фонової карти:

### Google Maps

* Стандартні супутникові та картографічні зображення від Google.
* Найкраще підходить для загального покриття по всьому світу.

### ESRI

* Супутникові та аерофотознімки від ESRI ArcGIS.
* Часто надає зображення з вищою роздільною здатністю в певних регіонах.

Ви можете вибрати тип шару карти (зліва направо):

## Навігація по карті

### Елементи керування масштабом

* **Збільшення/зменшення**: використовуйте коліщатко миші або кнопки масштабування
* **Повний екран**: перехід у повноекранний режим

### Елементи керування переміщенням

* **Переміщення**: клацніть і перетягніть, щоб переміститися по карті***

## Приклади використання

### Візуалізація траєкторії польоту

* Перегляд зони покриття сеансів зйомки дроном
* Виявлення прогалин у покритті зображеннями
* Перевірка виконання траєкторії польоту

### Перегляд наземних досліджень

* Перегляд просторового розподілу наземних знімків
* Визначення розташування калібрувальних цільових зображень відносно області дослідження
* Планування додаткових місць зйомки

### Контроль якості

* Швидко визначайте зображення, зняті в несподіваних місцях
* Перевіряйте точність GPS у всьому наборі даних
* Зіставляйте місця зйомки із польовими нотатками

## Усунення несправностей

### Не відображаються маркери

**Можливі причини:**

* Зображення не містять метаданих GPS
* Під час зйомки GPS на камері було вимкнено
* Дані EXIF були видалені зовнішнім програмним забезпеченням

**Рішення**: Перевірте, чи увімкнено GPS на вашій камері, і повторно імпортуйте оригінальні файли.

### Маркери в неправильному місці

**Можливі причини:**

* GPS камери мав поганий супутниковий сигнал.
* GPS змістився під час зйомки.

**Рішення**: Зазвичай це проблема часу зйомки; розгляньте можливість використання PPK/RTK GPS для точних застосувань.
