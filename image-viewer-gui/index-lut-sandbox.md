# Пісочниця для індексів/LUT

Пісочниця для індексів/LUT — це інтерактивне робоче середовище в програмі перегляду зображень Chloros, яке дозволяє експериментувати з обчисленням мультиспектральних індексів та візуалізацією кольорів у режимі реального часу. Цей потужний інструмент допомагає тестувати різні індекси, уточнювати діапазони значень та створювати готові до публікації візуалізації без повторної обробки всього набору даних.

## Що таке «Індекс/LUT Sandbox»?

### Призначення

«Sandbox» надає:

* **Розрахунок індексу в режимі реального часу** — миттєве застосування будь-якого індексу рослинності
* **Інтерактивне налаштування LUT** — точне налаштування колірних градієнтів та діапазонів
* **Оптимізація робочого процесу** — визначення найкращих налаштувань перед пакетною обробкою

### Sandbox проти обробки проектів

**Index/LUT Sandbox (інтерактивний):**

* Одне зображення за раз
* Миттєвий зворотний зв&#x27;язок
* Експериментальний та ітеративний
* Відсутність постійних змін у файлах
* Ідеально підходить для дослідження та тестування

**Обробка проектів (пакетна):**

* Весь набір даних одночасно
* Попередньо налаштовані параметри
* Постійні вихідні файли
* Часомісткий процес
* Найкраще підходить, коли налаштування остаточно затверджені

{% hint style="success" %}
**Найкращий робочий процес**: Використовуйте Sandbox для експериментів та пошуку оптимальних налаштувань індексу та LUT, а потім застосуйте ці налаштування під час обробки проекту для всього набору даних.
{% endhint %}

## Робота з пісочницею індексу/LUT

### Розуміння попередньо обчислених індексів

У Chloros індекси можна застосовувати під час обробки проекту. Щоб визначити, які налаштування індексу та LUT ви хочете застосувати до експорту, найпростіше скористатися пісочницею перегляду зображень.

Пісочниця дозволяє:

* **Застосовувати нові індекси та колірні градієнти (LUT)** для візуалізації даних
* **Налаштовувати параметри візуалізації** в інтерактивному режимі
* **Переглядати** вже обчислені індексні зображення
* **Перевіряти** значення пікселів на всіх рівнях масштабування

### Відкриття пісочниці

Доступ до пісочниці індексів/LUT здійснюється у вкладці бічної панелі **Переглядач зображень** <img src="../.gitbook/assets/icon_image-viewer.JPG" alt="" data-size="line"> :

1. Клацніть на зображення в сітці зображень файлового браузера, воно відкриється на вкладці **Image Viewer**<img src="../.gitbook/assets/icon_image-viewer.JPG" alt="" data-size="line"> 2. Клацніть на вкладці**Image Viewer** <img src="../.gitbook/assets/icon_image-viewer.JPG" alt="" data-size="line"> , щоб відкрити ліву висувну бічну панель, якщо вона ще не відкрита

### Вибір зображення для застосування індексу/LUT

Для роботи з індексом у <img src="../.gitbook/assets/icon_image-viewer.JPG" alt="" data-size="line"> :

1. **Відкрийте зображення** з головної сітки зображень, клацнувши на ньому
2. Відкриється вкладка **Image Viewer** <img src="../.gitbook/assets/icon_image-viewer.JPG" alt="" data-size="line"> відкриється
3. Натисніть на **випадаюче меню «Шар»** (у правому верхньому куті переглядача)
4. Виберіть шар із випадаючого меню:
   * RAW (Відбиття)

### Застосування індексу до зображення

Коли зображення відображається на весь екран і бічна панель **Переглядача зображень** <img src="../.gitbook/assets/icon_image-viewer.JPG" alt="" data-size="line"> :

1. Поставте галочку у полі «Індекс» у верхній частині бічної панелі
2. Виберіть фільтр вашої камери з випадаючого меню ліворуч
3. Виберіть потрібну формулу індексу з випадаючого меню праворуч
4. Перетягніть кольорові кола каналів фільтра у відповідні місця у формулі індексу нижче
5. Після того, як формула стане дійсною, зображення оновиться і покаже значення індексу
6. Переміщайте курсор миші, щоб побачити значення у місці розташування курсора
7. Збільште масштаб, щоб побачити окремі пікселі та пов&#x27;язані з ними значення

Кожен індекс має певний діапазон значень та значення:

#### Приклад NDVI

```

Formula: (NIR - Red) / (NIR + Red)

For Survey3W RGN camera:
NIR = 850nm band
Red = 661nm band

Result range: -1.0 to +1.0
Typical vegetation: 0.4 to 0.9
Stressed vegetation: 0.2 to 0.4
Bare soil: 0.0 to 0.2
Water: -0.1 to 0.1
```

Повну документацію щодо формул індексів див. у розділі [Формули мультиспектральних індексів](../project-settings/multispectral-index-formulas.md).

## Робота з LUT (таблицями перегляду)

### Що таке LUT?

**Таблиця перегляду (LUT)** зіставляє числові значення індексів із кольорами для візуалізації:

* **Вхідні дані**: Значення пікселя індексу (наприклад, NDVI 0,65)
* **Вихідні дані**: Колір RGB (наприклад, яскраво-зелений)
* **Мета**: Полегшити розпізнавання та інтерпретацію візерунків**LUT у відтінках сірого проти кольорового LUT:**

* Відтінки сірого: Науковий та нейтральний, показує необроблені дані
* Кольоровий LUT: Інтуїтивний та ефектний, виділяє візерунки та відмінності

{% hint style="success" %}
**Можливості візуалізації**: Застосування кольорової LUT до індексного зображення у відтінках сірого значно полегшує ідентифікацію візерунків, аномалій та областей, що представляють інтерес, з першого погляду.
{% endhint %}

### Застосування LUT до індексного зображення

Коли у вас є індексне зображення, що показує

1. Натисніть кнопку <img src="../.gitbook/assets/image (1) (1).png" alt="" data-size="line"> кнопку «+Додати LUT»
2. Виберіть колірний градієнт
3. Налаштуйте мінімальну та максимальну точки обрізки
4. Налаштуйте режим обрізки
5. Поставте галочку у полі «Індекс» на бічній панелі вкладки **Переглядач зображень** <img src="../.gitbook/assets/icon_image-viewer.JPG" alt="" data-size="line"> , щоб застосувати LUT

### Вибір колірного градієнта

**Вибір градієнта:**

1. На панелі LUT знайдіть**кольорову смугу градієнта**

2. Наведіть курсор миші на неї, щоб переглянути доступні пресети градієнта
3. Виберіть бажаний градієнт
4. Зображення **одразу оновлюється** новими кольорами, коли встановлено прапорець «Індекс»

{% hint style="success" %}
**Рекомендації**: Для індексів рослинності, таких як NDVI, градієнт Red-Yellow-Green є найбільш інтуїтивним, оскільки він відповідає природним асоціаціям кольорів (зелений = здоровий, жовтий = помірний, червоний = стресовий).
{% endhint %}

### Налаштування колірних класів

**Елемент керування «Класи»**визначає, скільки дискретних колірних ступенів з’являється у вашому градієнті:**Варіанти кількості класів:*** **2–5 класів**: Дуже широкі категорії, чітко виражені зони
* **6–10 класів**: Збалансовані, добре підходять для класифікації
* **11–20 класів**: плавні градієнти, безперервний вигляд
* **20+ класів**: майже безперервний, максимальна плавність**Як налаштувати:**

1. На панелі LUT знайдіть**квадрати зразків кольорів під смугою градієнта**

2. Налаштуйте кількість класів, додаючи їх за допомогою кнопки «+»
3. Видаліть кількість класів, двічі клацнувши на кольоровому зразку
4. Градієнт оновлюється **в режимі реального часу** на зображенні**Вплив на візуалізацію:*** **Менше класів** (3-5): Створює чіткі зони, спрощена класифікація, легше розрізняти категорії
* **Середня кількість класів** (6-10): Збалансований підхід, добре підходить для більшості застосувань
* **Більше класів** (15–20): плавні переходи, детальні варіації, фотографічний вигляд**Коли використовувати:*** **Мало класів (3–5)**: презентаційні слайди, класифікаційні карти, прості звіти
* **Середня кількість класів (6–10)**: загальний аналіз, збалансована деталізація, стандартні звіти
* **Багато класів (15–20)**: Науковий аналіз, детальний огляд, результати публікаційної якості

### Точне налаштування діапазонів значень

**Регулятори діапазону значень**визначають, які значення індексу відповідають яким кольорам у вашому градієнті:**Регулятори діапазону на панелі LUT:*** **Мінімальне значення**: Нижня межа колірної шкали
* **Максимальне значення**: Верхня межа колірної шкали
* **Проміжні значення**: автоматично розподіляються між мінімальним і максимальним значеннями (на основі кількості класів)

#### Налаштування мінімальних/максимальних значень

**Щоб налаштувати діапазони значень:**

1. На панелі LUT знайдіть поля введення**Мінімальне значення**та**Максимальне значення**

2. Клацніть поле**Мінімальне значення**

3. Введіть бажане мінімальне значення (наприклад, `0.2`)
4. Натисніть **Enter** або клацніть поза полем
5. Повторіть для поля **Максимальне значення** (наприклад, `0.9`)
6. Візуалізація **оновлюється негайно**{% hint style="info" %}**Автоматичне масштабування**: Коли ви вперше застосовуєте LUT, Chloros автоматично встановлює мінімальне/максимальне значення відповідно до фактичного діапазону даних на зображенні. Потім ви можете звузити цей діапазон, щоб зосередитися на конкретних діапазонах значень, що вас цікавлять.
{% endhint %}

**Приклад налаштування діапазону NDVI:*** **Повний діапазон**: від `-1.0` до `1.0` (показати всі можливі значення)
* **З фокусом на рослинності**: від `0.2` до `0.9` (виключити голий ґрунт і воду)
* **Тільки здорова рослинність**: від `0.5` до `0.9` (виділити лише рослини з інтенсивним ростом)
* **Виявлення стресу**: від `0.2` до `0.5` (підкреслити проблемні ділянки)
* **Індивідуальний діапазон**: налаштуйте на основі спостережуваних значень пікселів**Навіщо налаштовувати діапазони?*** **Підвищити контраст** у зоні, що вас цікавить
* **Виключіть нерелевантні значення** (наприклад, водойми, голий ґрунт)
* **Уніфікуйте візуалізацію** для декількох зображень або дат
* **Підкресліть тонкі відмінності** у вузькому діапазоні значень

### Обрізання значень, що виходять за межі діапазону

Коли значення пікселів виходять за межі визначеного вами мінімального/максимального діапазону, ви можете контролювати їх відображення за допомогою **режимів обрізання**.

#### **Доступні варіанти режимів обрізки:**

#### 1. Мінімум і максимум

* Пікселі **нижче мінімуму**→ відображаються з використанням**першого кольору** у градієнті (наприклад, червоного)
* Пікселі **вище максимуму**→ відображаються з використанням**останнього кольору** у градієнті (наприклад, зелений)
* **Приклад використання**: підкреслення крайніх значень, відображення повного діапазону даних із насиченими кольорами на межі
* **Приклад**: значення NDVI нижче 0,2 відображаються червоним, значення вище 0,9 — зеленим

#### 2. Прозорий фон

* Пікселі **поза діапазоном**стають**повністю прозорими*** Тільки пікселі **в межах діапазону** показують колірний градієнт
* **Випадок використання**: накладення ГІС, виділення конкретних діапазонів значень, виділення тільки областей, що представляють інтерес
* **Приклад**: Показати кольором тільки NDVI 0,4–0,7, все інше прозоре

{% hint style="warning" %}
**Обмеження прозорості**: Прозорі пікселі будуть відображатися у вигляді кольору фону у переглядачі. При експорті під час обробки прозорість зберігається у форматі PNG, але не у форматі JPG.
{% endhint %}

#### 3. Індексний фон

* Пікселі **поза діапазоном**відображаються у**відтінках сірого** (показуючи необроблені значення індексу)
* Пікселі **в межах діапазону**показують**колірний градієнт*** **Приклад використання**: Тонке виділення, збереження контексту при акцентуванні на областях, що представляють інтерес
* **Приклад**: Виділення кольором стресованої рослинності (NDVI 0,3–0,5) при одночасному відображенні здорових ділянок у сірому кольорі

#### 4. Оригінальний фон

* Пікселі **поза діапазоном**відображають**оригінальне мультиспектральне зображення*** Пікселі **в межах діапазону**показують**колірний градієнт*** **Випадок використання**: Найінтуїтивніший — поєднує природний контекст зображення з аналітичним кольоровим накладенням
* **Приклад**: Перегляд фактичного вигляду поля/посіву з накладеними кольоровими позначками зон стресу

### Вибір правильного режиму обрізки

| Режим обрізки              | Найкраще підходить для                                   | Стиль візуалізації          |
| -------------------------- | ------------------------------------------ | ---------------------------- |
| **Мінімальне та максимальне**    | Повне відображення даних, науковий аналіз     | Усі пікселі забарвлені           |
| **Прозорий фон** | Накладення ГІС, виділення конкретних діапазонів    | Колір у діапазоні, поза ним — порожньо |
| **Індексний фон**       | Незначне виділення, збереження контексту даних  | Колір у діапазоні, сірий поза ним  |
| **Оригінальний фон**    | Звіти, презентації, інтуїтивний аналіз | Колір у діапазоні, фото поза ним |

### Створення власних кольорів LUT

Для повного контролю над візуалізацією ви можете створити **власні колірні градієнти**, редагуючи окремі колірні зупинки.**Щоб створити власний градієнт:**

1. На панелі LUT знайдіть**панель попереднього перегляду градієнта**

2. Знайдіть**квадрати зразків кольорів** під градієнтом
3. **Клацніть на колірну зупинку**, щоб вибрати її
4. Відкриється **палітра кольорів**

5. Виберіть новий колір за допомогою:
   * **Колірного кола**: візуальний вибір кольору
   * **Повзунків RGB/HSV**: точне керування кольором
   * **Введення шестнадцяткового коду**: точна специфікація кольору (наприклад, `#FF0000` для червоного)
6. Клацніть поза палітрою кольорів, **щоб застосувати новий колір**

7. Градієнт**одразу оновлюється** на зображенні**Додавання або видалення колірних зупинок:*** **Додати зупинку**: Клацніть на значок +, щоб додати новий зразок у кінці
* **Видалити зупинку**: Двічі клацніть на кольоровий квадрат, щоб видалити зразок**Стратегії налаштування:*** **Інвертувати градієнт**: Змінити порядок кольорів, щоб змінити значення (наприклад, зелений = низький, червоний = високий)
* **Кольори бренду**: Підберіть палітру кольорів вашої організації для звітів
* **Для людей з кольоровою сліпотою**: Використовуйте комбінації помаранчево-синього або фіолетово-жовтого
* **Оптимізація друку**: Виберіть кольори, які підходять як для кольорового, так і для чорно-білого друку
* **Багатопороговий**: Використовуйте різні кольори для конкретних порогових значень класифікації

{% hint style="info" %}
**Збереження власних градієнтів**: Власні градієнти можна зберігати та використовувати повторно. Натисніть на піктограму збереження на панелі LUT, щоб зберегти власні колірні схеми для подальшого використання.
{% endhint %}

## Інтерактивний робочий процес

### Оновлення в реальному часі

Усі налаштування LUT у пісочниці оновлюють зображення **миттєво та інтерактивно**:

* **Перемикання шару** → Зображення змінюється негайно
* **Вибір градієнта** → Кольори оновлюються миттєво
* **Налаштування діапазону значень** → Контраст змінюється в реальному часі
* **Зміна класів** → Плавність градієнта оновлюється негайно
* **Зміна обрізки** → Відображення фону змінюється миттєво
* **Редагування кольорів** → Налаштований градієнт застосовується негайно**Кнопка «Застосувати» не потрібна** — усі зміни відбуваються в режимі реального часу та інтерактивно!

{% hint style="success" %}
**Зворотний зв&#x27;язок у реальному часі**: Миттєвий візуальний зворотний зв&#x27;язок дозволяє швидко експериментувати з різними налаштуваннями, доки ви не знайдете оптимальну візуалізацію для своїх потреб аналізу.
{% endhint %}

### Ітеративний робочий процес вдосконалення

**Типовий робочий процес оптимізації LUT:**

1.**Виберіть індексний шар** (наприклад, RAW (Відбиття))
2. **Застосуйте індекс** — виберіть фільтр камери та формулу індексу, перетягніть кольорові кола у відповідне місце у формулі індексу
3. **Застосуйте градієнт LUT** — почніть із пресета Red-Yellow-Green
4. **Перевірте значення пікселів** — переміщайте курсор, зверніть увагу на діапазони значень
5. **Налаштуйте мінімум/максимум** — звузьте діапазон, щоб зосередитися на рослинності (наприклад, від 0,2 до 0,9)
6. **Виберіть обрізку** — спробуйте «Оригінальний фон» для контексту
7. **Уточніть кольори** — налаштуйте градієнт, якщо потрібно, для конкретного акценту
8. **Завершіть налаштування**— задокументуйте налаштування та скопіюйте їх у «Налаштування проекту» для обробки експорту

### Перевірка значень пікселів

Розуміння фактичних значень пікселів є вирішальним для встановлення ефективних діапазонів LUT:**Як перевіряти значення:**

1. Значення пікселів відображаються, коли на зображенні**відмічені** або поле «Індекс», або і «Індекс», і «LUT».
2. **Наведіть курсор** на різні ділянки зображення
3. **Спостерігайте за значеннями пікселів**, що відображаються в легенді під час наведення курсору
4. Збільште масштаб, щоб побачити окремі пікселі, виділені плаваючим значенням
5. **Запишіть** діапазони значень для різних об’єктів:
   * **Здорова рослинність**: наприклад, NDVI 0,55–0,85
   * **Стресована рослинність**: наприклад, NDVI 0,30–0,50
   * **Голий ґрунт**: наприклад, NDVI 0,05–0,25
   * **Вода** (якщо є): наприклад, NDVI від -0,05 до 0,10**Використання значень пікселів для налаштування діапазонів LUT:**Після перевірки значень пікселів відповідно відрегулюйте мінімальне та максимальне значення LUT:**Приклад сценарію:*** **Спостереження**: Значення ґрунту = 0,05–0,25, Стресований = 0,25–0,50, Здоровий = 0,50–0,85
* **Мета**: Візуалізувати лише стан рослин (виключити ґрунт)
* **Налаштування LUT**: Min = `0.25`, Max = `0.85`
* **Обрізка**: «Оригінальний фон», щоб бачити ґрунт у природному кольорі
* **Результат**: Колірний градієнт застосовується лише до рослинності, ґрунт відображається як на оригінальному зображенні

{% hint style="info" %}
**Динамічний діапазон**: Різні культури, сезони та стадії росту матимуть різні діапазони значень. Завжди перевіряйте значення пікселів у вашому конкретному наборі даних перед налаштуванням діапазонів LUT.
{% endhint %}

## Налаштовані індекси (Chloros+)

### Створення формул користувацьких індексів

{% hint style="info" %}
**Де створювати**: Користувацькі індекси можна налаштувати в**Налаштуваннях проєкту** перед обробкою, а також у бічній панелі пісочниці Image Viewer.
{% endhint %}

**Щоб створити користувацький індекс:**

1.**Відкрийте налаштування проекту** (перед обробкою) або бічну панель пісочниці Image Viewer
2. Перейдіть до **випадаючого меню формул індексів**

3. Знайдіть опцію**«Custom»** (необхідно увійти з ліцензією Chloros+)
4. **Визначте свою формулу**, використовуючи змінні діапазонів:
   * Назви діапазонів: `NIR`, `Red`, `Green`, `Blue`, `RedEdge` тощо.
   * Оператори: `+`, `-`, `*`, `/`, `^` (експонента)
   * Функції: `sqrt()`, `abs()` тощо (якщо підтримуються)
   * Дужки: `()` для визначення порядку операцій
5. **Назвіть свій індекс** (наприклад, «MyIndex» або «CustomNDVI»)
6. **Збережіть конфігурацію**

**Приклади власних формул:**

```

Modified NDVI with offset:
(NIR - Red) / (NIR + Red + 0.5)

Simple ratio:
NIR / Red

Complex multi-band:
(NIR - Red) / (NIR + Red - Blue)

Exponential index:
(NIR / Red) ^ 2
```

{% hint style="warning" %}
**Перевірка формули**: Переконайтеся, що ваша формула використовує діапазони, доступні у вашій камері. Наприклад, RedEdge доступна лише на камерах із фільтром RedEdge.
{% endhint %}
