# Вибір зображень-мішеней

Позначення зображень, що містять мішені калібрування, є надзвичайно важливим етапом, який значно прискорює роботу конвеєра обробки Chloros. Завдяки попередньому відбору зображень-мішеней ви позбавляєте Chloros необхідності сканувати кожне зображення у вашому наборі даних на наявність мішеней калібрування.

## Навіщо позначати зображення-мішені?

### Швидкість обробки

Без позначення цільових зображень Chloros повинен:

* Просканувати кожне окреме зображення у вашому проєкті
* Запустити алгоритми виявлення цілей на кожному зображенні
* Непотрібно перевіряти сотні або тисячі зображень

**Результат**: Обробка може зайняти значно більше часу, особливо для великих наборів даних.

### З позначеними цільовими зображеннями

Коли ви відмічаєте стовпець «Ціль» для конкретних зображень:

* Chloros сканує лише відмічені зображення на наявність цілей
* Виявлення цілей відбувається набагато швидше
* Загальний час обробки значно скорочується

{% hint style="success" %}
**Підвищення швидкості**: Позначення 2–3 зображень-цілей у наборі даних із 500 зображень може скоротити час виявлення цілей з понад 30 хвилин до менше ніж 1 хвилини.
{% endhint %}

***

## Як позначити зображення мішеней

### Крок 1: Визначте свої зображення мішеней

Перегляньте імпортовані зображення у файловому браузері та визначте, які зображення містять калібрувальні мішені.

**Типові сценарії:*** **Ціль до зйомки**: Знята до початку сеансу
* **Ціль після зйомки**: Знята після завершення сеансу
* **Цілі в полі**: Цілі, розміщені в зоні зйомки
* **Кілька цілей**: 2–3 зображення цілей на сеанс (рекомендовано)

### Крок 2: Перевірте стовпець «Ціль»

Для кожного зображення, що містить калібрувальну ціль:

1. Знайдіть зображення в таблиці браузера файлів
2. Знайдіть стовпець **«Ціль»** (крайній правий стовпець)
3. Встановіть прапорець у стовпці «Ціль» для цього зображення
4. Повторіть для всіх зображень, що містять цілі

### Крок 3: Перевірте свій вибір

Перед обробкою ще раз перевірте:

* [ ] Всі зображення з калібрувальними мітками відмічені
* [ ] Жодне зображення, що не є міткою, випадково не відмічене
* [ ] Мітки чітко видно на відмічених зображеннях

## Кращі практики для зображень міток

### Вказівки щодо зйомки міток

**Час:**

* Знімайте зображення міток безпосередньо перед початком та протягом сеансу зйомки
* За тих самих умов освітлення, що й для світлового датчика DAQ
* Для досягнення найкращих результатів бажано знімати зображення мішеней якомога частіше. В іншому випадку дані світлового датчика будуть використовуватися для коригування калібрування з часом.

**Положення камери:**

* Тримайте камеру над мішенню так, щоб вона була по центру і займала приблизно 40–60 % центру зображення.
* Тримайте камеру паралельно поверхні мішені або перпендикулярно до неї

**Освітлення:**

* Таке саме навколишнє освітлення, як у світлового датчика DAQ
* Уникайте тіней на поверхнях об’єктів
* Не затуляйте джерело світла своїм тілом, транспортним засобом або рослинністю
* Похмура погода забезпечує найбільш стабільні результати

**Стан об’єкта:**

* Тримайте панелі об’єкта чистими та сухими
* Усі 4 панелі мають бути чітко видимими та без перешкод
* Якщо можливо, об’єкти мають бути перпендикулярними/надирними до джерела світла

### Скільки зображень об’єкта?

**Мінімум:**1 зображення мішені на сеанс.**Рекомендовано:** 3–5 зображень мішені на сеанс.**Рекомендований графік:**

* 3–5 зображень, зроблених одразу після початку запису датчиком освітлення
* Для найкращих результатів змінюйте положення камери між знімками
* Опціонально: періодично під час сеансу, якщо умови освітлення постійно змінюються

## Робота з кількома камерами

### Конфігурації з двома камерами

Якщо ви використовуєте дві камери MAPIR одночасно (наприклад, Survey3W RGN + Survey3N OCN):

1. Зробіть знімки мішеней **обома камерами** одночасно
2. Використовуйте **одну й ту саму фізичну мішень** для обох камер
3. Позначте знімки мішеней для **обох типів камер** у файловому браузері
4. Chloros використає відповідні мішені для калібрування кожної камери

### Стовпець «Модель камери»

Стовпець **«Модель камери»** допомагає визначити, які зображення походять від якої камери:

* Survey3W\_RGN
* Survey3N\_OCN
* Survey3W\_RGB
* тощо

Використовуйте цей стовпець, щоб перевірити, чи ви позначили мішені для кожного типу камери у вашому проєкті.

## Налаштування виявлення мішеней

### Регулювання чутливості виявлення

Якщо Chloros не виявляє ваші мішені правильно, відрегулюйте ці налаштування в [Налаштуваннях проєкту](adjusting-project-settings.md):**Мінімальна площа зразка калібрування:*** **За замовчуванням**: 25 пікселів
* **Збільште**, якщо отримуєте помилкові виявлення на невеликих артефактах
* **Зменште**, якщо цілі не виявляються**Мінімальне кластеризування цілей:*** **За замовчуванням**: 60
* **Збільште**, якщо цілі розділяються на кілька виявлень
* **Зменшіть**, якщо цілі з варіаціями кольору не виявляються повністю***

## Поширені проблеми із зображеннями цілей

### Проблема: цілі не виявлено

**Можливі причини:**

* Зображення цілей не позначені у файловому браузері
* Ціль занадто мала у кадрі (&lt; 30% зображення)
* Погане освітлення (тіні, відблиски)
* Надто суворі налаштування виявлення цілей

**Рішення:**

1. Перевірте, чи стоїть галочка у стовпці «Ціль» для правильних зображень
2. Перегляньте якість зображення цілі у попередньому перегляді
3. Зробіть повторний знімок цілей, якщо якість погана
4. Налаштуйте параметри виявлення цілей, якщо потрібно

### Проблема: помилкове виявлення цілей

**Можливі причини:**

* Білі будівлі, транспортні засоби або ґрунтовий покрив, які помилково сприймаються за цілі
* Яскраві ділянки у рослинності
* Занадто низька чутливість виявлення

**Рішення:**

1. Позначте лише зображення реальних цілей, щоб обмежити область виявлення
2. Збільште мінімальну площу калібрувального зразка
3. Збільште мінімальне значення кластеризації цілей
4. Переконайтеся, що на зображеннях цілей видно лише саму ціль (мінімальний фоновий шум)

## Контрольний список для перевірки

Перед початком обробки перевірте вибір зображень цілей:

* [ ] Позначено щонайменше 1 зображення цілі за сеанс
* [ ] Позначки у стовпці «Ціль» встановлені для всіх зображень цілей
* [ ] Зображення цілей зроблені в той самий проміжок часу, що й зйомка
* [ ] Цілі чітко видно у попередньому перегляді після натискання
* [ ] Усі 4 калібрувальні панелі видно на кожному зображенні цілі
* [ ] На цілях немає тіней чи перешкод
* [ ] Для подвійної камери: цілі позначені для обох типів камер

***

## Обробка без цілей

### Обробка без калібрувальних цілей

Хоча це не рекомендується для наукової роботи, ви можете проводити обробку без цілей:

1. Залиште всі прапорці у стовпці «Ціль» зняті
2. **Вимкніть** «Калібрування відбиття» у налаштуваннях проекту
3. Корекція віньєтування все одно буде застосована
4. Результат не буде калібрований для абсолютного відбиття

{% hint style="warning" %}
**Не рекомендується**: Без калібрування відбиття значення пікселів відображають лише відносну яскравість, а не наукові вимірювання відбиття. Для отримання точних і повторюваних результатів використовуйте калібрувальні мішені.
{% endhint %}
