# Вибір зображень-мішеней

Позначення зображень, що містять калібрувальні мішені, дозволяє програмі «Chloros» точно визначити, де їх шукати. Якщо у стовпці «Target» відмічено хоча б одне зображення, програма «Chloros» сканує **лише відмічені зображення** — отже, позначення мішеней дозволяє як пришвидшити обробку, так і уникнути помилкового розпізнавання знімків зйомки як мішеней.

## Навіщо позначати цільові зображення?

### Позначення керує процесом сканування

Коли ви відмічаєте у стовпці «Ціль» конкретні зображення:

* Chloros сканує лише відмічені зображення на наявність цілей
* Виявлення цілей відбувається набагато швидше
* Знімки з аерофотозйомки не можуть спричинити помилкового виявлення цілей

Якщо **жодне** зображення не відмічено, програма «Chloros» переходить до сканування кожного зображення в проєкті:

* Алгоритми виявлення цілей працюють над кожним зображенням
* Сотні або тисячі зображень перевіряються без потреби
* Обробка займає значно більше часу, особливо для великих наборів даних

{% hint style="success" %}
**Підвищення швидкості**: Позначення 2–3 зображень-цілей у наборі даних із 500 зображень може скоротити час виявлення цілей з понад 30 хвилин до менше ніж 1 хвилини.
{% endhint %}

***

## Як позначити зображення-мішені

### Крок 1: Визначте свої зображення-мішені

Перегляньте імпортовані зображення у браузері файлів і визначте, які з них містять калібрувальні мішені.

**Типові сценарії:*** **Ціль до зйомки**: знята до початку сеансу
* **Ціль після зйомки**: знята після завершення сеансу
* **Цілі в полі**: цілі, розміщені в межах зони зйомки
* **Кілька цілей**: 2–3 зображення цілей на сеанс (рекомендовано)

### Крок 2: Перевірте стовпець «Мішень» (<img src="../.gitbook/assets/image (33).png" alt="" data-size="original">)

Для кожного зображення, що містить калібрувальну мішень:

1. Знайдіть зображення в таблиці браузера файлів
2. Знайдіть стовпець **«Мішень»** (найправіший стовпець)
3. Встановіть прапорець у стовпці «Мішень» для цього зображення
4. Повторіть ці дії для всіх зображень, що містять мішені

### Крок 3: Перевірте свій вибір

Перед обробкою ще раз переконайтеся, що:

* [ ] Усі зображення з калібрувальними мішенями відмічені
* [ ] Жодне зображення, що не є мішенню, не відмічено випадково
* [ ] Мішені чітко видно на відмічених зображеннях

## LATTICE: Мішені є необов’язковими під час запису DAQ

Для мультиспектральних камер LATTICE калібрувальна мішень у кадрі є **одним із двох** можливих еталонів відбиття:

* **Мішень у кадрі**: коли зображення з позначеною мішенню проходить контроль якості (QA) у програмі «Chloros», мішень стає**абсолютним еталоном відбиття** для зображень навколо неї.
* **Напрямлене вниз випромінювання DAQ**: якщо мітки немає (або вона не пройшла перевірку якості), система «Chloros» обчислює відбиваність на основі інтенсивності випромінювання, що падає вниз, з датчика світла DAQ (ρ = π·L/E). Якщо ваші знімки охоплені записом `.daq` або DAQ-M `.csv`, ви отримаєте відкалібрований коефіцієнт відбиття**без жодних зображень мітки**.

Ця автоматична поведінка є стандартною. У файлі налаштувань «CLI» / «SDK» це відповідає параметру `--reflectance-source auto`; ви також можете примусово встановити `target` (суворий режим — без заміни даних DAQ) або `daq` (пріоритет даних DAQ). Див. [Довідку щодо CLI](../reference/cli-reference.md#per-product-export-toggles-lattice-multispectral).

**Геометрії мішеней LATTICE**: окрім класичного виявлення панелей, що використовується для Survey3, обробка LATTICE підтримує**мішені з маркуванням ArUco**,**мішені з фіксованою областю інтересу (ROI)**та**смугові мішені**, налаштовані для кожного проекту.**Виміряні** скани відбивної здатності мішеней для кожної одиниці можна надати за серійним номером (CLI: `--target-reflectance-dir`, по одному `<serial>.csv` на кожну одиницю мішені), з номінальними спектрами T3/T4P як запасним варіантом.

{% hint style="info" %}
**Модуль F988**: відбивна здатність F988 калібрується за допомогою панелі відбивної здатності на місці зйомки: діапазон лежить за межами каліброваного діапазону світлового датчика DAQ, тому Chloros застосовує ваші найсвіжіші дані зйомки панелі та зберігає їх між окремими спостереженнями панелі. Якщо модуль F988 обробляється виключно за даними DAQ, Chloros відхиляє відбиття на основі DAQ для цього діапазону (причина пропуску `dls-uncalibrated-band-988`) — підтримуваним способом є робочий процес із використанням панелі.
{% endhint %}

## Рекомендації щодо зображень мішеней

### Вказівки щодо зйомки мішеней

**Час:**

* Знімайте зображення мішеней безпосередньо перед початком та протягом сеансу зйомки
* За тих самих умов освітлення, що й для світлового датчика DAQ
* Для досягнення найкращих результатів бажано знімати зображення об’єкта якомога частіше. В іншому разі дані світлового датчика використовуватимуться для коригування калібрування з часом.

**Положення камери:**

* Тримайте камеру над об’єктом так, щоб він був у центрі кадру та займав приблизно 40–60 % центру зображення.
* Тримайте камеру паралельно поверхні об’єкта або під кутом, що відповідає надиру

**Освітлення:**

* Використовуйте те саме навколишнє освітлення, що й для світлового датчика DAQ
* Уникайте тіней на поверхнях об’єкта
* Не затуляйте джерело світла своїм тілом, транспортним засобом або рослинністю
* Похмура погода забезпечує найбільш стабільні результати

**Стан об’єкта:**

* Панелі мішені мають бути чистими та сухими
* Усі панелі мішені (наприклад, усі 4 на T4) мають бути чітко видимими та вільними від перешкод
* За можливості розміщуйте мішені перпендикулярно або вертикально до джерела світла

### Скільки зображень мішені потрібно?

**Мінімум:**1 зображення мішені за сеанс.**Рекомендовано:** 3–5 зображень мішені за сеанс.**Рекомендований графік:**

* Зробіть 3–5 знімків одразу після початку роботи світлового датчика
* Для найкращих результатів змінюйте положення камери між знімками
* Опціонально: періодично під час сеансу, якщо умови освітлення постійно змінюються

## Робота з кількома камерами

### Конфігурації з двома камерами

Якщо ви використовуєте дві камери «MAPIR» одночасно (наприклад, Survey3W RGN + Survey3N OCN):

1. Знімайте зображення мішеней **обома камерами** одночасно
2. Використовуйте **одну й ту саму фізичну мітку** для обох камер
3. Позначте зображення міток для **обох типів камер** у браузері файлів
4. Програма «Chloros» використає відповідні мітки для калібрування кожної камери

### Стовпець «Модель камери»

Стовпець **«Модель камери»** допомагає визначити, які зображення походять від якої камери:

* Survey3W\_RGN
* Survey3N\_OCN
* LATT-M3M-L41-F550
* LATT-M3C-L87-FRGN
* тощо.

Використовуйте цей стовпець, щоб переконатися, що ви позначили мішені для кожного типу камери у вашому проєкті.

## Налаштування виявлення цілей

### Регулювання чутливості виявлення

Якщо «Chloros» не виявляє ваші цілі правильно, відрегулюйте ці налаштування в [Налаштуваннях проєкту](adjusting-project-settings.md):**Мінімальна площа калібрувального зразка (px):*** **За замовчуванням**: 25 пікселів
* **Збільште**, якщо трапляються помилкові виявлення на дрібних артефактах
* **Зменште**, якщо цілі не виявляються**Мінімальне кластеризування цілей (0–100):*** **За замовчуванням**: 60
* **Збільште**, якщо цілі розділяються на кілька окремих виявлень
* **Зменште**, якщо цілі з варіаціями кольору не виявляються повністю

{% hint style="info" %}
**Порада щодо CLI**: `chloros-cli process` підтримує ті самі параметри (`--min-target-size`, `--target-clustering`), а його прапорець `--target`/`--targets` позначає всю вхідну папку як «тільки для панелі цілей». Див. [Довідку щодо CLI](../reference/cli-reference.md).
{% endhint %}

## Поширені проблеми з зображеннями цілей

### Проблема: Цілі не виявлено

**Можливі причини:**

* Зображення цілей не позначені в браузері файлів
* Ціль занадто мала в кадрі (&lt; 30 % зображення)
* Погане освітлення (тіні, відблиски)
* Надто суворі налаштування виявлення цілей

**Рішення:**

1. Перевірте, чи встановлено прапорець у стовпці «Ціль» для потрібних зображень
2. Перевірте якість зображень мішеней у попередньому перегляді
3. Якщо якість погана, повторно сфотографуйте мішені
4. За потреби відрегулюйте налаштування виявлення мішеней

### Проблема: хибне виявлення мішеней

**Можливі причини:**

* Білі будівлі, транспортні засоби або рослинний покрив помилково сприймаються за мішені
* Яскраві ділянки у рослинності
* Занадто низька чутливість виявлення

**Рішення:**

1. Позначте лише зображення реальних цілей — скануватимуться лише позначені зображення
2. Збільште мінімальну площу калібрувальної вибірки
3. Збільште мінімальне значення кластеризації цілей
4. Переконайтеся, що на зображеннях цілей видно лише саму ціль (мінімальний фоновий шум)

## Контрольний список для перевірки

Перед початком обробки перевірте вибір зображень цілей:

* [ ] Позначено щонайменше 1 зображення цілі за сеанс (або, для LATTICE, запис `.daq`/`.csv`, що охоплює сеанс)
* [ ] Позначки у стовпчику «Ціль» встановлені для всіх зображень цілей
* [ ] Зображення цілей зняті в той самий проміжок часу, що й обстеження
* [ ] Цілі чітко видно у попередньому перегляді після натискання
* [ ] Усі калібрувальні панелі видно на кожному зображенні цілі
* [ ] На цілях немає тіней чи перешкод
* [ ] Для системи з двома камерами: цілі позначені для обох типів камер

## Обробка без використання мішеней

### LATTICE: із записом DAQ

Якщо світловий датчик DAQ реєстрував інтенсивність сонячного випромінювання, спрямованого вниз, під час зйомки LATTICE, мішені не потрібні:

1. Імпортуйте файл `.daq` (або DAQ-M `.csv`) із зображеннями
2. Не відмічайте стовпець «Ціль»
3. Коефіцієнт відбиття обчислюється автоматично на основі еталонного значення інтенсивності опромінення, що спускається, з DAQ
4. Для розрахунку інтенсивності випромінювання ніколи не потрібні ні мітки, ні DAQ — це значення визначається виключно на основі заводської радіометричної калібровки камери

### Обробка без будь-яких еталонів

Ви також можете здійснювати обробку без міток і без DAQ:

1. Не ставте галочки у всіх полях стовпчика «Мітка»
2. **Вимкніть** «Калібрування відбивної здатності / баланс білого» у налаштуваннях проєкту — тоді виявлення мішеней повністю пропускається
3. Корекція віньєтування все одно застосовуватиметься
4. Результат не буде калібрований щодо абсолютної відбивної здатності (LATTICE multispectral все одно експортує продукти з дебейерингом, попередній перегляд та інтенсивність випромінювання)

{% hint style="warning" %}
**Не рекомендується для наукової роботи з проектом «Survey3»**: без калібрування відбивної здатності значення пікселів у файлі «Survey3» відображають лише відносну яскравість, а не наукові вимірювання відбивної здатності. Для отримання точних і відтворюваних результатів використовуйте калібрувальні мішені (або, у випадку LATTICE, світловий датчик DAQ).
{% endhint %}
