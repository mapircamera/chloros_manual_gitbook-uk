# Початок обробки

Після імпорту зображень, позначення калібрувальних міток та налаштування параметрів проєкту ви готові розпочати обробку. На цій сторінці ви знайдете покрокову інструкцію щодо запуску конвеєра обробки Chloros.

## Перелік перевірок перед початком обробки

Перш ніж натиснути кнопку «Start», переконайтеся, що все готово:

* [ ] **Файли імпортовано** — усі зображення відображаються у файловому браузері
* [ ] **Зображення-мішені позначено** — у стовпці «Target» позначено зображення для калібрування
* [ ] **Моделі камер виявлено** — у стовпці «Camera Model» вказано правильні камери
* [ ] **Налаштування сконфігуровано** — налаштування проекту перевірено та скориговано
* [ ] **Вибрано індекси** — додано потрібні мультиспектральні індекси (за потреби)
* [ ] **Вибрано формат експорту** — формат виводу, що відповідає вашому робочому процесу

{% hint style="info" %}
**Порада**: Перегляньте кілька зображень у браузері файлів, щоб переконатися, що вони завантажилися правильно перед обробкою.
{% endhint %}

***

## Початок обробки

### Знайдіть кнопку «Старт»

Кнопка «Старт/Відтворити» розташована у верхній панелі заголовка Chloros:

* Розташування: у верхній центральній частині вікна
* Піктограма: **Кнопка «Відтворити/Старт»** <img src="../.gitbook/assets/image (2) (1).png" alt="" data-size="line">
* Стан: Кнопка активована (світиться), коли готова до обробки

### Натисніть, щоб почати

1. Натисніть **кнопку «Відтворити/Почати»** у верхньому заголовку
2. Обробка розпочнеться негайно
3. Під час обробки кнопка стає неактивною (сірою)
4. Смуга прогресу оновлюється, показуючи стан обробки

{% hint style="success" %}
**Обробка розпочалася**: Після натискання Chloros автоматично виконує всі етапи обробки — виявлення об’єкта, дебейерінг, калібрування, обчислення індексу та експорт.
{% endhint %}

## Розуміння режимів обробки

Chloros працює у двох різних режимах обробки залежно від вашої ліцензії:

### Безкоштовний режим (послідовна обробка)

**Доступний для всіх користувачів**

**Як це працює:**

* Обробляє зображення по одному, послідовно
* Однопотокова робота
* Менше використання пам&#x27;яті

**Індикатор прогресу показує 2 етапи:**

1.**Виявлення мішеней** — сканування для пошуку мішеней калібрування
2. **Обробка** — застосування калібрування та експорт зображень**Час обробки:**

* Набагато повільніше, ніж у паралельному режимі Chloros+
* Підходить для малих та середніх наборів даних (&lt; 200 зображень)

### Режим Chloros+ (паралельна обробка)

**Потрібна ліцензія Chloros+**

**Як це працює:**

* Одночасно обробляє кілька зображень за допомогою [4-потокового конвеєра обробки](../processing-architecture/processing-pipeline.md)
* [Динамічна адаптація обчислень](../processing-architecture/dynamic-compute-adaptation.md) автоматично вибирає оптимальну стратегію для вашого обладнання
* Прискорення на GPU (CUDA) за допомогою відеокарт NVIDIA (настільних ПК та Jetson)
* Масштабується від Jetson Nano (1 робочий процес) до настільного ПК з GPU 12 ГБ+ (3–4 робочі процеси)

**Смуга прогресу показує 4 етапи** (що відповідають 4 потокам конвеєра):

1. **Виявлення** (Потік 1) — пошук об’єктів калібрування
2. **Аналіз** (Потік 2) — вивчення метаданих зображення та обчислення калібрування
3. **Калібрування** (Потік 3) — дебейерінг на GPU, корекція віньєтування, обчислення індексу
4. **Експорт** (потік 4) — збереження оброблених зображень та індексів**Взаємодія з індикатором прогресу:*** **Наведіть курсор миші** на індикатор, щоб побачити детальну випадаючу панель із 4 етапами
* **Клацніть** на індикатор прогресу, щоб зафіксувати випадаючу панель на місці
* **Клацніть ще раз**, щоб розфіксувати та приховати панель**Час обробки:**

* Значно швидше, ніж у безкоштовному режимі
* Швидкість залежить від кількості ядер процесора
* Прискорення за допомогою графічного процесора ще більше підвищує швидкість

{% hint style="info" %}
**Швидкість Chloros+**: Паралельна обробка може бути в 5–10 разів швидшою, ніж послідовний режим, для великих наборів даних. Проект із 500 зображеннями, який у безкоштовному режимі займає 2 години, із Chloros+ може завершитися за 15–20 хвилин.
{% endhint %}

## Що відбувається під час обробки

### Етап 1: Виявлення цілей

**Що робить Chloros:**

* Сканує позначені зображення цілей (або всі зображення, якщо жодне не позначено)
* Ідентифікує 4 калібрувальні панелі в кожній мішені
* Витягує значення відбиття з панелей мішеней
* Записує часові мітки мішеней для планування калібрування

**Тривалість:** 1–30 секунд (з позначеними мішенями), 5–30+ хвилин (без позначок)

### Етап 2: Дебейерінг (перетворення RAW)

**Що робить Chloros:**

* Конвертує дані RAW у форматі Байєра в повні зображення RGB
* Застосовує високоякісний алгоритм демозаїкування
* Зберігає максимальну якість зображення та деталі

**Тривалість:** Залежить від кількості зображень та швидкості процесора

### Етап 3: Калібрування

**Що робить Chloros:*** **Корекція віньєтування**: Усуває затемнення по краях об&#x27;єктива
* **Калібрування відбиття**: Нормалізує за допомогою цільових значень відбиття
* Застосовує корекції до всіх діапазонів/каналів
* Використовує відповідну калібрувальну мітку для кожного зображення на основі часової мітки

**Тривалість:** Більша частина часу обробки

### Етап 4: Розрахунок індексів

**Що робить Chloros:**

* Розраховує налаштовані мультиспектральні індекси (NDVI, NDRE тощо)
* Застосовує математичні операції з діапазонами до відкаліброваних зображень
* Генерує індексні зображення для кожного вибраного індексу

**Тривалість:** Кілька секунд на зображення

### Етап 5: Експорт

**Що робить Chloros:**

* Зберігає відкалібровані зображення у вибраному форматі
* Експортує індексні зображення з налаштованими кольорами LUT
* Записує файли у підпапки за моделями камер
* Зберігає оригінальні імена файлів із суфіксами

**Тривалість:** Залежить від формату експорту та розміру файлу***

## Поведінка обробки

### Автоматичний конвеєр обробки

Після запуску весь конвеєр працює автоматично:

* Втручання користувача не потрібне
* Усі налаштовані кроки виконуються послідовно
* Оновлення прогресу відображаються в режимі реального часу

### Використання ресурсів комп&#x27;ютера під час обробки

**Вільний режим:**

* Відносно низьке використання процесора (однопотокове)
* Комп&#x27;ютер залишається чутливим до інших завдань
* Можна безпечно згорнути Chloros і працювати в інших програмах

**Chloros+ Паралельний режим:**

* Високе використання процесора (багатопотокове, до 16 ядер)
* З прискоренням на графічному процесорі: Високе використання графічного процесора
* Під час обробки комп&#x27;ютер може реагувати повільніше
* Уникайте запуску інших завдань, що інтенсивно використовують процесор

{% hint style="warning" %}
**Порада щодо продуктивності**: Для найкращої продуктивності Chloros+ закрийте інші програми та дозвольте Chloros використовувати всі системні ресурси.
{% endhint %}

### Обробку неможливо призупинити

**Важливі обмеження:**

* Після запуску обробку неможливо призупинити
* Ви можете скасувати обробку, але прогрес буде втрачено
* Часткові результати не зберігаються
* У разі скасування необхідно розпочати спочатку

**Порада щодо планування:** Для дуже великих проектів розгляньте можливість обробки партіями або використання CLI для кращого контролю.***

## Моніторинг обробки

Під час виконання обробки ви можете:

* **Спостерігати за індикатором прогресу** — переглядати загальний відсоток виконання
* **Переглядати поточний етап** — «Виявлення», «Аналіз», «Калібрування» або «Експорт»
* **Переглядати вкладку журналу** — переглядати детальні повідомлення та попередження щодо обробки
* **Переглядати попередній перегляд готових зображень** — деякі файли експорту можуть з’являтися під час обробки

Детальну інформацію про моніторинг див. у розділі [Моніторинг обробки](monitoring-the-processing.md).

## Скасування обробки

Якщо вам потрібно зупинити обробку:

### Як скасувати

1. Знайдіть **кнопку «Стоп/Скасувати»** (під час обробки вона замінює кнопку «Старт»)
2. Натисніть кнопку «Стоп»
3. Обробка зупиниться негайно
4. Часткові результати будуть відкинуті

### Коли скасовувати

**Поважні причини для скасування:**

* Виявилося, що були використані неправильні налаштування
* Забули позначити цільові зображення
* Імпортовано неправильні зображення
* Система працює занадто повільно або не реагує

**Після скасування:**

* Перегляньте та виправте будь-які проблеми
* Налаштуйте параметри за потреби
* Перезапустіть обробку з початку
* Для найкращого результату повністю закрийте Chloros і перезапустіть

{% hint style="warning" %}
**Відсутність часткових результатів**: Скасування призводить до втрати всього прогресу. Chloros не зберігає частково оброблені зображення.
{% endhint %}

## Орієнтовний час обробки

Фактичний час обробки значно варіюється залежно від:

* Кількості зображень
* Роздільної здатності зображень
* Формату вхідних даних (RAW чи JPG)
* Режиму обробки (Free чи Chloros+)
* Швидкості процесора та кількості ядер
* Наявності графічного процесора (лише Chloros+)
* Кількість індексів, що підлягають обчисленню
* Складність формату експорту

### Приблизні оцінки (Chloros+, зображення 12 МП, сучасний процесор)

| Кількість зображень | Безкоштовний режим | Chloros+ (процесор) | Chloros+ (графічний процесор) |
| ----------- | --------- | -------------- | -------------- |
| 50 зображень   | 15-20 хв | 5-8 хв        | 3-5 хв        |
| 100 зображень  | 30-40 хв | 10-15 хв      | 5-8 хв        |
| 200 зображень  | 1-1,5 год | 20-30 хв      | 10-15 хв      |
| 500 зображень  | 2-3 години   | 45-60 хв      | 20-30 хв      |
| 1000 зображень | 4-6 годин   | 1,5-2 години      | 40-60 хв      |

{% hint style="info" %}
**Перший запуск**: Початкова обробка може тривати довше, оскільки Chloros створює кеші та профілі. Наступна обробка подібних наборів даних буде швидшою.
{% endhint %}

## Поширені проблеми під час запуску

### Кнопка «Запустити» неактивна (зафарбована сірим)

**Можливі причини:**

* Не імпортовано зображень
* Бекенд не повністю запущений
* Попередня обробка все ще виконується
* Проєкт не повністю завантажено

**Рішення:**

1. Зачекайте, поки бекенд повністю ініціалізується (перевірте піктограму в головному меню)
2. Перевірте, чи зображення імпортовано у файловому браузері
3. Перезапустіть Chloros, якщо кнопка залишається неактивною
4. Перевірте журнал налагодження на наявність повідомлень про помилки

### Обробка починається, але одразу ж завершується з помилкою

**Можливі причини:**

* У проекті немає дійсних зображень
* Пошкоджені файли зображень
* Недостатньо місця на диску
* Недостатньо пам&#x27;яті (RAM)

**Рішення:**

1. Перевірте журнал налагодження <img src="../.gitbook/assets/icon_log.JPG" alt="" data-size="line"> на наявність повідомлень про помилки
2. Перевірте наявність вільного місця на диску
3. Спробуйте обробити меншу підмножину зображень
4. Перевірте, чи зображення не пошкоджені

### Попередження «Цілі не виявлено»

**Можливі причини:**

* Забули позначити цільові зображення
* Цільові зображення не містять видимих цілей
* Налаштування виявлення цілей занадто суворі

**Рішення:**

1. Перегляньте [Вибір зображень-мішеней](choosing-target-images.md)
2. Позначте відповідні зображення у стовпці «Мішень»
3. Перевірте, чи мішені видно на позначених зображеннях
4. За потреби відрегулюйте налаштування виявлення мішеней

## Поради для успішної обробки

### Перед початком

1. **Спочатку проведіть тест на невеликій підмножині** — обробіть 10–20 зображень, щоб перевірити налаштування
2. **Перевірте вільний простір на диску** — забезпечте 2–3 рази більше вільного місця, ніж розмір набору даних
3. **Закрийте непотрібні програми** — звільніть системні ресурси
4. **Перевірте цільові зображення** — перегляньте позначені цілі, щоб переконатися в якості
5. **Збережіть проект** — проект зберігається автоматично, але рекомендується зберегти його вручну

### Під час обробки

1. **Уникайте переходу системи в режим сну** — вимкніть режими енергозбереження
2. **Тримайте Chloros у фоновому режимі** — або принаймні видимим у панелі завдань
3. **Періодично перевіряйте хід роботи** — перевіряйте наявність попереджень або помилок
4. **Не завантажуйте інші ресурсомісткі програми** — особливо в паралельному режимі Chloros+

### Chloros+ Прискорення за допомогою графічного процесора

Якщо ви використовуєте прискорення за допомогою графічного процесора NVIDIA:

1. Оновіть драйвери NVIDIA до останньої версії
2. Переконайтеся, що графічний процесор має 4 ГБ+ відеопам&#x27;яті
3. Закрийте програми, що інтенсивно використовують графічний процесор (ігри, редагування відео)
4. Слідкуйте за температурою графічного процесора (забезпечте належне охолодження)
