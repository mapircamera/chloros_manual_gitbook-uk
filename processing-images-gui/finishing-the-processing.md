# Завершення обробки

Після завершення обробки Chloros настав час переглянути результати, перевірити якість вихідних даних та підготувати оброблені зображення до використання у вашому робочому процесі. На цій сторінці ви знайдете покрокові інструкції щодо завершальних кроків та подальших дій.

## Індикація завершення обробки

Коли обробка успішно завершиться, ви побачите кілька індикаторів:

* ✅ **Смуга прогресу**: Досягає 100% завершення
* ✅ **Журнал налагодження**: Показує повідомлення «Обробка завершена»
* ✅ **Кнопка «Старт»**: Стає знову активною (готова до наступного запуску обробки)
* ✅ **Вихідні файли**: всі оброблені зображення збережені в підпапці моделі камери***

## Пошук оброблених зображень

### Відкриття папки вихідних файлів

1. Натисніть на піктограму **Головне меню** <img src="../.gitbook/assets/image (1) (1) (1) (1).png" alt="" data-size="line"> (у верхньому лівому куті)
2. Виберіть **«Відкрити папку проекту»**

3. Відкриється провідник файлів у каталозі проекту
4. Знайдіть свій проект за назвою

## Перегляд оброблених зображень

### Швидкий попередній перегляд у файловому менеджері

**Вбудований попередній перегляд Windows:**

1. Перейдіть до підпапки моделі камери
2. Виберіть файл зображення
3. Попередній перегляд з&#x27;явиться у панелі попереднього перегляду Windows Explorer
4. Використовуйте клавіші зі стрілками для перегляду зображень

### Перегляд у зовнішніх програмах перегляду зображень

**Рекомендовані програми перегляду:*** **QGIS** — безкоштовне програмне забезпечення для геоінформаційних систем (найкраще підходить для геореферентного мультиспектрального аналізу)
* **IrfanView** — швидка, легка програма перегляду зображень (підтримує TIFF)
* **Adobe Photoshop** — професійне редагування (підтримка TIFF)
* **GIMP** — безкоштовна альтернатива Photoshop
* **Windows Photos** — базовий перегляд (може не підтримувати 16-бітний TIFF)

### Перегляд у Chloros Image Viewer

Використовуйте вбудований Image Viewer Chloros для розширеної візуалізації:

1. Клацніть на мініатюру зображення у файловому браузері
2. Зображення відкриється в основній області попереднього перегляду
3. Клацніть на вкладку **Image Viewer** <img src="../.gitbook/assets/icon_image-viewer.JPG" alt="" data-size="line"> на лівій бічній панелі
4. Використовуйте [Index/LUT Sandbox](../image-viewer-gui/index-lut-sandbox.md) для інтерактивного аналізу

Детальні інструкції дивіться в розділі [Image Viewer](../image-viewer-gui/opening-an-image-full-screen.md).

## Поширені проблеми з результатами та їх вирішення

### Проблема: Відсутні файли результатів

**Можливі причини:**

* Файли не відповідали критеріям обробки
* Зображення, призначені лише для цільового використання (виключені з експорту)
* Під час експорту закінчився простір на диску
* Пошкодження файлів під час обробки

**Рішення:**

1. Перевірте журнал налагодження на наявність повідомлень про пропуски/помилки
2. Перевірте, чи було достатньо місця на диску
3. Підрахуйте файли: кількість має відповідати (початкова кількість - цільова кількість) × (індекси + 1)
4. Повторно імпортуйте та переобробіть відсутні файли

### Проблема: Темні або світлі краї (віньєтування все ще помітне)

**Можливі причини:**

* Корекція віньєтування вимкнена
* Камера/об&#x27;єктив відсутні в базі профілів Chloros
* Екстремальне віньєтування, яке перевищує можливості корекції

**Рішення:**

1. Перевірте, чи увімкнено корекцію віньєтування в налаштуваннях проекту
2. Перевірте, чи правильно визначено модель камери
3. Зверніться до служби підтримки MAPIR, якщо віньєтування не зникає

### Проблема: Неправильні кольори або значення

**Можливі причини:**

* Не виявлено калібрувальних мішеней
* Вибрано неправильну модель калібрувальної мішені
* Калібрування відбиття вимкнено
* Низька якість зображень мішеней

**Рішення:**

1. Перевірте, чи увімкнено калібрування відбиття
2. Перевірте повідомлення «Ціль знайдено» у журналі налагодження
3. Перевірте якість зображень цілей
4. Повторіть обробку, позначивши правильні цілі

### Проблема: Значення NDVI здаються неправильними

**Очікувані діапазони NDVI:*** **Вода, скелі, ґрунт**: від -0,1 до 0,2
* **Рідка/нездорова рослинність**: від 0,2 до 0,4
* **Помірна рослинність**: від 0,4 до 0,6
* **Здорова, густа рослинність**: від 0,6 до 0,9**Якщо значення виходять за межі цих діапазонів:**

1. Перевірте, чи було застосовано калібрування відбиття
2. Перевірте, чи було включено журнал датчика освітлення
3. Перевірте, чи були виявлені калібрувальні мішені
4. Переконайтеся, що було виявлено правильну модель камери
5. Перегляньте час і умови зйомки зображення мішені

## Використання оброблених зображень

### Для фотограмметрії / створення ортомозаїки

**Рекомендований робочий процес:**

1.**Імпортуйте відкалібровані зображення відбиття** у програмне забезпечення для фотограмметрії:
   * Pix4Dmapper
   * Agisoft Metashape
   * DroneDeploy
   * WebODM
2. **Зберігайте метадані EXIF**: Переконайтеся, що дані GPS збережені для геотагування
3. **Відкалібровані робочі процеси**: Використовуйте зображення відбиття для наукової точності
4. **Обробка індексних мозаїк**: Створіть ортомозаїки NDVI з окремих індексних зображень
5. **Експортуйте геореференційовані GeoTIFF**: Для використання в ГІС-додатках

### Для ГІС-аналізу

**Рекомендований робочий процес:**

1.**Завантажте в QGIS, ArcGIS або подібне програмне забезпечення**

2.**Використовуйте 16-бітні зображення відбиття TIFF** для багатосмугового аналізу
3. **Використовуйте індексні зображення** (NDVI, NDRE) як готові до використання шари рослинності
4. **Растровий калькулятор**: об&#x27;єднуйте смуги для власного аналізу
5. **Експорт**: Створюйте класифікаційні карти, карти виявлення змін, карти стану рослинності

### Для безпосереднього аналізу / звітності

**Рекомендований робочий процес:**

1.**Використовуйте індексні зображення з кольорами LUT** для візуальних звітів
2. **Витягуйте статистику**: Середнє значення NDVI для кожного поля/ділянки
3. **Часові ряди**: порівняння індексів за кілька сесій
4. **Створення звітів**: включення карт, статистичних даних та візуалізацій***

## Архівування та резервне копіювання

### Рекомендована стратегія резервного копіювання

**Що зберігати:*** ✅ **Оригінальні зображення у форматі RAW/JPG** — архівувати на окремому диску/у хмарі
* ✅ **Оброблені результати** — зберігайте відкалібровані зображення та індекси
* ✅ **Файл проєкту** — містить усі налаштування для повторної обробки, якщо це буде потрібно
* ✅ **Журнал налагодження** — документує деталі обробки
* ✅ **Зображення калібрувальних мішеней** — для перевірки та повторної обробки**Рекомендації щодо зберігання:*** **Негайне резервне копіювання**: Зовнішній жорсткий диск
* **Довгострокове архівування**: Хмарне сховище (Google Drive, Dropbox тощо)
* **Критичні дані**: Зберігайте 2–3 копії в різних місцях***

## Наступні цикли обробки

### Повторне використання налаштувань проекту

Якщо в майбутньому ви будете обробляти подібні набори даних:

1. **Збережіть шаблон проекту** (якщо ще не зробили цього)
2. **Створіть новий проект**, використовуючи збережений шаблон
3. **Імпортуйте нові зображення**

4.**Обробіть**з ідентичними налаштуваннями для забезпечення узгодженості

### Пакетна обробка декількох сесій

Для декількох сесій/наборів даних:**Варіант 1: Графічний інтерфейс — декілька проектів**

* Створіть окремий проект для кожного сеансу
* Використовуйте однакові налаштування шаблону
* Обробляйте по одному

**Варіант 2: Chloros CLI (лише Chloros+)**

* Автоматизуйте пакетну обробку
* Обробляйте кілька папок за допомогою скриптів
* Див. [Документацію CLI](../CLI.md)

**Варіант 3: Python SDK (лише для Chloros+)**

* Програмне керування
* Інтеграція з конвеєрами аналізу
* Див. [Документація API](../api-python-sdk.md)

## Усунення несправностей після обробки

### Повторна обробка з іншими налаштуваннями

Якщо результати не задовольняють:

1. Збережіть оригінальні зображення (ніколи не видаляйте)
2. Відкрийте той самий проєкт у Chloros
3. Налаштуйте параметри на панелі «Налаштування проєкту»
4. Виконайте обробку знову — результати замінять попередні

### Обробка підмножини зображень

Щоб переобробити лише певні зображення:

1. Створіть новий проєкт
2. Імпортуйте лише ті зображення, які потребують переобробки
3. Використовуйте той самий шаблон налаштувань
4. Обробіть менший набір даних
