# Налаштування параметрів проекту

Перед обробкою зображень важливо налаштувати параметри проекту відповідно до вимог вашого робочого процесу. Панель «Налаштування проекту» <img src="../.gitbook/assets/icon_project-settings.JPG" alt="" data-size="line"> забезпечує повний контроль над калібруванням, параметрами обробки, мультиспектральними індексами та форматами експорту.

## Доступ до налаштувань проекту

1. Відкрийте свій проект у Chloros
2. Натисніть на піктограму **Налаштування проекту** <img src="../.gitbook/assets/icon_project-settings.JPG" alt="" data-size="line"> на лівій бічній панелі
3. На панелі «Налаштування проекту» відображаються всі параметри конфігурації

{% hint style="info" %}
**Налаштування зберігаються автоматично** разом із проектом. При повторному відкритті проекту всі налаштування відновлюються.
{% endhint %}

***

## Швидке налаштування для типових робочих процесів

### Налаштування за замовчуванням (рекомендовано для більшості користувачів)

Для типових робочих процесів з камерами MAPIR Survey3 налаштування за замовчуванням працюють добре:

* ✅ **Корекція віньєтування**: Увімкнено
* ✅ **Калібрування відбиття**: Увімкнено (потрібні зображення мішеней MAPIR)
* ✅ **Метод дебейєра**: Стандартний (Швидкий, Середня якість)
* ✅ **Формат експорту**: TIFF (16-бітний)

Просто імпортуйте свої зображення та розпочніть обробку з цими налаштуваннями за замовчуванням.

## Огляд налаштувань проекту

Панель налаштувань проекту поділена на кілька категорій. Нижче наведено короткий опис кожного розділу. Повну документацію див. у [Налаштуваннях проекту](../project-settings/project-settings.md).

### Виявлення мішеней

Керує тим, як Chloros ідентифікує калібрувальні мішені на ваших зображеннях.

**Ключові налаштування:*** **Мінімальна площа зразка калібрування**: поріг розміру для виявлення мішеней (за замовчуванням: 25 пікселів)
* **Мінімальне кластеризування мішеней**: поріг схожості для групування областей мішеней (за замовчуванням: 60)**Коли слід коригувати:**

* Збільшуйте площу зразка, якщо виявляються помилкові мішені
* Зменшуйте, якщо цілі не виявляються
* Налаштовуйте кластеризацію, якщо цілі розділяються на кілька виявлень

### Обробка

Основні параметри обробки зображень та калібрування.

**Ключові налаштування:*** **Корекція віньєтування**: Компенсує затемнення об&#x27;єктива по краях ✅ Рекомендовано
* **Калібрування відбиття**: Нормалізує значення за допомогою калібрувальних мішеней ✅ Рекомендовано
* **Метод дебейєра**: Алгоритм перетворення RAW у 3-канальний мультиспектральний формат
* **Мінімальний інтервал повторної калібрування**: Час між використанням калібрувальних мішеней (0 = використовувати всі)**Розширені налаштування:*** **Зсув часового поясу датчика освітленості**: Для синхронізації часу PPK (за замовчуванням: 0)
* **Застосувати корекції PPK**: Використовує дані GPS/експозиційних контактів з файлів .daq
* **Експозиційний контакт 1/2**: Призначає камери експозиційним контактам для конфігурацій з двома камерами

### Метод дебейєрингу

Наразі ми пропонуємо 2 методи дебейєрингу в Chloros:

#### Стандартний (Швидкий, Середня якість)

Стандартний метод дебайєрингу працює швидко, але демонструє колірний шум, що призводить до менш точних і більш зашумлених зображень.

#### З урахуванням текстури (повільний, найвища якість) \[Тільки Chloros+]

Метод з урахуванням текстури використовує високоякісний дебайєринг з урахуванням країв у поєднанні з моделлю шумозаглушення на основі штучного інтелекту та машинного навчання, яка усуває майже весь шум дебайєрингу. Для роботи моделі з урахуванням текстури потрібна пам&#x27;ять графічного процесора (VRAM). Ми рекомендуємо використовувати її, якщо у вас є &gt;4 ГБ VRAM, щоб пришвидшити обробку.

### Індекс (мультиспектральні індекси)

Налаштуйте, які індекси рослинності обчислювати та експортувати.

**Як додати індекси:**

1. Натисніть кнопку**«Додати індекс»**

2. Виберіть індекс із випадаючого меню (NDVI, NDRE, GNDVI тощо)
3. Налаштуйте параметри візуалізації (кольори LUT, діапазони значень)
4. Додайте кілька індексів за потреби

**Популярні індекси:*** **NDVI**: Загальний стан рослинності (найпоширеніший)
* **NDRE**: Раннє виявлення стресу разом з RedEdge
* **GNDVI**: Чутливий до концентрації хлорофілу
* **OSAVI**: Добре працює з видимим ґрунтом
* **EVI**: Регіони з високим індексом листової поверхні (LAI)**Власні формули (лише Chloros+):**

* Створюйте власні формули мультиспектральних індексів
* Використовуйте математичні операції з діапазонами для всіх каналів зображення
* Зберігайте власні формули для повторного використання

Усі доступні індекси та формули див. у розділі [Формули мультиспектральних індексів](../project-settings/multispectral-index-formulas.md).

### Експорт

Керує форматом та якістю вихідного файлу.

**Доступні формати:*** **TIFF (16-біт)**: Рекомендується для ГІС та наукового аналізу (діапазон 0–65 535)
* **TIFF (32-біт, відсотки)**: Значення відбиття з плаваючою комою (діапазон 0,0–1,0)
* **PNG (8-біт)**: стиснення без втрат для візуалізації (діапазон 0–255)
* **JPG (8-біт)**: найменші файли, стиснення з втратами (діапазон 0–255)***

## Збереження та завантаження налаштувань

### Збереження шаблону проєкту

Створіть шаблони, які можна використовувати повторно, для забезпечення послідовності робочих процесів:

1. Налаштуйте всі необхідні параметри на панелі «Налаштування проекту»
2. Прокрутіть до розділу **«Зберегти шаблон проекту»** внизу
3. Введіть описову назву шаблону (наприклад, «Survey3N\_RGN\_Agriculture»)
4. Натисніть на піктограму збереження

**Переваги:**

* Застосовуйте однакові налаштування у багатьох проектах
* Діліться конфігураціями з членами команди
* Забезпечте послідовність при повторних опитуваннях

### Завантаження шаблону в новий проект

Під час створення нового проекту:

1. Виберіть **«Новий проект»** у головному меню
2. Оберіть опцію **«Завантажити з шаблону»**

3. Виберіть збережений шаблон
4. Усі налаштування застосовуються автоматично

### Робоча директорія

Налаштування **«Папка для збереження проектів»** визначає, де за замовчуванням створюються нові проекти:

* **Розташування за замовчуванням**: `C:\Users\[Username]\Chloros Projects`
* **Змінити розташування**: натисніть значок редагування та виберіть нову папку
* **Коли змінювати**:
  * Мережевий диск для спільної роботи команди
  * Інший диск з більшим об&#x27;ємом пам&#x27;яті
  * Впорядкована структура папок за роком/клієнтом

## Налаштування PPK (Post-Processed Kinematic)

Якщо ви використовуєте реєстратори даних MAPIR з GPS для точного визначення геопозиції:

### Необхідні умови

* DAQ MAPIR з модулем GPS (GNSS)
* Файл журналу .daq із записами контактів експозиції
* Камера, підключена до контактів експозиції DAQ під час сеансу зйомки

### Етапи налаштування

1. Помістіть файл журналу .daq у папку вашого проєкту
2. У налаштуваннях проєкту встановіть прапорець **«Застосувати корекції PPK»**

3. За необхідності встановіть**«Зсув часового поясу датчика освітленості»** (за замовчуванням: 0 для UTC)
4. Призначте камери до контактів експозиції:
   * **Одна камера**: автоматично призначається до контакту 1
   * **Дві камери**: вручну призначте кожну камеру до відповідного контакту**Призначення контактів експозиції:*** **Контакт експозиції 1**: Виберіть модель камери зі списку
* **Контакт експозиції 2**: Виберіть другу камеру або «Не використовувати»
* Одну й ту саму камеру не можна призначити обом контактам

{% hint style="warning" %}
**Важливо**: Контакти експозиції повинні бути правильно призначені відповідним камерам. Неправильне призначення призведе до неправильних даних геолокації.
{% endhint %}

## Розширені сценарії

### Проекти з кількома камерами

Під час обробки зображень з декількох камер MAPIR в одному проекті:

1. Chloros автоматично визначає модель кожної камери
2. Кожна камера отримує відповідний профіль обробки
3. PPK: вручну призначте кожній камері правильний контакт експозиції
4. Усі камери використовують однаковий формат експорту та індекси

**Приклад**: Survey3W RGN + Survey3N OCN установка з двома камерами

### Зйомки з інтервалом або зйомки за кількома датами

Для повторних зйомок однієї й тієї ж території з плином часу:

1. Створіть шаблон зі своїми стандартними налаштуваннями
2. Використовуйте однакову конфігурацію калібрувальних мішеней під час кожного сеансу
3. Обробляйте кожну дату як окремий проєкт
4. Використовуйте однакові налаштування для отримання порівнянних результатів
5. Експортуйте в однаковому форматі для часового аналізу

### Великі набори даних

Для проєктів із великою кількістю зображень (500+):

* Розгляньте можливість поділу на менші проекти за датою або територією
* Використовуйте паралельну обробку Chloros+ для швидших результатів
* Розгляньте CLI або API для автоматизації пакетної обробки
* Налаштуйте мінімальний інтервал повторної калібрування, щоб скоротити час виявлення мішеней

## Перевірка налаштувань

Перед початком обробки перевірте такі ключові налаштування:

* [ ] Модель камери правильно визначена у файловому браузері
* [ ] Увімкнено корекцію віньєтування
* [ ] Увімкнено калібрування відбиття
* [ ] Імпортовано принаймні одне зображення калібрувальної мішені
* [ ] Додано бажані мультиспектральні індекси
* [ ] Формат експорту відповідає вашому робочому процесу
* [ ] Налаштовано параметри PPK (якщо використовуєте .daq із подіями експозиції)
