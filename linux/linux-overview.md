# Огляд Linux

Chloros 1.3.0 забезпечує вбудовану підтримку Linux для **CLI**та**Python SDK** — обробку мультиспектральних зображень у режимі без монітора, а також управління камерами LATTICE та світлочутливими датчиками DAQ у режимі реального часу — на робочих станціях, серверах Linux та периферійних пристроях NVIDIA Jetson.

{% hint style="info" %}
**На Linux немає графічного інтерфейсу для настільних ПК.**Графічний інтерфейс Chloros Desktop доступний лише для Windows. Користувачі Linux взаємодіють із Chloros через [CLI](../CLI.md) та [Python SDK](../api-python-sdk.md). `.deb` дійсно додає пункт**Chloros CLI** до меню програм — він просто відкриває емулятор терміналу, на якому запускається `chloros-cli`.
{% endhint %}

## Підтримувані архітектури

| Архітектура | Опис | Пакет |
| --- | --- | --- |
| **amd64 (x86_64)** | Стандартні процесори для настільних ПК/серверів (Intel, AMD) | `chloros_<version>_amd64.deb` |
| **arm64 (aarch64)** | Процесори ARM — сімейство NVIDIA Jetson Orin (JetPack 6) | `chloros_<version>_arm64_jp6.deb` |

## Підтримувані дистрибутиви Linux

* **Ubuntu 22.04 LTS або новіше** (amd64)
* **Debian 12 або новіше** (amd64)
* **NVIDIA JetPack 6** (arm64 — платформи Jetson Orin)***

## Що отримують користувачі Linux

* **Chloros CLI** — повний інтерфейс командного рядка для пакетної обробки, автоматизації та створення скриптів
* **Chloros Python SDK** — програмний інтерфейс Python для дослідницьких конвеєрів та власних інструментів, що встановлюється за допомогою `.deb` для системи `python3` (Wheel-пакет відповідної версії для virtualenvs міститься у `/usr/lib/chloros/sdk/`; PyPI призначений для машин без пакета Chloros)
* **Управління камерами LATTICE** — виявлення, підключення, налаштування та зйомка з камер LATTICE та синхронізованих масивів з декількох камер за допомогою `chloros-cli lattice` та SDK; `.deb` містить середовище виконання Arena SDK, необхідне для роботи камер
* **Керування світловими датчиками DAQ** — підключення датчиків DAQ-U/M/E, потокова передача відкаліброваних спектрів та запис файлів `.daq` за допомогою `chloros-cli daq pool-*` та SDK
* **Синхронізація часу за PTP** — бекенд Chloros запускає головний сервер PTP, до якого підключаються камери LATTICE та датчики DAQ-E; перевіряйте його за допомогою `chloros-cli time-sync` та підтримуйте його роботу в бездисплейному режимі за допомогою модуля systemd `chloros-backend@<user>.service` (див. [Встановлення на Linux](linux-installation.md#always-on-ptp-for-headless-hosts))
* **Автоматизація проектів** — запускайте збережені проекти в бездисплейному режимі за допомогою `chloros-cli project` та `open_project` з SDK
* **Прискорення на GPU** — обробка з прискоренням CUDA на графічних процесорах NVIDIA (настільні графічні процесори на amd64 та графічний процесор Jetson із JetPack 6)
* **Динамічна адаптація обчислень** — автоматичне виявлення апаратного забезпечення та вибір стратегії обробки, з можливістю перевизначення за допомогою `CHLOROS_STRATEGY` як експертного «запасного виходу»
* **Усі функції обробки** — той самий конвеєр, що й у Windows: калібрування, корекція віньєтування, індекси рослинності та всі формати експорту
* **Функції Chloros+** — багатопотокова (конвеєрна) обробка, дебейер з урахуванням текстури (на графічному процесорі CUDA) та користувацькі індекси за умови придбання платного плану Chloros+

## Чого не отримують користувачі Linux

* **Графічний інтерфейс** — немає графічного інтерфейсу; вся взаємодія відбувається через CLI або Python SDK
* **Переглядач зображень** — немає інтерактивного переглядача зображень, режиму перегляду у вигляді сітки чи маркерів на карті
* **Візуальне управління проектами** — проекти створюються та керуються за допомогою команд CLI та викликів SDK (саме обладнання — камери, датчики, пристрої збору даних — залишається повністю керованим із терміналу)***

## Вимоги до ліцензії

Для доступу до CLI та SDK необхідний **платний тариф Chloros+ — Copper або вище**(Copper, Bronze, Silver, Gold). Безкоштовний тариф**Iron** не надає доступу до CLI/SDK. Це обмеження застосовується на рівні бекенду, а не лише в CLI:

| Ситуація | Відповідь бекенду |
| --- | --- |
| Не ввійшли в систему | `401` з `error_code: AUTH_REQUIRED` |
| Увійшли на безкоштовному рівні «Iron» | `403` з `error_code: PLAN_UPGRADE_REQUIRED` |

`chloros-cli status` працює на будь-якому тарифі — це єдиний маршрут, на який не поширюється обмеження, — тому причина відмови завжди видна.

## Початок роботи на Linux

1. **Встановіть Chloros** — див. [Встановлення на Linux](linux-installation.md) для встановлення `.deb`
2. **Перевірка** — `chloros-cli --version` виводить `Chloros CLI 1.3.0`; `chloros-cli selftest` запускає 7-крокову діагностику
3. **Перевірте Python SDK** — `.deb` встановлює його: `python3 -c "import chloros_sdk; print(chloros_sdk.__version__)"` (у virtualenv, `pip install /usr/lib/chloros/sdk/chloros_sdk-*.whl`)
4. **Увійдіть у систему** — `chloros-cli login your@email.com 'your-password'` (один раз на кожну машину; оновлення пакета зберігають дані входу, а видалення пакета — очищає їх)
5. **Обробіть свій перший набір даних** — `chloros-cli process ~/datasets/flight001`

Для NVIDIA Jetson дивіться спеціальний [Посібник з NVIDIA Jetson](nvidia-jetson-guide.md), де ви знайдете інформацію про налаштування для конкретної платформи, теплові характеристики та розгортання в польових умовах.
