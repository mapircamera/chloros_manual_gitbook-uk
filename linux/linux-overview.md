# Linux: огляд

Chloros 1.1.0 забезпечує вбудовану підтримку Linux для **CLI**та**Python SDK**, що дозволяє здійснювати обробку мультиспектральних зображень без монітора на робочих станціях, серверах та периферійних пристроях NVIDIA Jetson.

{% hint style="info" %}
**На Linux немає графічного інтерфейсу.** Графічний інтерфейс Chloros Desktop доступний лише на Windows. Користувачі Linux взаємодіють з Chloros через [CLI](../CLI.md) та [Python SDK](../api-python-sdk.md).
{% endhint %}

***

## Матриця підтримки платформ

| Функція | Windows (GUI) | Windows (CLI/SDK) | Linux amd64 (CLI/SDK) | Linux arm64 / Jetson (CLI/SDK) |
| --- | --- | --- | --- | --- |
| **Графічний інтерфейс для настільних ПК** | Так | Немає | Ні | Ні |
| **CLI** | Так | Так | Так | Так |
| **Python SDK** | Так | Так | Так | Так |
| **Прискорення на GPU (CUDA)** | Так | Так | Так | Так (JetPack 6) |
| **Дебайер з урахуванням текстур** | Так (Chloros+) | Так (Chloros+) | Так (Chloros+) | Так (Chloros+) |
| **Динамічна адаптація обчислень** | Так | Так | Так | Так |***

## Підтримувані архітектури

| Архітектура | Опис | Спосіб встановлення |
| --- | --- | --- |
| **amd64 (x86_64)** | Стандартні процесори для настільних ПК/серверів (Intel, AMD) | Пакет `.deb` |
| **arm64 (aarch64)** | Процесори на базі ARM, переважно NVIDIA Jetson | Пакет `.deb` (JetPack 6) |

## Підтримувані дистрибутиви Linux

* **Ubuntu 20.04+** (amd64)
* **Debian 11+** (amd64)
* **NVIDIA JetPack 6** (arm64 — платформи Jetson)***

## Що отримують користувачі Linux

* **Chloros CLI** — Повний інтерфейс командного рядка для пакетної обробки, автоматизації та написання скриптів
* **Chloros Python SDK** — Програмний інтерфейс Python (`pip install chloros-sdk`) для інтеграції в дослідницькі конвеєри та власні інструменти
* **Прискорення на GPU** — обробка з прискоренням CUDA на графічних процесорах NVIDIA (настільних ПК та Jetson)
* **Динамічна адаптація обчислень** — автоматичне виявлення апаратного забезпечення та оптимізація стратегії обробки
* **Усі функції обробки** — той самий конвеєр мультиспектральної обробки, що й у Windows (калібрування, корекція віньєтування, індекси рослинності, усі формати експорту)
* **Функції Chloros+** — багатопотокова обробка, дебайер з урахуванням текстури, власні індекси (з ліцензією Chloros+)

## Чого не отримують користувачі Linux

* **Графічний інтерфейс для настільних ПК** — Немає графічного інтерфейсу; вся взаємодія відбувається через CLI або Python SDK
* **Переглядач зображень** — Немає інтерактивного переглядача зображень, режиму перегляду у вигляді сітки або маркерів на карті
* **Візуальне управління проектами** — Управління проектами здійснюється за допомогою команд CLI та викликів SDK***

## Початок роботи з Linux

1. **Встановіть Chloros** — Дивіться [Встановлення Linux](linux-installation.md) для встановлення пакета `.deb`
2. **Встановіть Python SDK** (опціонально) — `pip install chloros-sdk`
3. **Активуйте свою ліцензію** — `chloros-cli login your@email.com 'password'`
4. **Обробіть свій перший набір даних** — `chloros-cli process ~/datasets/flight001`

Користувачам NVIDIA Jetson рекомендується ознайомитися зі спеціальним [Посібником NVIDIA Jetson](nvidia-jetson-guide.md) для налаштування та оптимізації під конкретну платформу.
