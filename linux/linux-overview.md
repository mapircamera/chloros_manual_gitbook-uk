# Огляд Linux

Chloros 1.2.0 забезпечує вбудовану підтримку Linux для **CLI**та**Python SDK** — обробку мультиспектральних зображень без монітора, а також управління камерами LATTICE та світлочутливими датчиками DAQ у режимі реального часу — на робочих станціях, серверах та периферійних пристроях NVIDIA Jetson з Linux.

{% hint style="info" %}
**На Linux немає настільного графічного інтерфейсу.**Настільний графічний інтерфейс Chloros доступний лише на Windows. Користувачі Linux взаємодіють із Chloros через [CLI](../CLI.md) та [Python SDK](../api-python-sdk.md). `.deb` дійсно додає**Chloros CLI** до меню вашої програми — він просто відкриває емулятор терміналу, на якому запущено `chloros-cli`.
{% endhint %}

## Підтримувані архітектури

| Архітектура | Опис | Пакет |
| --- | --- | --- |
| **amd64 (x86_64)** | Стандартні процесори для настільних ПК/серверів (Intel, AMD) | `chloros_<version>_amd64.deb` |
| **arm64 (aarch64)** | Процесори ARM — сімейство NVIDIA Jetson Orin | `chloros_<version>_arm64_jp6.deb` (збірка JetPack 6) |

## Підтримувані дистрибутиви Linux

* **Ubuntu 22.04 LTS або новіші версії** (amd64)
* **Debian 12 або новіші версії** (amd64)
* **NVIDIA JetPack 6** (arm64 — платформи Jetson Orin)***

## Що отримують користувачі Linux

* **Chloros CLI** — повний інтерфейс командного рядка для пакетної обробки, автоматизації та створення скриптів
* **Chloros Python SDK** — програмний інтерфейс Python для дослідницьких конвеєрів та власних інструментів (можна встановити з PyPI, а також входить у склад `.deb` у вигляді колеса, що відповідає версії)
* **Керування камерами LATTICE** — виявлення, підключення, налаштування та зйомка з камер LATTICE та синхронізованих масивів з декількох камер за допомогою `chloros-cli lattice` та SDK; `.deb` містить середовище виконання Arena SDK, необхідне для роботи камер
* **Управління світловими датчиками DAQ** — підключайте датчики DAQ-U/M/E, передавайте відкалібровані спектри та записуйте файли `.daq` за допомогою `chloros-cli daq pool-*` та SDK
* **Синхронізація часу за протоколом PTP** — бекенд Chloros запускає головний сервер PTP, до якого підключені камери LATTICE та датчики DAQ-E як підлеглі пристрої; перевіряйте його за допомогою `chloros-cli time-sync`, а також підтримуйте його роботу в бездисплейному режимі за допомогою модуля systemd `chloros-backend.service` (див. [Встановлення Linux](linux-installation.md#always-on-ptp-for-headless-hosts))
* **Автоматизація проектів** — запускайте збережені проекти в режимі без інтерфейсу за допомогою `chloros-cli project` та `open_project` з SDK
* **Прискорення на GPU** — обробка з прискоренням CUDA на графічних процесорах NVIDIA (настільних ПК та Jetson)
* **Динамічна адаптація обчислень** — автоматичне виявлення апаратного забезпечення та вибір стратегії обробки, з можливістю ручного втручання за допомогою параметра `CHLOROS_STRATEGY` як експертного «запасного виходу»
* **Усі функції обробки** — той самий конвеєр, що й у Windows: калібрування, корекція віньєтування, індекси рослинності та всі формати експорту
* **Функції Chloros+** — багатопотокова (конвеєрна) обробка, дебейер з урахуванням текстури та користувацькі індекси, доступні за платним планом Chloros+

## Чого не отримують користувачі Linux

* **Графічний інтерфейс для настільних ПК** — відсутній графічний інтерфейс; вся взаємодія здійснюється через CLI або Python SDK
* **Переглядач зображень** — немає інтерактивного переглядача зображень, режиму перегляду у вигляді сітки або маркерів на карті
* **Візуальне управління проектами** — проекти створюються та керуються за допомогою команд CLI та викликів SDK (саме обладнання — камери, датчики, засоби збору даних — залишається повністю керованим з терміналу)***

## Вимоги до ліцензії

Для доступу до CLI та SDK необхідний **платний тариф Chloros+ — Copper або вище**(Copper, Bronze, Silver, Gold). Безкоштовний тарифний план**«Iron»** не надає доступу до CLI/SDK. Цей мінімальний рівень контролюється серверною частиною, а не лише CLI:

| Ситуація | Відповідь серверної частини |
| --- | --- |
| Не ввійшли в систему | `401` з `error_code: AUTH_REQUIRED` |
| Увійшов на безкоштовному рівні Iron | `403` з `error_code: PLAN_UPGRADE_REQUIRED` |

`chloros-cli status` працює на будь-якому тарифному плані — це єдиний маршрут, на який не поширюється обмеження, — тому причина відмови завжди відображається.

## Початок роботи з Linux

1. **Встановіть Chloros** — див. [Встановлення Linux](linux-installation.md) для встановлення `.deb`
2. **Перевірка** — `chloros-cli --version` виводить на екран `Chloros CLI 1.2.0`; `chloros-cli selftest` запускає 7-етапну діагностику
3. **Встановіть Python та SDK** (опціонально) — `pip install chloros-sdk`
4. **Увійдіть у систему** — `chloros-cli login your@email.com 'your-password'` (один раз на кожну машину та повторно після кожного оновлення пакета)
5. **Обробіть свій перший набір даних** — `chloros-cli process ~/datasets/flight001`

Для NVIDIA Jetson дивіться спеціальний [Посібник з NVIDIA Jetson](nvidia-jetson-guide.md), де наведено налаштування для конкретної платформи, інформацію про теплові характеристики та розгортання в польових умовах.
