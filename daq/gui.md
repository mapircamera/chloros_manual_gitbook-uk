# Вкладка «DAQ» у програмі Chloros

Вкладка «DAQ» — позначена як **Світлові датчики** на бічній панелі Chloros — є інтерфейсом управління в режимі реального часу для [світлових датчиків DAQ-U, DAQ-M та DAQ-E](README.md): підключайте датчики через будь-який канал передачі даних, переглядайте відкалібровані спектри в режимі реального часу, обчислюйте коефіцієнт відбиття в режимі реального часу за допомогою пари датчиків та записуйте файли `.daq` безпосередньо у ваш проєкт.

Вкладка стає доступною після завершення запуску серверної частини Chloros. Дані для діаграм на вкладці надходять від служби DAQ Chloros через активне з’єднання, яке автоматично відновлюється (з затримкою 2–10 с) у разі переривання; поки служба недоступна, у рядку «Статус» датчика відображається **«No Server»**.

Макет складається з **бічної панелі датчиків**(один рядок на кожен підключений датчик) та**області діаграм** (одна плитка діаграми на кожен датчик або групу).

## Підключення датчика

Натисніть **«Підключити датчик»** у верхній частині бічної панелі. У головній області відкриється діалогове вікно підключення (або у вигляді накладного вікна під час додавання ще одного датчика — у цьому випадку з’явиться кнопка «Скасувати»).

| Елемент керування | Поведінка |
| --- | --- |
| **Тип пристрою** | `DAQ-U (USB)` (за замовчуванням), `DAQ-M (Bluetooth)` або `DAQ-E (Ethernet)`. Перемикання запускає повторне сканування для щойно обраного транспортного протоколу. |
| **Порт / Пристрій BLE / Ім’я хоста / IP** | Перелік виявлених пристроїв у форматі `device - description`; автоматично вибирається перший запис, розпізнаний як датчик. Під час сканування відображається `Scanning...` (USB), `Scanning (N)...` із 8-секундним відліком (BLE) або `Discovering ethernet sensors (N)...` із 5-секундним відліком (Ethernet). У разі відсутності результатів відображаються записи `No ports` / `No BLE devices` / `No ethernet sensors found`. |
| **↻ Оновити** | Негайно повторно сканує вибраний канал передачі (не працює під час сканування BLE/Ethernet). |
| **Підключити датчик** | Стає доступним після вибору пристрою; під час встановлення з’єднання змінює позначку на `Connecting...`. |

Пошук працює лише **під час відображення діалогового вікна підключення** і повторюється кожні 15 секунд лише для вибраного каналу передачі даних — просто відкриття вкладки не запускає сканування. У разі невдачі у діалоговому вікні з’являється повідомлення: *«Підключення не вдалося. Спробуйте від’єднати та знову під’єднати датчик, а потім натисніть «Підключити» ще раз».*

Бічна панель відкривається автоматично, коли підключається ваш перший датчик.

{% hint style="info" %}
**DAQ-E не відображається?**DAQ-E не має світлодіода стану — перевірте індикатор PoE/з’єднання на комутаторі або порту інжектора, до якого він підключений, і зачекайте кілька секунд після увімкнення живлення, щоб пристрій завантажився. Комп’ютер з Chloros повинен перебувати в тому самому домені мовлення (mDNS не проходить через маршрутизатори). Правило брандмауера**«Chloros Backend (UDP-In)»** у програмі встановлення пропускає mDNS (UDP 5353), дані DAQ-E (UDP 5002) та PTP (UDP 319/320); у брандмауері стороннього виробника необхідно дозволити ті самі порти. Два пристрої DAQ-E в одній локальній мережі виявляються окремо, кожен під власним іменем хоста `daq-e-<id>.local`.
{% endhint %}

## Бічна панель датчиків

Кожен підключений датчик отримує свій рядок (плюс один рядок на кожну групу «Навколишнє середовище + Об’єкт»). Порядок рядків можна змінювати перетягуванням, при цьому змінюється й порядок блоків діаграми. Клацніть на рядок, щоб зробити цей датчик/групу активною діаграмою у списку.

| Елемент | Значення |
| --- | --- |
| Кольорова ліва рамка | Колір графіка датчика. |
| Значок передачі даних | `DAQ-U` / `DAQ-M` / `DAQ-E`, або зелений значок `REF` для групи відбиття Ambient+Object. |
| Назва пристрою | За замовчуванням — серійний номер датчика (його стабільний ідентифікатор для калібрування, імен файлів `.daq` та зіставлення при імпорті); власні назви зберігаються для кожного проєкту. |
| Піктограма **«Калібровано»** (зелена) | Відображається, коли завантажено заводський пакет калібрування датчика, тобто спектри мають значення у Вт/м²/нм. |
| Піктограма **Доступне оновлення** (бурштинова, лише для DAQ-E) | Версія прошивки, що працює, є старішою за образ, що входить до складу цієї збірки Chloros. Під час оновлення відображається поточний прогрес (`Flashing… N%`, `Restarting sensor…`, потім `Updated X → Y` або `Failed`). |
| Око | Вмикає/вимикає відображення цього датчика на графіку. |
| Шестерня | Відкриває модальне вікно налаштувань для окремого датчика (нижче). |
| ✕ (червоний) | Відключає датчик або видаляє групу «Ambient+Object». |

Над рядками розташовані дві кнопки:

* **Підключити датчик** — відкриває діалогове вікно підключення (під час роботи перейменовується на `Connecting...`).
* **Записати все / Зупинити все**— запускає або зупиняє запис `.daq` на**усіх**підключених датчиках. Потрібен принаймні один датчик**та відкритий проєкт** (підказка: «Відкрийте проєкт для запису»); під час будь-якого запису кнопка стає червоною.

У порожньому стані відображається напис «Датчики не підключені».

## Налаштування для кожного датчика (модальне вікно із значком шестерні)

Відкривається за допомогою іконки шестерні у рядку датчика. Вміст у порядку:

* **Рядки інформації** — Тип пристрою (DAQ-U/M/E), З’єднання (`Serial (USB)` / `Bluetooth` / `Ethernet`), порт (COM-порт, адреса BLE або хост) та послідовний порт.
* **Звіт про калібрування: Завантажити** — завантажує сертифікат калібрування цього пристрою, що відповідає стандартам NIST (PDF), та відкриває його у вашій програмі перегляду PDF-файлів. Доступно після введення серійного номера; сертифікат зберігається у кеші під час першого підключення.
* **Назва пристрою** — натисніть на олівець, щоб змінити назву; зберігається для кожного проєкту.
* **Колір лінії графіку** — зразок кольору; зберігається для кожного проєкту.
* **Час інтеграції (мс)**— повзунок + число,**1–500 мс**, за замовчуванням**32 мс**. Вимкнено, коли AE увімкнено.
* **Середнє за кадром**— повзунок + число,**1–50 кадрів**, за замовчуванням**20**.
* **AE: УВІМКНЕНО/ВИМКНЕНО**— перемикач автоматичної експозиції;**за замовчуванням УВІМКНЕНО** під час підключення. Вимкніть, щоб встановити час інтеграції вручну.
* **Зупинити трансляцію / Почати трансляцію** — призупинити або відновити пряму трансляцію.
* **Запис / Зупинити запис** — запис за датчиком `.daq` (потрібен відкритий проєкт).
* **Cap** — профіль корекції капа (наступний розділ).
* **Рядки з інформацією в режимі реального часу** — час інтеграції (мс), FPS, кількість зразків, запис (червоний `REC` або `Off`) та стан (`Streaming` / `Paused` / `SATURATED` / `No Server`).

### Тільки для DAQ-E: рядки «Мережа», «Прошивка» та «PTP»

* **Ім’я хоста / IP** — поточна адреса пристрою.
* **Прошивка** — поточна версія прошивки, а також клітинка дії:<version\>

кнопка</version\>

**Оновити до \<version\>** з’являється, коли ця збірка Chloros містить новіший образ прошивки для DAQ-E. Оновлення передається через мережу приблизно за 30 секунд; датчик автоматично перезапускається та повторно підключається, а у разі переривання передачі поточна прошивка залишається незмінною. Хід оновлення відображається в режимі реального часу (`Flashing… N%` → `Restarting sensor…` → `Updated X → Y`), а в комірці відображається значення `Up to date`, коли оновлення завершено.
* **Синхронізація PTP** — поточний стан PTP (переходить у режим `unknown`). Прошивка DAQ-E версії 1.2.0+ бере участь у стандарті IEEE 1588 PTPv2 як годинник, що працює лише у режимі веденого; бекенд хоста Chloros є головним годинником PTP, і кожна камера DAQ-E та LATTICE у локальній мережі підпорядковується йому в домені 0, підтримуючи похибку часових міток у межах приблизно 1 мс.
* **Мережа**— адреса, за якою працює пристрій, та спосіб її отримання (DHCP, локальна за зв’язком або статична), а також збережене налаштування, яке застосовується після перезапуску.**Змінити…**відкриває форму:**Автоматично (DHCP)**або**Статична IP-адреса**із зазначенням IP-адреси, маски підмережі та опціонального шлюзу.**Застосувати та перезапустити** — зберігає налаштування, перезапускає датчик і повторно підключає його. Статична адреса поза мережею цього комп’ютера відхиляється, оскільки Chloros не зможе підключитися до датчика після перезапуску; у такому разі з’являється поле, що дозволяє все ж дозволити це для комп’ютера, який буде переадресовано або маршрутизовано до цієї мережі. **Трансляція при увімкненні**визначає, чи датчик почне трансляцію одразу після увімкнення, до того, як будь-яке програмне забезпечення підключиться.**Перезапустити датчик** — перезапускає його та повторно підключає з поточними налаштуваннями. Перезапуск неможливий, поки датчик веде запис. Нове у версії 1.3.0.

Для групи «Ambient+Object» у модальному вікні з шестірнею відображаються лише джерельні датчики групи, назва пристрою та колір лінії на графіку.

### Вибір кришки

У випадаючому меню **Кришка** вказується програмі Chloros, яка фізична кришка встановлена на дифузорі датчика, і до кожного спектра застосовується виміряний на заводі профіль корекції цієї кришки. Варіанти вибору залежать від моделі:

| Модель | Варіанти кришок |
| --- | --- |
| DAQ-U | Немає (голий датчик), FOV 15°, FOV 30°, FOV 45°, FOV 60°, FOV 90°, Sunshine (косинусний коректор) |
| DAQ-M | Немає (голий датчик), Sunshine (коректор косинуса) |
| DAQ-E | Немає (голий датчик), FOV 15°, FOV 45°, FOV 90°, Sunshine (коректор косинуса) |

**За замовчуванням для кожної моделі встановлено режим «Сонячне світло» (коректор косинуса)** — компанія MAPIR постачає кожен DAQ із встановленим ковпаком «Сонячне світло», і це є стандартною конфігурацією для роботи на відкритому повітрі: напівсферичний огляд 180° з похибкою косинуса ≤ ±4 % до 60° та ≤ ±4,5 % до 70° (не рекомендується при куті підйому Сонця нижче ~15°), з вбудованим ослабленням сигналу (~12×). Ваш вибір зберігається в проєкті.

{% hint style="warning" %}
**Вибір ковпачка повинен відповідати фізичному ковпачку.**Ні датчик, ні програмне забезпечення не можуть визначити, який саме ковпачок встановлено. Цей вибір визначає як поточну корекцію, так і мітку, що записується у кожен файл `.daq` — з огляду на ~12-кратне ослаблення ковпачка Sunshine, незадекларована зміна кришки призводить до неправильної корекції спектрів приблизно на цей коефіцієнт. (Зняття та повторне встановлення тієї самої кришки повторює результат з точністю до приблизно 1,5 %.) Обирайте**«None» (голий датчик)** лише тоді, коли кришка фізично знята; на DAQ-E опція «None» все одно застосовує заводський геометричний профіль для вбудованого скляного дифузора — це не порожня операція — а DAQ-E без насадки є лабораторною конфігурацією, а не підтримуваною польовою конфігурацією.
{% endhint %}

{% hint style="info" %}
Оновлення порівняно з попереднім посібником: перемикач «Встановлено сонячний дифузор» у браузері, що був у версії 1.1.0, зник. Тепер управління кришками здійснюється за допомогою профілю кришки для кожного датчика, що застосовується на стороні сервера.
{% endhint %}

## Область діаграм

У верхній фіксованій панелі розміщено **перемикач між режимами перегляду «Список» ⇄ «Сітка»**та повзунок**«Масштаб діаграми»** (розмір клітинки 200–2000 пікселів). Режим перегляду автоматично перемикається на «Сітку», коли існує більше ніж одна група діаграм, і повертається до «Списку», коли їх одна або менше. Режим перегляду та розмір діаграми зберігаються для кожного проєкту.**Спектральна діаграма** для кожного датчика показує:

* **Вісь X** — довжина хвилі (нм). Сітка датчика становить 340–1010 нм з кроком 5 нм (135 точок), інтерпольована до 1 нм для відображення.
* **Вісь Y**— для відкаліброваного датчика (зелена пігулка**Відкалібровано**),**Потужність (Вт/м²/нм)**— радіометрично відкалібрована спектральна інтенсивність випромінювання для всіх трьох носіїв — з автоматичним префіксом SI (м/мк/н), обраним за піковим значенням. Датчик, для якого не завантажено пакет калібрування, відображає свої необроблені показання як**Інтенсивність (імпульси)**, без масштабування. Коли на графіку накладено обидва типи даних, потужність відображається на лівій осі, а імпульси — на правій.
* Спектральне зафарбування у вигляді веселки під окремою кривою; дані від декількох датчиків на одному графіку накладаються у вигляді кольорових ліній із приглушеним зафарбуванням.
* **Наведення курсору**— вертикальний курсор із довжиною хвилі та значенням для кожного датчика (Вт/м²/нм для відкаліброваного датчика, інакше — загальна кількість імпульсів);**перетягування** для масштабування (під час масштабування з’являється кнопка зменшення масштабу).
* Кнопка **+** (лише у режимі сітки) для додавання датчика до цього графіку або створення групи (див. нижче).
* Назва пристрою, вирівняна по центру зверху, та індикатор завантаження до надходження першого кадру.

**Насиченість** не позначається на самому графіку: насичений датчик відображає червоний текст стану `SATURATED` та червоний рядок `Saturated: Yes` у таблиці даних у реальному часі. Щоб усунути це, зменшіть час інтеграції або знову увімкніть AE.

## Таблиця даних у реальному часі (перегляд у вигляді списку)

Під діаграмою у вигляді списку, оновлюється кожні 500 мс:

* **Усі моделі**: Зразок кольору світла (sRGB за CIE XYZ), Насичений (Так/Ні), CIE 1931 X/Y/Z, Хроматичність x/y, CIE u′/v′, CCT (K), CRI (Ra), домінуюча довжина хвилі (нм), пікова довжина хвилі (нм), чистота збудження, Duv, CIE L\*/a\*/b\* та Munsell H/V/C.
* **Тільки відкалібровані датчики**(будь-який із DAQ-U / DAQ-M / DAQ-E після завантаження заводського калібрувального пакета — про це свідчить зелений значок**Відкалібровано** у рядку датчика): Загальна потужність (Вт/м²), Фотопічний люкс (лк), Скотопічний люкс (лк), співвідношення S/P, PPFD та PPFD Red /Green /Blue (мкмоль/м²/с), а також оптичні інтенсивності випромінювання — S-конус, меланопічний, родопічний, M-конус, L-конус (усі в Вт/м²).

## Групи відбиття (Навколишнє освітлення + Об’єкт)

Два підключені датчики можна об’єднати для відображення коефіцієнта відбиття в режимі реального часу — без використання камери:

1. У режимі перегляду сітки натисніть **+**на плитці діаграми та виберіть**Об’єднати навколишнє освітлення + об’єкт**.
2. Виберіть датчик **Джерело навколишнього світла**та датчик**Сканер об’єкта**(два різних датчики), а потім натисніть**Створити**.

Chloros обчислює R(λ) = об’єкт(λ) / навколишнє середовище(λ) для кожної довжини хвилі на основі двох потоків даних у реальному часі (0, якщо навколишнє середовище ≤ 0). Назва групи залежить від класу калібрування датчиків:

* Обидва датчики відкалібровані (пакет завантажено) → **«Видима відбивна здатність»**.
* Хоча б один датчик не відкалібрований → **«Відносна відбивна здатність»**.

Група відображається у бічній панелі як зелений рядок `REF` та має власний графік (зафарбований у кольори веселки, значення при наведенні курсору з точністю до 4 знаків після коми, масштабування перетягуванням).

Меню **+**також пропонує опцію**Додати новий датчик** із трьома варіантами розміщення: *Об’єднати новий датчик* (додати до цього графіку), *Перемістити існуючий датчик сюди* або *Переглянути новий датчик* (окремий графік).

### Таблиця індексів рослинності

У режимі перегляду списку таблиця індексів рослинності розташована під діаграмою групи відбивної здатності; ці індекси обчислюються на основі поточних значень відбивної здатності в центрах діапазонів **синій 450 / зелений 550 / червоний 670 / NIR 800 нм** (значення з точністю до 4 знаків після коми, `---`, якщо не можна обчислити; наведіть курсор на назву індексу, щоб побачити його повну назву):

## Запис файлів `.daq`

* Для запису необхідний **відкритий проєкт** — інакше як кнопка «Записати все» (бічна панель), так і кнопка «Записати» для кожного датчика окремо будуть неактивними.
* Файли записуються у папку **`<project folder>/light_sensor/`**; імена файлів містять ідентифікатор датчика та мітку часу, а назва пристрою зберігається разом із записом.
* Коли запис зупиняється (кнопка «Зупинити», «Зупинити все» або роз’єднання під час запису), готовий файл `.daq` **автоматично додається до відкритого проєкту** — він з’являється у списку файлів проєкту без ручного додавання, готовий для використання як дані про інсоляцію для [обробки коефіцієнта відбиття](README.md).
* Під час запису у рядках модального вікна налаштувань відображається червоний індикатор `REC`.

Для отримання кількісних значень інтенсивності випромінювання слід усереднювати дані щонайменше за 15 секунд — це характеристика приладу, а не його несправність.

## Розміщення декількох датчиків та збереження налаштувань проєкту

* Об’єднуйте кілька датчиків на одному графіку (спільні осі), зберігайте окремі графіки (автоматичне розміщення у сітці), переміщуйте датчики між графіками, перетягуйте та змінюйте порядок рядків/плиток, а також приховуйте окремі датчики за допомогою перемикача у вигляді ока.
* Для кожного проєкту Chloros зберігає: назви пристроїв, кольори графіків, розмір діаграми, режим перегляду та налаштування кожного датчика (час інтеграції, усереднення кадрів, стан AE, вибір кришки).
* **При повторному відкритті проєкту датчики автоматично підключаються** за адресою — COM-порт для DAQ-U, пристрій BLE для DAQ-M, ім’я хосту mDNS для DAQ-E (визначається навіть у разі зміни IP-адреси пристрою) — та повторно застосовує збережений для кожного датчика профіль капелюшка, усереднення кадрів, стан AE та час інтеграції, заданий вручну.***

## Спряження камери (DLS)

Спарювати нічого. На відміну від робочих процесів DLS для дронів, які заздалегідь прив’язують датчик освітленості до камери, Chloros зіставляє дані DAQ із зображеннями на пізнішому етапі: під час імпорту/обробки показання `.daq` інтерполюються до мітки часу експозиції кожного знімка.
