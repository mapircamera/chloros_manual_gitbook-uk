# Вкладка «DAQ» у Chloros

Вкладка «DAQ» — позначена як **«Світлові датчики»** на бічній панелі Chloros — є панеллю управління в режимі реального часу для [світлових датчиків DAQ-U, DAQ-M та DAQ-E](README.md): підключайте датчики через будь-який канал передачі даних, переглядайте відкалібровані спектри в режимі реального часу, обчислюйте коефіцієнт відбиття в режимі реального часу за допомогою пари датчиків та записуйте файли `.daq` безпосередньо у ваш проєкт.

Вкладка стає доступною після завершення запуску серверної частини Chloros. Діаграми на вкладці оновлюються службою DAQ Chloros через активне з’єднання, яке автоматично відновлюється (з затримкою 2–10 с) у разі переривання; поки служба недоступна, у рядку «Статус» датчика відображається **«No Server»**.

Макет складається з **бічної панелі датчиків**(один рядок на кожен підключений датчик) та**області діаграм** (одна плитка діаграми на кожен датчик або групу).

## Підключення датчика

Натисніть **Підключити датчик** у верхній частині бічної панелі. У головній області відкриється діалогове вікно підключення (або у вигляді накладки під час додавання іншого датчика — у цьому випадку з’явиться кнопка «Скасувати»).

| Елемент керування | Поведінка |
| --- | --- |
| **Тип пристрою** | `DAQ-U (USB)` (за замовчуванням), `DAQ-M (Bluetooth)` або `DAQ-E (Ethernet)`. Перемикання запускає повторне сканування для щойно обраного транспортного протоколу. |
| **Порт / Пристрій BLE / Ім’я хоста / IP** | Відображає список виявлених пристроїв у форматі `device - description`; перший запис, розпізнаний як датчик, вибирається автоматично. Під час сканування відображається `Scanning...` (USB), `Scanning (N)...` із 8-секундним відліком (BLE) або `Discovering ethernet sensors (N)...` із 5-секундним відліком (Ethernet). У разі відсутності результатів відображаються значення `No ports` / `No BLE devices` / `No ethernet sensors found`. |
| **↻ Оновити** | Негайно повторно сканує вибраний канал передачі (відключено під час сканування BLE/Ethernet). |
| **Підключитися** | Стає доступним після вибору пристрою; під час встановлення з’єднання змінює позначку на `Connecting...`. |

Пошук працює лише **під час відображення діалогового вікна підключення** і повторюється кожні 15 секунд лише для вибраного каналу передачі даних — просто відкриття вкладки не запускає сканування. У разі невдачі у діалоговому вікні з’являється повідомлення: *«Підключення не вдалося. Спробуйте від’єднати та знову під’єднати датчик, а потім натисніть «Підключити» ще раз».*

Бічна панель відкривається автоматично, коли підключається ваш перший датчик.

{% hint style="info" %}
**DAQ-E не відображається?** DAQ-E не має світлодіода стану — перевірте індикатор PoE/з’єднання на комутаторі або порту інжектора, до якого він підключений, і зачекайте кілька секунд після увімкнення живлення, щоб пристрій завантажився. Пристрій Chloros повинен перебувати в тому самому домені мовлення (mDNS не проходить через маршрутизатори). На Windows підтвердьте запит брандмауера Defender під час першого підключення Chloros до своїх мультикаст-сокетів (mDNS UDP 5353, дані DAQ-E UDP 5002, PTP UDP 319/320). Два пристрої DAQ-E в одній локальній мережі виявляються окремо, кожен під власним іменем хосту `daq-e-<id>.local`.
{% endhint %}

## Бічна панель датчиків

Кожен підключений датчик отримує свій рядок (плюс один рядок на кожну групу «Ambient+Object»). Рядки можна перетягувати для зміни порядку, при цьому їхній порядок також змінює порядок блоків діаграми. Клацніть на рядок, щоб зробити цей датчик/групу активною діаграмою в режимі перегляду списку.

| Елемент | Значення |
| --- | --- |
| Кольорова ліва рамка | Колір графіка датчика. |
| Іконка передачі даних | `DAQ-U` / `DAQ-M` / `DAQ-E`, або зелений значок `REF` для групи відбиття «Ambient+Object». |
| Назва пристрою | За замовчуванням — серійний номер датчика (його стабільний ідентифікатор для калібрування, імен файлів `.daq` та зіставлення при імпорті); власні назви зберігаються для кожного проєкту. |
| Піктограма **«Калібровано»** (зелена) | Відображається, коли завантажено заводський пакет калібрування датчика, тобто спектри відповідають справжнім значенням у Вт/м²/нм. |
| Іконка **Доступне оновлення** (бурштинова, лише для DAQ-E) | Версія прошивки, що працює, є старшою за образ, що входить до складу цієї збірки Chloros. Під час оновлення відображається поточний прогрес (`Flashing… N%`, `Restarting sensor…`, потім `Updated X → Y` або `Failed`). |
| Око | Вмикає/вимикає відображення цього датчика на графіку. |
| Шестерня | Відкриває модальне вікно налаштувань для окремого датчика (нижче). |
| ✕ (червоне) | Відключає датчик або видаляє групу «Навколишнє середовище + об’єкт». |

Над рядками розташовані дві кнопки:

* **Підключити датчик** — відкриває діалогове вікно підключення (під час роботи змінюється на `Connecting...`).
* **Записати все / Зупинити все**— запускає або зупиняє запис `.daq` на**усіх**підключених датчиках. Потрібен принаймні один датчик**та відкритий проєкт** (підказка: «Відкрийте проєкт для запису»); під час запису кнопка стає червоною.

У порожньому стані відображається напис «Датчики не підключені».

## Налаштування для кожного датчика (модальне вікно із значком шестерні)

Відкривається за допомогою значка шестерні у рядку датчика. Вміст у порядку:

* **Рядки інформації** — Тип пристрою (DAQ-U/M/E), Підключення (`Serial (USB)` / `Bluetooth` / `Ethernet`), порт (COM-порт, адреса BLE або хост) та послідовний порт.
* **Звіт про калібрування: Завантажити** — завантажує сертифікат калібрування цього пристрою, що відповідає стандартам NIST (PDF), та відкриває його у вашій програмі перегляду PDF-файлів. Доступно після введення серійного номера; сертифікат зберігається у кеші під час першого підключення.
* **Назва пристрою** — натисніть на олівець, щоб змінити назву; зберігається для кожного проєкту.
* **Колір лінії графіка** — палітра кольорів; зберігається для кожного проєкту.
* **Час інтеграції (мс)**— повзунок + число,**1–500 мс**, за замовчуванням**32 мс**. Вимкнено, коли AE увімкнено.
* **Середнє значення по кадрах**— повзунок + число,**1–50 кадрів**, за замовчуванням**20**.
* **AE: УВІМКН. / ВИМКН.**— перемикач автоматичної експозиції;**за замовчуванням УВІМКН.** під час підключення. Вимкніть його, щоб встановити час інтеграції вручну.
* **Зупинити трансляцію / Почати трансляцію** — призупинити або відновити пряму трансляцію.
* **Запис / Зупинити запис** — запис за датчиком `.daq` (потрібен відкритий проєкт).
* **Cap** — профіль корекції капа (наступний розділ).
* **Рядки з інформацією в режимі реального часу** — час інтеграції (мс), FPS, кількість зразків, запис (червоний `REC` або `Off`) та стан (`Streaming` / `Paused` / `SATURATED` / `No Server`).

### Тільки для DAQ-E: рядки мережі, прошивки та PTP

* **Ім’я хоста / IP** — поточна адреса пристрою.
* **Прошивка** — поточна версія прошивки, а також клітинка дії:<version\>

кнопка</version\>

**Оновити до \<version\>** з’являється, коли ця збірка Chloros містить новіший образ прошивки DAQ-E. Оновлення передається по мережі приблизно за 30 секунд; датчик автоматично перезапускається та повторно підключається, а у разі переривання передачі поточна версія прошивки залишається незмінною. Хід оновлення відображається в режимі реального часу (`Flashing… N%` → `Restarting sensor…` → `Updated X → Y`), а в комірці відображається значення `Up to date`, коли оновлення завершено.
* **Синхронізація PTP** — поточний стан PTP (переходить у режим `unknown`). Прошивка DAQ-E версії 1.2.0+ бере участь у стандарті IEEE 1588 PTPv2 як годинник, що працює лише у режимі веденого; бекенд хоста з кодом Chloros є головним годинником (grandmaster) PTP, і кожна камера DAQ-E та LATTICE у локальній мережі (LAN) підпорядковується йому в домені 0, підтримуючи похибку часових міток у межах приблизно 1 мс.

Для групи «Ambient+Object» у вікні «Gear» відображаються лише джерельні датчики групи, назва пристрою та колір лінії графіку.

### Вибір кришки

Випадаюче меню **Cap** повідомляє Chloros, який фізичний ковпачок встановлено на дифузорі датчика, і застосовує виміряний на заводі профіль корекції цього ковпачка до кожного спектра. Варіанти вибору залежать від моделі:

| Модель | Варіанти ковпачків |
| --- | --- |
| DAQ-U | Без насадки (голий датчик), FOV 15°, FOV 30°, FOV 45°, FOV 60°, FOV 90°, Sunshine (косинусний коректор) |
| DAQ-M | Немає (голий датчик), Sunshine (коректор косинуса) |
| DAQ-E | Немає (голий датчик), FOV 15°, FOV 45°, FOV 90°, Sunshine (коректор косинуса) |

**За замовчуванням для кожної моделі встановлено режим «Сонячне світло» (коректор косинуса)** — компанія MAPIR постачає кожен DAQ із встановленим ковпаком «Сонячне світло», і це є стандартною конфігурацією для використання на відкритому повітрі: напівсферичний огляд 180° з похибкою косинуса ≤ ±4 % до 60° та ≤ ±4,5 % до 70° (не рекомендується при куті підйому Сонця нижче ~15°), з вбудованим ослабленням (~12×). Ваш вибір зберігається у проєкті.

{% hint style="warning" %}
**Вибір ковпачка повинен відповідати фізичному ковпачку.**Ні датчик, ні програмне забезпечення не можуть визначити, який саме ковпачок встановлено. Вибір впливає як на корекцію в режимі реального часу, так і на мітку, що записується в кожен файл `.daq` — з огляду на ~12-кратне ослаблення ковпачка Sunshine, незадекларована зміна ковпачка призводить до неправильної корекції спектрів приблизно на цей коефіцієнт. (Зняття та повторне встановлення того самого ковпачка призводить до повторення похибки на рівні приблизно 1,5 %.) Вибирайте**«None» (голий датчик)** лише тоді, коли кришка фізично знята; на DAQ-E опція «None» все одно застосовує заводський геометричний профіль для його вбудованого скляного дифузора — це не «no-op» — а голий DAQ-E є лабораторною конфігурацією, а не підтримуваною польовою конфігурацією.
{% endhint %}

{% hint style="info" %}
Оновлення з попередньої версії: перемикач «Встановлено сонячний дифузор» у браузері, який був у версії 1.1.0, зник. Тепер управління кришкою здійснюється за допомогою профілю кришки для кожного датчика, що застосовується на стороні сервера.
{% endhint %}

## Область діаграм

У фіксованій верхній панелі розміщено **перемикач між списком та сіткою**та повзунок**масштабування діаграми** (розмір клітинки 200–2000 пікселів). Режим перегляду автоматично перемикається на сітку, якщо існує більше ніж одна група діаграм, і повертається до списку, якщо їх одна або менше. Режим перегляду та розмір діаграми зберігаються для кожного проєкту.**Діаграма спектра** для кожного датчика показує:

* **Вісь X** — довжина хвилі (нм). Сітка датчика становить 340–1010 нм з кроком 5 нм (135 точок), інтерпольована до 1 нм для відображення.
* **Вісь Y** — потужність (Вт/м²), з автоматичним префіксом SI (м/мк/н), обраним на основі пікового значення. Спектри є радіометрично відкаліброваною спектральною інтенсивністю випромінювання (Вт/м²/нм) для всіх трьох середовищ поширення.
* Спектральне зафарбування у вигляді веселки під окремою кривою; дані від декількох датчиків на одному графіку накладаються у вигляді кольорових ліній із приглушеним зафарбуванням.
* **Наведення курсору**— вертикальний курсор із зазначенням довжини хвилі та значення для кожного датчика;**перетягніть**, щоб змінити масштаб (під час масштабування з’являється кнопка зменшення масштабу).
* Кнопка **+** (лише в режимі сітки) для додавання датчика до цього графіку або створення групи (нижче).
* Назва пристрою, вирівняна по центру вгорі, та індикатор завантаження до надходження першого кадру.

**Насиченість** не позначається на самому графіку: насичений датчик відображає червоний текст статусу `SATURATED` та червоний рядок `Saturated: Yes` у таблиці даних у реальному часі. Щоб скинути цей стан, зменшіть час інтеграції або знову увімкніть AE.

## Групи відбиття (Навколишнє освітлення + Об’єкт)

Два підключені датчики можна об’єднати в динамічне відображення коефіцієнта відбиття — без використання камери:

1. У режимі сітки натисніть **+**на плитці діаграми та виберіть**Об’єднати навколишнє освітлення + об’єкт**.
2. Виберіть датчик **Джерело навколишнього світла**та датчик**Сканер об’єкта**(два різних датчики), а потім натисніть**Створити**.

Chloros обчислює R(λ) = об’єкт(λ) / навколишнє середовище(λ) для кожної довжини хвилі на основі двох потоків даних у реальному часі (0, якщо навколишнє освітлення ≤ 0). Назва групи залежить від класу калібрування датчиків:

* Обидва датчики відкалібровані (пакет завантажено) → **«Видима відбивна здатність»**.
* Хоча б один датчик не відкалібрований → **«Відносна відбивна здатність»**.

Група відображається у вигляді зеленого рядка `REF` на бічній панелі та у власному графіку (заповнення кольорами веселки, значення при наведенні курсору з точністю до 4 знаків після коми, масштабування перетягуванням).

Меню **+**також пропонує опцію**Додати новий датчик** із трьома варіантами розміщення: *Об’єднати новий датчик* (додати до цього графіку), *Перемістити існуючий датчик сюди* або *Переглянути новий датчик* (окремий графік).

## Запис файлів `.daq`

* Для запису необхідний **відкритий проєкт** — в іншому разі кнопки «Записати все» (на бічній панелі) та «Записати» для кожного датчика будуть неактивними.
* Файли записуються у форматі **`<project folder>/light_sensor/`**; імена файлів містять ідентифікатор датчика та мітку часу, а назва пристрою зберігається разом із записом.
* Коли запис зупиняється (кнопка «Зупинити», «Зупинити все» або роз’єднання під час запису), готовий файл `.daq` **автоматично додається до відкритого проєкту** — він з’являється у списку файлів проєкту без ручного додавання, готовий для використання як дані про інсоляцію для [обробки коефіцієнта відбиття](README.md).
* Під час запису у динамічних рядках модального вікна налаштувань відображається червоний індикатор `REC`.

Для отримання кількісних значень інтенсивності випромінювання слід усереднювати дані щонайменше за 15 секунд — це характеристика приладу, а не його несправність.

## Розміщення декількох датчиків та збереження проектів

* Об&#x27;єднуйте кілька датчиків на одному графіку (спільні осі), зберігайте окремі графіки (автоматичне розміщення у сітці), переміщуйте датчики між графіками, перетягуйте та змінюйте порядок рядків/плиток, а також приховуйте окремі датчики за допомогою перемикача у вигляді ока.
* Для кожного проєкту Chloros зберігає: назви пристроїв, кольори графіків, розмір діаграми, режим перегляду та налаштування кожного датчика (час інтегрування, усереднення кадрів, стан AE, вибір обмежувача).
* **При повторному відкритті проєкту датчики автоматично підключаються** за адресою — COM-порт для DAQ-U, пристрій BLE для DAQ-M, ім&#x27;я хоста mDNS для DAQ-E (визначається навіть у разі зміни IP-адреси пристрою) — та повторно застосовує збережений для кожного датчика профіль кришки, усереднення кадрів, стан AE та вручну заданий час інтеграції.***

## Синхронізація камери (DLS)

Нічого синхронізувати не потрібно. На відміну від робочих процесів DLS для дронів, які заздалегідь прив’язують датчик освітленості до камери, Chloros зіставляє дані DAQ із зображеннями на наступному етапі: під час імпорту/обробки показання `.daq` інтерполюються до мітки часу експозиції кожного знімка. Здійснюйте запис за допомогою будь-якого підключеного датчика (`.daq` автоматично додається до проєкту), а обробка відбиття знайде правильні показники за часом — див. [Датчики освітленості DAQ](README.md), щоб дізнатися, як використовуються дані про світло, що падає.</version\>
