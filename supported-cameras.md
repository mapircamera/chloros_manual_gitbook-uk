# Підтримувані камери.

Chloros обробляє зображення з двох сімейств камер MAPIR на **усіх платформах** (Windows, Linux amd64 та Linux arm64/Jetson):

* **Survey3** — камери Survey3W (ширококутні) та Survey3N (вузькокутні). Вхідні дані: `RAW+JPG`.
* **LATTICE**— мультиспектральні камерні модулі M3C та M3M. Вхідні дані: знімки `.tif`/`.tiff`. Камерами LATTICE також можна**керувати в режимі реального часу** з Chloros — через вкладку «Камери» графічного інтерфейсу (Windows) або `chloros-cli lattice` / Python SDK (Windows та Linux) — включаючи синхронізовані масиви з декількох камер. Див. [посібник LATTICE](lattice/).

Конвеєр обробки також підтримує вхідні файли формату `.dng`.

Лінійка LATTICE — це модульна мультиспектральна система камер, побудована на базі датчика Sony IMX265 із глобальним затвором (3,1 МП, розмір пікселя 3,45 мкм). Кожна камера зберігає свій ідентифікатор у вигляді рядка моделі:

```
<sensor>-<lens>-F<filter>        e.g.  M3C-L41-FRGN,  M3M-L87-F550
``` Програма

Chloros відображає її з префіксом `LATT-` (наприклад, `LATT-M3M-L41-F550`), а рядок моделі визначає всі подальші параметри — профіль сенсора, розклад смуг та калібрування визначаються автоматично; налаштування для кожної камери окремо не потрібні. Номер об’єктива відповідає **горизонтальному полю зору в градусах**: `L41` = вузьке 41°, `L87` = широке 87°.

Існує дві конфігурації датчиків:

| Конфігурація | Датчик      | Тип фільтра                           | Діапазони на камеру                                                        |
| ------------- | ----------- | ------------------------------------- | ----------------------------------------------------------------------- |
| **M3C**       | Кольоровий фільтр Байєра | Потрійний смуговий фільтр                       | 3 спектральні діапазони за одну експозицію                                 |
| **M3M**       | Монохромний  | Односмуговий вузькосмуговий інтерференційний фільтр | 1 калібрований діапазон — об’єднайте кілька камер M3M для розрахунку індексів рослинності |

### Варіанти фільтрів M3C (Байєра)

| Фільтр | Діапазони (назва @ центр, нм / FWHM, нм)       |
| ------ | ---------------------------------------- |
| `FRGB` | Blue 475/30 · Green 550/30 · Red 625/30  |
| `FRGN` | Red 660/21 · Green 550/30 · NIR 850/30   |
| `FOCN` | Orange 618,4/46 · Cyan 494,1/40 · NIR 821,6/54 (виміряно — див. нижче) |
| `FNGB` | Blue 475/30 · Green 550/30 · NIR 850/30  |

Для `FOCN` наведені значення є **виміряною** смугою напівмаксимуму фільтра (у Chloros 1.3.0 та пізніших версіях; у попередніх версіях використовувалися значення з технічного паспорта: 615/21 · 490/38 · 808/14). Назви діапазонів залишаються `Orange_615`, `Cyan_490` та `NIR_808`, а виміряні значення центру та ширини — це ті дані, які Chloros вказує у кожному відкаліброваному експорті.
