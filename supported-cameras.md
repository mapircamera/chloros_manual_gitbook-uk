# Підтримувані камери

Chloros обробляє зображення з двох сімейств камер MAPIR на **усіх платформах** (Windows, Linux amd64 та Linux arm64/Jetson):

* **Survey3** — камери Survey3W (ширококутні) та Survey3N (вузькокутні). Вхідні дані: `RAW+JPG`.
* **LATTICE**— мультиспектральні камерні модулі M3C та M3M. Вхідні дані: знімки `.tif`/`.tiff`. Камерами LATTICE також можна**керувати в режимі реального часу** з Chloros — через вкладку «Камери» графічного інтерфейсу користувача (Windows) або `chloros-cli lattice` / Python SDK (Windows та Linux) — включаючи синхронізовані масиви з декількох камер. Див. [посібник LATTICE](lattice/).

Конвеєр обробки також приймає вхідні файли формату `.dng`.

Лінійка LATTICE — це модульна мультиспектральна система камер, побудована на базі датчика Sony IMX265 із глобальним затвором (3,1 МП, розмір пікселя 3,45 мкм). Кожна камера зберігає свій ідентифікатор у вигляді рядка моделі:

```
<sensor>-<lens>-F<filter>        e.g.  M3C-L41-FRGN,  M3M-L87-F550
```

Chloros відображає його з префіксом `LATT-` (наприклад, `LATT-M3M-L41-F550`), і цей ідентифікатор моделі визначає всі подальші параметри — профіль сенсора, розміщення діапазонів та калібрування визначаються автоматично; налаштувати окремо для кожної камери нічого не потрібно. Номер об’єктива відповідає **горизонтальному куту огляду в градусах**: `L41` = вузький 41°, `L87` = широкий 87°.

Існує дві конфігурації датчиків:

| Конфігурація | Датчик      | Тип фільтра                           | Діапазони на камеру                                                        |
| ------------- | ----------- | ------------------------------------- | ----------------------------------------------------------------------- |
| **M3C**       | Кольоровий фільтр Байєра | Потрійний смуговий                       | 3 спектральні смуги за одну експозицію                                 |
| **M3M**       | Монохромний  | Один вузькосмуговий інтерференційний фільтр | 1 калібрована смуга — об’єднайте кілька камер M3M для розрахунку індексів рослинності |

### Варіанти фільтрів M3C (Bayer)

| Фільтр | Діапазони (назва @ центр нм / FWHM нм)       |
| ------ | ---------------------------------------- |
| `FRGB` | Blue 475/30 · Green 550/30 · Red 625/30  |
| `FRGN` | Red 660/21 · Green 550/30 · NIR 850/30   |
| `FOCN` | Orange 615/21 · Cyan 490/38 · NIR 808/14 |
